# 엄마도 처음이라 — 육아 엄마 노래 뮤직비디오

육아하는 엄마에게 바치는 창작곡을 브라우저가 그 자리에서 연주하고, 노래하고, 그린다.

- 배포: https://richroro.github.io/mom-mv/
- 소스: `index.html` 한 파일 (외부 스크립트·폰트·샘플 없음, 서버 없음)

## 곡

80BPM, F장조 발라드. 약 3분 15초.

| 구간 | 마디 | 장면 |
| --- | --- | --- |
| 인트로 (오르골로 후렴 멜로디 예고) | 4 | 밤하늘, 불 켜진 창, 제목 |
| 1절 | 8 | 새벽 세 시 수유 → 창밖이 밝아 옴 (시계 3시→7시) |
| 프리코러스 | 4 | 거울 속 낯선 얼굴 → 아이가 부르는 순간 |
| 후렴 | 8 | 햇살 언덕, 아기를 번쩍 |
| 간주 | 2 | 오르골 |
| 2절 | 8 | 어린이집 등원, 돌아서는 길 |
| 프리코러스 | 4 | 달력이 넘어가고 키가 자람 |
| 후렴 | 8 | 노을 공원 그네 |
| 브리지 | 4+1 | 비 오는 밤, 우리 엄마의 옛 사진 |
| 마지막 후렴 (G장조로 한 음 올림, 화음 보컬) | 8 | 삼대가 손잡은 황금빛 장면 |
| 아웃트로 | 4 | 잠든 아이 이마에 입맞춤, 엔딩 카드 |

## 구조

`섹션·코드·멜로디·가사(SECTIONS, PH) → 이벤트 목록(EV, 초 단위) → Web Audio 합성`,
화면은 `render(t)` 하나가 시간 t만 보고 그린다(상태 없음). 그래서 탐색·녹화 어디서든 같은 그림이 나온다.

- **보컬**: 톱니파 + 포먼트 대역 필터 3개. 음절을 자모로 풀어 모음별 포먼트, 초성(ㅅ·ㅈ 바람, ㄱ·ㄷ·ㅂ 파열),
  받침(ㄴ·ㅁ·ㅇ 비음으로 닫힘)을 흉내 낸다. 이어지는 음은 포르타멘토, 긴 음은 늦게 걸리는 비브라토.
  녹음한 목소리는 아니라서 발음이 또렷하지 않다. 그래서 가사를 노래방 자막으로 띄운다.
- **반주**: 피아노 아르페지오(페달), 오르골, 패드, 베이스, 킥·스네어·하이햇·림·셰이커·크래시·라이저.
- **믹스**: 채널별 컨볼루션 리버브 센드 → 컴프레서 → 리미터. 노래방 모드는 보컬 버스만 끈다.
- **재생**: 40ms마다 0.35초 앞까지 예약(탭이 뒤로 가면 1.6초). 멈추면 재생마다 만든 버스를 통째로 끊는다.
- **WAV**: OfflineAudioContext. 음표를 한꺼번에 걸면 대기 중인 노드까지 매번 계산돼 몹시 느려서,
  `suspend()`로 2초마다 멈춰 다음 구간만 건다 (3분 15초 곡을 굽는 데 1분 남짓).
- **영상 저장**: `canvas.captureStream(30)` + `MediaStreamDestination` → MediaRecorder.
  크롬·엣지는 WebM(VP9/Opus), 사파리는 MP4. 실시간 녹화라 곡 길이만큼 걸린다.

## 조작

`Space` 재생·정지, `←` `→` 5초 이동, `K` 노래방 모드, `F` 전체 화면, 가사 목록을 누르면 그 소절로 이동.
