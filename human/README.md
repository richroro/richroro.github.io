# 디지털 휴먼 — 실시간으로 살아 움직이는 3D 인물

브라우저에서 실시간으로 숨 쉬고, 눈을 깜빡이고, 보는 사람과 눈을 맞추고, 한국어로 말하는 3D 인물.
미리 녹화한 영상이 아니라 매 프레임 WebGL 로 렌더링한다.

- 배포: https://richroro.github.io/human/
- 소스: `src/main.js` → esbuild 로 묶은 `app.js` 한 파일 (three.js r186 포함)
- 인물: [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox) `Female_Adult_03` (MIT, `assets/LICENSE-Rocketbox.md`)

## 사람처럼 보이게 하는 것들

움직임이 외모보다 더 많이 "사람 같음"을 좌우한다. 그래서 대부분의 코드가 행동에 있다.

- **깜빡임**: 평균 3초 남짓, 꼬리가 긴 분포로 간격을 뽑는다. 닫힐 때 75ms, 뜰 때 더 천천히. 14% 확률로 두 번 연속.
  시선을 크게 옮길 때 따라서 깜빡이고, 말할 때 더 자주 깜빡인다.
- **시선**: 눈알은 뼈로 돌리고(±30° 제한), 눈꺼풀은 시선 방향 모프(eyeLook*)로 따라간다. 아래를 보면 윗눈꺼풀이 내려온다.
  모델의 eyeLook 모프는 원래 눈알도 함께 돌리기 때문에 눈알 프리미티브에서는 그 변위를 지웠다(이중 회전 방지).
- **머리**: 시선을 40% 정도만 늦게 따라가고, 서로 다른 주기의 노이즈로 끄덕임·기울임이 섞인다. 말할 때 강세 음절에서 살짝 끄덕인다.
- **호흡**: 약 4.3초 주기로 가슴(척추)·쇄골이 오르내리고 콧볼이 아주 조금 벌어진다.
- **미세표정**: 2~5초마다 눈썹 들썩, 입술 다물기, 한쪽 입꼬리, 침 삼키기 같은 작은 움직임을 하나씩 섞는다.
- **피부**: 직접광 디퓨즈를 채널별로 감싸는(wrap) 셰이더 패치로 명암 경계에 붉은 산란광이 번지게 했다. 시즌(sheen)과 옅은 클리어코트로 피부 기름기.
- **카메라**: 망원(14~15°) 초상 화각, 손에 든 듯한 미세 흔들림, 필름 그레인·비네팅·약한 색수차.

## 에셋 다시 만들기

원본 FBX 는 모프가 175개, 정점 27,624개(비인덱스)라 그대로 쓰면 무겁다. `tools/convert-fbx.js` 가 다음을 한다.

1. 모프를 ARKit 52 + 비셈 15 = 67개만 남기고 이름을 정리(`AK_09_EyeBlinkLeft` → `eyeBlinkLeft`)
2. 모프로 움직이는 삼각형만 `Face` 메시로, 나머지는 모프 없는 `Body` 메시로 분리 → 얼굴 정점 1,174개
3. 눈 뼈에 붙은 삼각형은 따로 `eyes` 재질로(반짝이는 각막용)
4. 모프 노멀을 직접 계산(위치 기준으로 부드러운 노멀을 다시 구해 차이를 저장)
5. 정점 병합 → GLTFExporter 로 GLB, 그다음 `gltf-transform meshopt` 로 압축 (2.4MB → 470KB)

```bash
npm i three@0.186 esbuild playwright-core @gltf-transform/cli
# convert-fbx.js 를 esbuild 로 묶어 브라우저에서 열고, window.GLB(ArrayBuffer)를 파일로 저장
npx gltf-transform meshopt raw.glb assets/avatar.glb
python3 tools/textures.py <tga 폴더> assets
```

npx esbuild src/main.js --bundle --minify --format=esm --target=es2020 --outfile=app.js

## 한계

- 게임용 아바타(얼굴 1천여 정점)라 아주 가까이 보면 윤곽이 각지고 머리카락이 카드 형태로 보인다.
- 말하기 음성은 기기의 TTS 를 쓴다. 한국어 음성이 없는 브라우저에선 입 모양만 움직인다.
  음성 엔진이 단어 경계 이벤트를 주면 그에 맞춰 입 모양 시간축을 보정하고, 안 주면 음절당 0.17초로 추정한다.
- TTS 소리는 브라우저가 녹음 스트림으로 내주지 않아서 녹화 파일에는 들어가지 않는다(영상만).
