# 공모주 캘린더

한국 공모주 청약 일정과 수요예측 결과, 상장 성적을 한 화면에서 보고, 청약 금액과 손익을 계산하는 페이지.

- 배포: https://richroro.github.io/ipo/
- 종목 바로 열기: `/ipo/#i=<id>` (상세 창의 **링크 복사**)

## 무엇을 할 수 있나

| 기능 | 내용 |
| --- | --- |
| 요약 | 지금 청약 중, 이번 주 청약, 2주 안 상장, 최근 3개월 평균 시초가 수익률(스팩 제외) |
| 청약 일정 | 진행·예정 / 상장 예정 / 최근 상장 / 관심 / 전체. 단계와 D-day, 확정 공모가(밴드 상단 대비), 기관경쟁률, 확약 비율, 청약경쟁률, 주간사. 종목명·주간사 검색, 스팩 숨기기 |
| 상세 | 수요예측 → 청약 → 환불 → 상장 타임라인, 공모 금액·주식 수, 상장 뒤 시초가·첫날 종가·현재가 수익률, 숫자로 본 수요 신호, 38·DART·뉴스 링크, 상장 종목은 [전 종목 탐색기](../finder/)로 |
| 달력 | 월 달력에 청약(평일만)·환불·상장. 날짜를 누르면 그날 일정. 휴대폰에서는 색 막대로 줄여 보인다 |
| 달력 파일 | 종목마다 청약·환불·상장일을 `.ics` 로 내려받아 휴대폰·구글 캘린더에 넣는다 |
| 계산기 | 공모가·청약 주수·증거금률로 증거금, 균등 + 비례(청약 주수 ÷ (통합 경쟁률 × 2)) 예상 배정, 환불 예상액, 상장일 가격(-40%~+300%)별 순손익 |
| 내 청약 기록 | 종목·증권사·배정·매도가를 적으면 실현 손익, 올해 손익, 보유 평가 손익. 이 브라우저(localStorage)에만 저장. CSV, JSON 백업·복원 |
| 그 밖 | 관심 종목(★), 다크 모드(다른 페이지와 같은 설정), 앱 설치(PWA)·오프라인 열람 |

## 데이터

페이지는 `data/ipo.json` **한 파일**만 읽는다. `build.py` 가 만들고, GitHub Actions
(`.github/workflows/update-ipo.yml`)가 평일 07:10 · 17:10 KST 에 다시 만들어 커밋한다. 인증키는 필요 없다.

| 무엇 | 출처(38커뮤니케이션) | 막히면 |
| --- | --- | --- |
| 청약 일정 · 확정/희망 공모가 · 청약경쟁률 · 주간사 | `/html/fund/index.htm?o=k` | **실패로 끝나고 기존 파일 유지** |
| 수요예측일 · 공모 금액 · 기관경쟁률 · 의무보유확약 | `/html/fund/index.htm?o=r1` | 이전 값 유지 |
| 상장일 · 시초가 · 첫날 종가 · 현재가 | `/html/fund/index.htm?o=nw` | 이전 값 유지 |
| 시장 · 업종 · 종목코드 · 총공모주식수 · 환불일 · 상장일 | 종목 상세 `/html/fund/?o=v&no=…` (최근 2주·앞으로 일정인 종목 중 모르는 값이 있을 때만, 최대 40곳) | 이전 값 유지 |

표 열은 순서가 아니라 **머리글 글자**로 찾는다(`SCHEDULE_COLS` 등). 38 이 표 모양을 바꿔 청약 일정 표를
5종목 넘게 읽지 못하면 빌드가 실패하고 기존 파일을 지킨다 — 그럴 때는 머리글 이름표를 고치면 된다.
400일이 지난 종목은 파일에서 뺀다.

### `ipo.json` 필드

`id`(38 번호) `name` `market`(KOSPI/KOSDAQ/KONEX) `sector` `code` `uw`(주간사 목록)
`band_lo` `band_hi` `price`(확정 공모가) `amount`(억원) `shares`
`fc_start` `fc_end` `inst_comp` `lockup`(%) `sub_start` `sub_end` `sub_comp` `refund`
`list_date` `open` `close1` `cur` `spac`. 날짜는 `YYYY-MM-DD`, 모르는 값은 키가 없다.

## 개발

```sh
python ipo/build.py                      # 네트워크에서 모아 data/ipo.json 저장
python ipo/build.py --html-dir /tmp/38   # 받아 둔 HTML(k.html, r1.html, nw.html, v-<no>.html)로
python ipo/validate.py                   # 파일 검사
python -m unittest discover -s ipo/tests # 파서 테스트(네트워크 없음)
```

`.github/workflows/ipo-tests.yml` 이 `ipo/` 를 바꾸는 PR 마다 위 테스트와 JS 문법 검사를 돌린다.

일정과 숫자는 늦거나 틀릴 수 있다. 청약 전에는 증권사 공지와 DART 투자설명서를 확인할 것. 투자 권유가 아니다.
