# M7 지표 노트

매그니피센트 7(엔비디아·애플·마이크로소프트·알파벳·아마존·메타·테슬라)을 **같은 틀**로 정리한 지표 노트.

- 배포: https://richroro.github.io/m7/
- 회사별: `/m7/nvda/` `/m7/aapl/` `/m7/msft/` `/m7/googl/` `/m7/amzn/` `/m7/meta/`
  (테슬라는 먼저 만든 [`/tesla-metrics/`](../tesla-metrics/)를 그대로 씁니다)

## 구조 — 왜 파일을 나눴나

앞선 페이지들은 "HTML 한 파일"이 원칙이었다. 여기서는 **엔진을 공유한다.**

```
m7/assets/m7.css   공유 스타일 (tesla-metrics 에서 추출)
m7/assets/m7.js    공유 엔진 — 차트·테마·표·페이지 렌더
m7/<slug>/index.html   회사 데이터(CO 객체) + 위 두 파일 링크
m7/index.html      허브 — 7개 비교
```

6개 페이지에 40KB짜리 엔진을 복사하면 차트 버그 하나를 여섯 곳에서 고쳐야 한다. 외부 라이브러리와
빌드 단계는 여전히 없고, 각 회사 페이지가 직접 들고 있는 건 **그 회사 숫자뿐**이다.

회사 페이지는 마크업을 거의 갖고 있지 않다. `CO` 객체 하나를 두면 엔진이 섹션을 만들어낸다 —
개요 / 매출 구성 / 시그니처 인사이트 / 한국 공급망 / 체크포인트 / 출처. 새 회사를 추가하려면
`CO` 하나를 더 쓰면 된다.

## 이 묶음이 말하려는 것

**하나. M7은 하나의 성격이 아니다.** 영업이익률이 4.6%(테슬라)부터 60.4%(엔비디아)까지 13배 벌어져 있다.
매출 1위(아마존)가 수익성으로는 아래에서 두 번째다. 규모와 수익성의 순서가 반대인 회사들이 한 묶음에 들어 있다.

**둘. 회계연도가 제각각이다.** "2025년 실적"이 회사마다 다른 기간을 가리킨다.

```
엔비디아   FY2026 = 2025년 2월 ~ 2026년 1월   ← 사실상 2025년
애플       FY2025 = 2024년 10월 ~ 2025년 9월
마이크로소프트 FY2026 = 2025년 7월 ~ 2026년 6월   ← 절반이 2025년
알파벳·아마존·메타·테슬라  2025 = 달력 연도
```

같은 해라고 생각하고 나란히 놓으면 틀린다. 허브에 이 표를 따로 뒀다.

**셋. 한국과의 접점은 두 종류다.**

- **직접 납품** — 엔비디아(HBM: SK하이닉스·삼성전자), 애플(OLED: 삼성디스플레이·LG디스플레이,
  카메라: LG이노텍), 테슬라(AI6 칩 전량: 삼성 파운드리)
- **간접 수요** — 마이크로소프트·알파벳·아마존·메타는 부품 공급사를 공시하지 않는다.
  연결은 계약이 아니라 **설비투자 → AI 서버 → HBM·서버 D램 수요** 경로다.

각 페이지에 어디까지가 공시이고 어디부터가 업계 관측인지 적었다. 두 번째 묶음은 동시에 엔비디아의
최대 고객이기도 해서, 같은 돈을 두 번 세지 않게 주의해야 한다.

## 최근 분기

각 페이지 맨 위, 연간 수치 바로 아래에 **가장 최근 발표된 분기**를 따로 뒀다. 연간보다 최대 세 분기 더 최신이라
그림이 꽤 달라지는 곳이 있다.

| 회사 | 분기 | 매출 | 전년 대비 | 영업이익률 |
| --- | --- | --- | --- | --- |
| 아마존 | 26 Q2 | $200.6B | +20% | 13.7% (연간 11.2%) |
| 알파벳 | 26 Q2 | $119.8B | +24% | 34.1% (연간 32.0%) |
| 애플 | FY26 Q3 | $109.4B | +16% | — |
| 엔비디아 | FY27 Q2 | $96.22B | 약 2배 | — |
| 마이크로소프트 | FY26 Q4 | $90.0B | +18% | 45.1% |
| 메타 | 26 Q2 | $60.80B | +28% | **31%** (연간 41.4%) |
| 테슬라 | 26 Q2 | $28.24B | +26% | **1.4%** |

일곱 곳 모두 두 자릿수로 크는데 마진 방향은 갈린다.

- **좋아진 쪽** — 알파벳(클라우드 +82%, 클라우드 영업이익 28억 → 88억), 아마존(AWS 영업이익 비중 57% → 60.4%),
  엔비디아(총마진 71.1% → 75.0%, 데이터센터만 890억)
- **나빠진 쪽** — 메타(43% → 31%, 매출 +28%인데 순이익 −14%), 테슬라(1.4%)
- 공통 원인은 **AI 설비투자**다. 알파벳은 한 분기 설비투자 449억 달러로 잉여현금흐름이 −59억이 됐다.

> 분기 순이익에 일회성 평가이익이 섞인 곳이 있다 — 알파벳 990억, 아마존(앤스로픽 관련) 534억.
> 영업 실적과 구분해서 읽어야 한다. 엔비디아·애플은 분기 영업이익을 담지 않아 영업이익률을 비워 뒀다.

## 검산

부문 합계가 회사 발표 총매출과 맞는지 전부 확인했고, 테스트에 넣었다.

```
아마존   426.3 + 161.9 + 128.7 = 716.9    정확히 일치
메타     198.76 + 2.21 = 200.97           정확히 일치
마이크로소프트 위와 같이 정확히 일치 (FY2026)
애플     209.59+109.16+35.69+33.71+28.02 = 416.17  (발표 416.161, 반올림)
마이크로소프트 139,996+137,791+54,052 = 331,839백만  정확히 일치
엔비디아  75.0 + 6.4 = 81.4                (발표 81.6, 각 수치 반올림)
알파벳    342.721+58.705+1.537 = 402.96    (발표 402.8 — 차이는 헤지 손익 항목)
```

알파벳만 성격이 다르다. 나머지는 반올림 차이지만 알파벳은 **헤지 손익이 별도 항목으로 잡히는
정상적인 공시 구조** 때문이다. 페이지에도 그렇게 적었다.

파생값도 검산한다. 메타 앱 영업이익 = 발표 영업이익 83.28 + 리얼리티랩스 손실 19.19 = 102.47,
19.19 ÷ 102.47 = 18.7%. 알파벳 부문 영업이익 139.404 + 13.910 − 7.515 = 145.80, 본사 비용 약 16.8을
빼면 발표 영업이익 129.04.

헤드리스 크로미움(Playwright)에서 **81개 항목**을 확인했다 — 회사 6곳 × (JS 에러, 부문 합계,
막대 개수, 영업이익률 재계산, 한국 기업 강조, 섹션 구성, 내비, 최근 분기, 보조 문구 색, 모바일)
+ 허브(카드·회계연도 표·최근 분기 표·차트·파생 계산).

그중 하나는 **회귀 테스트**다. `.st .s{color:var(--ink-3)}` 의 우선순위(0,2,0)가 `.up{color:var(--up)}`(0,1,0)를
이겨서, "+26% YoY" 같은 보조 문구가 빨강/파랑 대신 회색으로 나오던 버그가 있었다. 네 개 페이지 전부에 있었고
`.st .s.up` / `.st .s.down` 을 명시해 고쳤다. 계산된 색을 직접 읽어 회색이 아닌지 확인한다.

## 한계

- 주가·밸류에이션은 싣지 않는다. **실적 구조**를 보는 용도다.
- 부문 전년 대비는 회사가 연간 기준으로 일관되게 공개하지 않는 경우 비워 뒀다(마이크로소프트·알파벳·메타).
- 엔비디아 부문 비중만 분기 기준이다. FY2027 1분기부터 5개 → 2개로 공시 구조가 바뀌어 연간과 이어지지 않는다.
- 간접 수요로 묶은 네 회사의 한국 연결은 **계약이 아니라 수요 경로**다. 그대로 실적 상관관계로 읽으면 안 된다.
- 투자 권유가 아니다.
