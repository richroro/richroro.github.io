# 쇼츠 대본

## 쇼츠 1

**훅:** 블로그 글, 아직도 세 번 쓰세요?

블로그 쓰고, 뉴스레터로 줄이고, 유튜브 대본으로 또 고치고. 이제 메모 한 장만 쓰세요. AI가 다섯 채널 원고를 한 번에 만듭니다. 사람은 검토만.

캡션: 메모 한 장 → 5채널 콘텐츠 #콘텐츠자동화 #1인미디어

## 쇼츠 2

**훅:** AI 글쓰기의 진짜 병목은 이겁니다

초안은 10초면 나옵니다. 문제는 검증이에요. AI는 그럴듯한 숫자를 잘 지어냅니다. 그래서 규칙 하나 박아 두세요. 메모에 없는 통계는 쓰지 말 것.

캡션: 초안보다 검증 #AI글쓰기

## 쇼츠 3

**훅:** 서버 0원으로 콘텐츠 공장 만들기

깃허브 페이지에 폴더 하나. 메모를 올리고 클로드에게 '콘텐츠 공장 돌려줘' 한 마디. 블로그 게시, RSS 갱신, 유튜브 대본까지. 서버도 API 키도 필요 없습니다.

캡션: GitHub Pages + Claude Code #자동화
