# 같은 글 세 번 쓰지 마세요 | 메모 한 장으로 5채널 콘텐츠 만드는 AI 파이프라인

**썸네일 문구:** 같은 글 3번 쓰지마

## 설명란

블로그·뉴스레터·유튜브·쇼츠·SNS를 혼자 운영할 때 가장 시간을 잡아먹는 '다시 쓰기'를 AI에게 넘기는 방법. 서버 없이 GitHub Pages + Claude Code로 만든 실제 구조를 보여드립니다.

전체 구조 정리: https://richroro.github.io/blog/one-idea-five-channels/?utm_source=youtube&utm_medium=content-factory&utm_campaign=one-idea-five-channels

> 업로드 시 YouTube '변경되거나 합성된 콘텐츠' 공개 항목을 확인하세요(AI 음성·영상 사용 시).

## 챕터

0:00 같은 얘기, 몇 번 쓰세요?
0:30 진짜 병목은 다시 쓰기
1:30 원본은 메모 한 장
3:00 실제 파이프라인 구조
5:00 채널별 규칙
7:00 AI 초안의 함정
8:30 이번 주 과제

## 대본

### 훅 (0:00)

🎬 화면: 화면을 3분할: 블로그 편집기·뉴스레터 편집기·유튜브 대본 문서에 같은 문장이 복붙되는 타임랩스

이번 주에 같은 얘기, 몇 번 쓰셨어요? 블로그에 한 번, 뉴스레터에 한 번, 유튜브 대본에 또 한 번. 오늘은 이 반복을 통째로 기계에 넘기는 '1인 콘텐츠 공장'을 실제로 만든 과정을 보여드릴게요.

### 문제 (0:30)

🎬 화면: 하루 일정표에 '쓰기' 1시간, '채널별로 다시 쓰기' 3시간 블록이 표시되는 그래픽 (예시 수치임을 자막으로 표기)

혼자 여러 채널을 운영하면 힘든 건 쓰는 게 아니라 다시 쓰는 겁니다. 예를 들어 글 하나에 한 시간 쓰고, 채널별로 고치는 데 세 시간 쓴다면, 진짜 일은 사분의 일뿐인 거죠.

### 핵심 아이디어 (1:30)

🎬 화면: 메모 한 장 아이콘에서 화살표 다섯 개가 블로그·메일·유튜브·쇼츠·SNS 아이콘으로 뻗는 애니메이션

해법은 원본을 하나로 두는 겁니다. 아이디어 메모 한 장. 그리고 채널별 원고는 그 메모에서 변환합니다. 사람은 메모를 쓰고, 결과를 검토하고, 반응을 보고 다음 주제를 고르는 것만 합니다.

### 실제 구조 (3:00)

🎬 화면: ideas 폴더에 메모 업로드 → Claude Code에 '콘텐츠 공장 돌려줘' 입력 → 생성된 블로그 페이지 순서로 화면 녹화

제 사이트에 붙인 구조입니다. ideas 폴더에 마크다운 메모를 올리고 Claude에게 콘텐츠 공장 돌려달라고 하면, 원고를 쓰고 검증을 거쳐 블로그 게시와 RSS 갱신까지 합니다. 서버도 API 키도 없습니다.

### 채널별 규칙 (5:00)

🎬 화면: 채널 카드 다섯 장을 하나씩 뒤집으며 규칙 한 줄씩 표시

여기서 중요한 게 채널별 규칙입니다. 그냥 바꿔 달라고 하면 길이만 다른 같은 글이 나와요. 블로그는 검색으로 온 사람이 끝까지 읽게, 뉴스레터는 편지처럼, 유튜브는 첫 15초 훅과 장면별 화면 지시까지, 쇼츠는 첫 2초 한 줄. 역할을 정해 줘야 채널마다 살아 있는 글이 나옵니다.

### 함정 (7:00)

🎬 화면: '그럴듯한 가짜 통계' 문장에 빨간 줄이 그어지는 화면, 이어서 규칙 문구 확대

만들어 보니 병목은 초안이 아니라 검증이었습니다. AI는 그럴듯한 숫자를 잘 지어내요. 그래서 메모에 없는 통계는 쓰지 말라는 규칙을 넣었고, 처음 몇 주는 결과를 직접 읽으면서 규칙을 고치는 걸 추천합니다.

### 마무리 (8:30)

🎬 화면: 빈 메모 템플릿 세 장이 화면에 놓이고 '이번 주 과제' 자막

이번 주 과제입니다. 쓰고 싶은 주제 세 개를 메모 한 장씩 적어 보세요. 요지 세 줄, 사례 하나면 충분합니다. 전체 구조는 설명란 블로그 링크에 정리해 뒀습니다.
