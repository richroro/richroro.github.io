『AI로 1인 콘텐츠 공장 만들기』를 읽고 실제로 이 사이트에 파이프라인을 만들어 봤다.

요지
- 혼자서 채널을 여러 개 운영하면 '글 쓰는 시간'보다 '같은 얘기를 채널마다 다시 쓰는 시간'이 더 든다.
- 그래서 원본은 아이디어 메모 한 장으로 두고, 채널별 원고는 기계가 변환하게 한다 (One Source, Multi Use).
- 사람이 할 일은 ① 아이디어 메모 쓰기 ② 결과 검토·보정 ③ 반응 보고 다음 아이디어 고르기. 나머지는 자동.

구조 (이 사이트 기준)
- ideas/ 폴더에 마크다운 메모를 올린다 → GitHub Actions 가 Claude API 로 블로그·뉴스레터·유튜브 대본·쇼츠 3개·SNS 글을 한 번에 만든다
- 블로그는 바로 사이트에 게시, RSS(feed.xml)가 갱신된다 → 뉴스레터 도구의 RSS→메일 기능에 물리면 발송까지 이어진다
- 유튜브·쇼츠 대본은 장면별 화면 지시까지 들어 있어 촬영·편집 준비물이 된다
- 비용: 서버 0원(GitHub Pages·Actions 무료 범위), API 사용료만 아이디어당 몇백 원 수준

주의할 점
- AI 초안은 사실 확인이 병목이다. 메모에 없는 통계·인용은 넣지 말라고 규칙을 박아 뒀다.
- 채널마다 문장을 복붙하면 어느 채널에서도 안 읽힌다. 핵심 메시지는 하나, 형식은 채널마다 다르게.
- 처음부터 완전 자동 발행보다, 한동안은 결과를 보고 규칙(프롬프트)을 고치는 게 낫다.

행동 제안: 이번 주에 쓰고 싶은 주제 3개를 메모 한 장씩으로 적어 보기.
