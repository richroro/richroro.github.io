# 둘만의 밤 · 커플 대화 카드

연인끼리 번갈아 한 장씩 뽑는 19세 이상 대화 카드 게임.

- 배포: https://richroro.github.io/couple-cards/
- 소스: `index.html` 한 파일 (외부 스크립트·빌드 없음, 폰트만 Google Fonts)
- 검색 노출 안 함(`noindex`), 메인 페이지·사이트맵에도 넣지 않았다

## 카드

| 단계 | 질문 | 도전 | 성격 |
| --- | --- | --- | --- |
| 설렘 | 28 | 8 | 첫인상, 추억, 가벼운 칭찬 |
| 깊은 | 28 | 7 | 서운함, 사랑의 언어, 앞으로의 약속 |
| 아찔 | 28 | 10 | 끌림, 스킨십 취향, 둘만의 신호. 노골적인 묘사는 없다 |

- **섞어서**는 완전 무작위가 아니라 앞 1/3은 설렘 위주, 가운데는 깊은, 뒤 1/3은 아찔 위주로 점점 올라가게 섞는다.
- 도전 카드는 기본 꺼짐. 문구에 “30초”, “1분”이 있으면 카드에 타이머 버튼이 붙는다.
- 차례는 카드 순번으로 정해진다(홀수 번째는 첫 번째 사람). 이전 카드로 돌아가도 차례가 어긋나지 않는다.

## 기능

- 19세 확인: 태어난 해로 판정(연 나이 19세 이상). 자기 신고 방식이라 실제 본인 인증은 아니다
- 스와이프로 넘기기, 키보드 ←/→/Space
- 하트로 카드 저장 → 저장한 카드만 모아서 하기
- 우리만의 카드: 단계·질문/도전을 골라 직접 추가
- 빠르게 숨기기: 눈 버튼이나 Esc → 평범한 메모 화면(탭 제목도 “메모”). 제목 “메모”를 세 번 빠르게 누르면 돌아온다
- 시작할 때 규칙 시트: 패스 자유, 들은 이야기는 둘만, 술 많이 마셨으면 아찔·도전은 다음에, 신호등(초록/노랑/빨강)
- 어둡게/밝게/기기 설정 테마

모든 기록은 `localStorage`의 `cc.*` 키에만 저장되고 서버로 보내지 않는다. 설정의 “기록 모두 지우기”가 이 키를 전부 지운다.
