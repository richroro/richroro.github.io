# Jev 노트

"Jev가 뭐야?"라는 질문 하나에서 시작한 정리 노트. 새 모델 소개를 그대로 옮기는 대신,
**내 호출량에서 실제로 얼마나 싼지**와 **어디엔 못 쓰는지**까지 적었다.

- 배포: https://richroro.github.io/jev/
- 소스: `index.html` 한 파일 (외부 스크립트·빌드 없음, 구글 폰트만 링크)
- 기준일: 2026-09-21

## 들어 있는 것

| 영역 | 내용 |
| --- | --- |
| 한 줄 정의 | System One이 뭔지, "환각을 못 한다"가 어디까지인지 |
| LLM과 차이 | 출력·생성 방식·지연·과금·실패 모드를 7행으로 대조 |
| 프리미티브 | Choice(≤255) · Score(2~10단계) · Noul 과 각 제약 |
| 비용 계산기 | 월 호출 수·입력 토큰·비교 모델을 넣으면 월 비용, 차액, 배수를 계산 |
| 끼우는 자리 | 게이트 패턴 다이어그램 + 자주 나오는 자리 4개 |
| 한계 | 쓸 자리 5개 / 안 쓸 자리 5개 |
| 팩트·출처 | 회사 발표와 제3자 측정을 구분한 12행 표 |

## 이 페이지가 말하려는 것

**하나. Jev는 더 싼 LLM이 아니다.** 텍스트 생성을 아예 학습하지 않았다. 답장·요약·설명·코드는 못 한다.
할 수 있는 건 미리 정의한 스키마 안에서 값 하나와 확률을 돌려주는 것뿐이다. 그래서 대체가 아니라
LLM 앞단에 붙이는 부품이다.

**둘. "환각을 못 한다"는 형식 얘기다.** 스키마 밖의 값이 나올 수 없다는 뜻이지, 맞는 값이 나온다는 뜻이 아니다.
유효하지만 틀린 선택은 그대로 나온다. 형식 검증이 필요 없어지고, 정답 검증은 그대로 필요하다.

**셋. 400배는 비교 대상에 달렸다.** 회사가 말하는 수백~수천 배는 비싼 프런티어 모델에 긴 출력을 받는 경우다.
값싼 모델에 짧은 답만 받으면 계산기 기본값(월 30만 건 · 입력 395토큰 · 출력 10토큰 · Haiku 4.5 단가)에서
**26.8배**로 줄어든다. 반대쪽에 캐싱·배치 할인을 적용하면 더 줄어든다. 그래서 배수를 하나로 적지 않고
계산기로 만들었다.

**넷. 절감의 실체는 단가가 아니라 건수다.** 앞단 게이트로 쓰면 LLM 호출 자체가 줄어든다. 페이지의
파이프라인 다이어그램이 그 이야기다.

## 계산

```
Jev      = 호출수 × 입력토큰 × $0.042 / 1,000,000          (출력 무과금)
비교 모델 = 호출수 × (입력토큰 × 입력단가 + 출력토큰 × 출력단가) / 1,000,000
배수     = 비교 모델 ÷ Jev
```

검증된 항등식(테스트에 포함):

```
분류 1건, 입력 395토큰
  395 × $0.042 / 1,000,000 = $0.0000166
```

공개된 제3자 벤치마크가 보고한 건당 비용과 같은 값이다. 계산기도 같은 식을 쓰므로
입력 토큰을 395로 두면 호출당 비용이 그 값과 맞는다.

**반영하지 않는 것:** 프롬프트 캐싱 할인, 배치 API 50% 할인, 최소 과금, 무료 한도, 세금.
캐싱·배치는 비교 모델 쪽 비용을 낮추는 방향이라 배수는 계산기 값보다 작아질 수 있다.

> 페이지에도 "확인 필요"로 적어 두었다.

## 색

비용 구성 막대의 입력/출력 2색은 검사를 돌려 통과한 값만 썼다. 밝은 모드(`#2a78d6` / `#eb6834`)와
어두운 모드(`#3987e5` / `#d95926`)를 각각 확인했다 — 명도 대역, 채도 하한, 색각 이상 분리도
(protan ΔE 24.7 / 26.8), 정상 시야 분리도(ΔE 33.6 / 31.8), 배경 대비 모두 통과. 두 칸 사이에는
2px 간격을 두고 금액과 비중을 직접 적어, 색만으로 읽지 않게 했다.

## 검증

헤드리스 크로미움(Playwright)에서 확인했다.

- 기본값(30만 건 · 395토큰 · 10토큰 · Haiku 4.5)에서 Jev $4.98, 비교 모델 $133.50, 차액 $128.52, 26.8배
- 모델 변경(Opus 5) 시 $667.50 · 134배로 재계산
- 벤치마크 항등식($0.0000166)이 화면 문구와 일치
- 0건 · 0토큰 · 빈칸 입력에서 NaN·Infinity 없이 `$0` / `—` 로 떨어지는지
- 막대 두 칸 폭의 합이 전체 폭(2px 간격 제외)과 맞는지
- 데스크톱/모바일(375px) 가로 스크롤 0px, 다크 모드, 테마 토글

## 한계

- 이 페이지 수치의 대부분은 **회사 발표와 언론 보도를 옮긴 것**이고 직접 재현한 값이 아니다.
- Jev는 얼리 액세스(웨이트리스트) 단계라 가격·제약·프리미티브 구성이 바뀔 수 있다.
- 계산기는 단순 곱셈이다. 할인·최소 과금·무료 한도는 넣지 않았다.
- 정확도 비교는 넣지 않았다. 배수만 보고 고를 일이 아니라, 본인 데이터로 정확도를 재봐야 한다.
