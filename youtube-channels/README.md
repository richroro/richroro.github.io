# 채널 공장 — 유튜브 멀티채널 플래너

유튜브 채널 여러 개를 한 화면에서 기획하고 관리하는 정적 웹 앱.
실제 채널 개설은 유튜브에서 직접 해야 하고(구글 로그인 필요), 이 도구는 그 전후의 기획·일정·준비 상황을 정리한다.

- 배포: https://richroro.github.io/youtube-channels/
- 소스: `index.html` 한 파일 (외부 스크립트·빌드 없음, 구글 폰트만 링크)

## 되는 것

| 영역 | 기능 |
| --- | --- |
| 채널 | 이름·핸들(@ 형식·중복 검사)·상태(기획/개설 준비/운영/쉬는 중)·주제·대상·형식·업로드 요일·소속 구글 계정·구독자 목표·색·메모, 예시 템플릿 6종 |
| 주간 업로드 | 채널 업로드 요일 → 날짜별 슬롯. 영상이 배정되지 않은 슬롯 표시, 눌러서 바로 영상 배정, 주 이동 |
| 영상 기획 | 아이디어 → 대본 → 촬영 → 편집 → 예약 → 공개 보드, 채널별 필터, 공개일 지남 표시 |
| 개설 체크리스트 | 채널마다 12단계(브랜드 채널 만들기, 핸들, 프로필·배너 규격, 전화 인증, 권한…) + 구글 계정 하나로 여러 채널 만드는 법 |
| 백업 | JSON 내보내기/불러오기, 채널·영상 CSV(엑셀용 BOM 포함), 모두 지우기 |

## 저장

`localStorage['ytch.v1']` 에 `{ v, channels[], videos[] }` 로 저장한다. 불러올 때와 JSON 가져올 때 모두
`sanitize()` 로 필드 길이·값 범위를 다시 맞추고, 없는 채널을 가리키는 영상은 버린다.
저장이 막힌 브라우저(사생활 보호 모드 등)에서도 화면은 그대로 동작하고, 닫으면 사라진다는 안내를 띄운다.
