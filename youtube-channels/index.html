내 채널

채널마다 주제·대상·업로드 요일을 정해 두면 주간 일정과 영상 기획이 자동으로 따라옵니다.

주간 업로드 일정

채널별 업로드 요일이 슬롯이 됩니다. 영상이 배정되지 않은 슬롯을 눌러 바로 기획을 채우세요.

채널 색 = 업로드 슬롯 빈 슬롯 = 아직 영상 미배정 점선 = 정기 요일 밖에 잡은 영상

영상 기획 보드

아이디어부터 공개까지 단계별로 옮기며 관리합니다. 카드를 누르면 수정할 수 있어요.

개설 체크리스트

채널을 새로 열 때 빠뜨리기 쉬운 것들. 채널마다 따로 체크됩니다.

구글 계정 하나로 채널 여러 개 만드는 법

  1. 유튜브에 로그인한 뒤 오른쪽 위 프로필 사진 → 설정으로 갑니다.
  2. 채널 추가 또는 관리를 누르고 채널 만들기를 고릅니다. (바로 가기)
  3. 채널 이름과 핸들(@)을 정하면 브랜드 계정으로 새 채널이 생깁니다. 기존 채널과 구독자·영상·분석이 모두 따로입니다.
  4. 채널 사이는 다시 로그인할 필요 없이 프로필 사진 → 계정 전환으로 오갑니다.
  5. 함께 운영할 사람이 있으면 유튜브 스튜디오 설정 → 권한에서 채널별로 관리자·편집자를 초대합니다.

짧은 시간에 채널을 한꺼번에 많이 만들면 생성이 잠시 막힐 수 있습니다. 수익 창출(파트너 프로그램) 조건도 채널마다 따로 채워야 하니, 처음엔 2~3개로 시작해 업로드 주기를 지킬 수 있는지 확인한 뒤 늘리는 걸 권합니다.
