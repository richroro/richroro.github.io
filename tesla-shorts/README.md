## 데이터

수치는 [테슬라 지표](../tesla-metrics/)·[테슬라 주주 계산기](../tesla/)의 `DATA` 블록과 같은 값이다(기준일 2026-09-19).
`index.html` 맨 위 `DATA` 에 원값만 두고, −76%·2.94배·+25% 같은 파생값은 `D` 에서 계산해 영상·자막·업로드 문구·계산 표에 똑같이 쓴다.
같은 숫자를 두 군데 손으로 적지 않으려는 것이다.

```
영업이익    28.095 × 5.8% = 1.630B → 0.398B(발표) = −75.6%  (0.244배 ≈ 4분의 1)
설비투자    25.0 ÷ 8.5 = 2.94배
에너지 매출 12.80 ÷ 6.04 = 2.12배
저장장치    46.7 ÷ 31.4 − 1 = +48.7%
인도량      480,126 ÷ 384,122 − 1 = +24.99%
```

새 분기가 나오면 `DATA` 를 고치고 장면 문구(`SCENES`)를 확인하면 된다.

## 만드는 방식

- **그림**: `draw(t)` 가 시간 t 만의 함수라 어느 시점이든 같은 프레임이 나온다. 탐색·표지 PNG·녹화가 모두 이 함수 하나를 쓴다.
- **음악**: `OfflineAudioContext` 로 52초짜리 배경음(킥·하이햇·베이스·패드 + 장면 전환 효과음)을 한 번 합성해 둔다.
  외부 음원이 없으니 저작권 문제 없이 올릴 수 있다. 미리보기 음소거는 스피커 경로만 끄고 녹화 경로는 그대로 둔다.
- **폰트**: 한글 웹폰트는 글자 범위별로 쪼개져 있어 캔버스에 쓰기 전에 실제 글자로 `document.fonts.load` 를 불러야 한다.
  스크립트 본문 텍스트를 그대로 샘플로 넘겨 영상에 쓰는 글자를 전부 받아 온다.
- **저장**: [웹컷](../video-editor/)과 같은 방식. `canvas.captureStream(30)` + 음악 트랙을 `MediaRecorder` 로 실시간 녹화한다.
  그래서 52초가 걸리고, 그동안 탭을 벗어나면 안 된다.

## 검증

헤드리스 크로미움(Playwright)에서 확인했다.

- 9개 장면 프레임을 실제 폰트로 렌더해 겹침·잘림 확인 (이익 장면 수치 겹침, 매출 장면 배지 겹침을 고침)
- 저장 버튼으로 끝까지 녹화 → 받은 파일을 다시 디코딩: **1080×1920, 52.26초**, 오디오 피크 0.88(무음 아님, 클리핑 없음)
- 녹화 파일을 재생하며 9·15·28·45초 프레임을 캡처해 장면 내용이 맞는지 확인
- 재생/일시정지, 장면 칩 이동, 탐색 막대, 대본 표 강조, JS 에러 0건
- 데스크톱·모바일(375px) 가로 스크롤 0px, 다크 모드

> 헤드리스 크로미움(오픈소스 빌드)은 H.264 가 없어 WebM 으로 저장됐다. 크롬·엣지 정식판은 MP4 로 저장된다.

## 한계

- 실시간 녹화라 52초가 걸린다. 모바일 브라우저는 녹화 지원이 들쭉날쭉해서 PC 크롬·엣지를 권한다.
- 나레이션 음성은 넣지 않았다. 브라우저 음성 합성(`speechSynthesis`)은 녹화 스트림에 잡히지 않는다. 대신 대본을 제공한다.
- 로보택시 수치는 회사 공시가 아닌 외부 집계이고, 웨이모(운행 차량)와 테슬라(텍사스 등록 대수)는 기준이 다르다. 영상에도 적었다.
- 투자 권유가 아니다.
