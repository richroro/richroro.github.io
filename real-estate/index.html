신고가 장부

국토교통부 실거래가 파일을 넣으면 단지·면적별 최근 시세와 신고가, 경신 이력을 한 표로 정리합니다. 파일은 브라우저 밖으로 나가지 않습니다.

실거래가 CSV · 엑셀 파일을 여기에 끌어다 놓기 또는 클릭해서 선택 · rt.molit.go.kr 내려받은 파일 그대로 (EUC-KR 자동 인식, 여러 파일 가능)
쓰는 법
  1. 국토교통부 실거래가 공개시스템(rt.molit.go.kr) → 아파트 매매 → 지역·기간 선택 → CSV 또는 엑셀 다운로드
  2. 파일을 위에 놓으면 단지·전용면적별로 최근 시세 · 신고가 · 경신 이력 · 고점 대비가 표로 정리됩니다
  3. 지역·기간이 다른 파일을 여러 개 넣어도 합쳐서 봅니다. 정리표는 CSV로 내려받거나 바로 복사할 수 있습니다
자동 수집 — 안양시(만안구·동안구) 아파트 매매 최근 6년치는 매일 아침 실거래가 API 로 받아 두어서, 파일을 넣지 않아도 바로 보입니다. 위쪽 띠에 갱신 시각이 나옵니다. 다른 지역은 파일을 넣으면 됩니다.
신고가 = 같은 단지·면적에서 이전 어떤 거래보다 높은 값에 체결된 거래. 해제(취소)된 거래는 기본으로 뺍니다. 시세는 최근 N개월 거래의 중위값이고, 거래가 없으면 마지막 거래가를 씁니다.
