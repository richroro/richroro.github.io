# 신고가 장부 — 아파트 시세·신고가 정리

아파트 실거래가를 단지·전용면적별로 묶어 **최근 시세, 신고가, 신고가 경신 이력, 고점 대비 등락**을
한 표로 정리해 주는 정적 웹 도구.

- 배포: https://richroro.github.io/real-estate/
- 소스: `index.html` 한 파일 (엑셀 파일을 넣을 때만 SheetJS 를 CDN 에서 지연 로드)

## 데이터가 들어오는 두 갈래

**1. 자동 수집 (기본)** — 깃허브 액션이 매일 아침 국토교통부 실거래가 API 로 자료를 받아
`data/latest.json` 으로 커밋하고, 페이지가 열릴 때 그 파일을 읽는다. 방문자는 아무것도 하지 않아도 된다.

**2. 파일 넣기** — [실거래가 공개시스템](https://rt.molit.go.kr) 에서 받은 CSV·엑셀을 끌어다 놓으면
그 자료로 바뀐다. EUC-KR/UTF-8 자동 판별, 여러 파일을 넣으면 합치면서 중복 거래는 뺀다.
이렇게 넣은 자료는 브라우저에만 저장되고 다음 방문에도 유지된다(`비우기` 를 누르면 자동 수집 자료로 돌아간다).

`?src=경로` 로 다른 파일을 지정할 수도 있다(같은 사이트 안이거나 CORS 허용 주소).
어느 경우든 파일이 서버로 올라가지 않는다. 계산은 전부 브라우저에서 한다.

## 자동 수집 설정

한 번만 해 두면 된다.

1. [공공데이터포털](https://www.data.go.kr) 에서 **국토교통부_아파트 매매 실거래가 상세 자료** 활용신청 → 인증키 발급
2. 저장소 **Settings → Secrets and variables → Actions → New repository secret** 에
   이름 `DATA_GO_KR_KEY`, 값은 발급받은 인증키(일반 인증키, Decoding 쪽을 넣으면 된다)
3. **Actions → 실거래가 자동 수집 → Run workflow** 로 첫 실행. 이후 매일 06:10 KST 에 자동 실행된다.

키를 넣기 전까지는 예약 실행이 **아무것도 받지 않고 초록색으로 건너뛴다.** 매일 실패 알림이
오면 곧 안 보게 되기 때문이다. 대신 실행 요약에 왜 건너뛰었는지와 등록 방법이 남고,
`Run workflow` 로 직접 돌린 실행은 키가 없으면 그대로 실패한다 — 사람이 결과를 보고 있으니
빨갛게 알려 주는 게 맞다.

키가 없는 동안 페이지는 **가상의 샘플 데이터**로 뜨고, 화면에도 그렇게 적힌다.

수집 지역과 기간은 `regions.json` 에서 바꾼다. 기본값은 **안양시 만안구·동안구, 최근 72개월(6년)** 이다.
6년을 받는 이유는 2021년 고점이 자료 안에 들어와야 신고가와 고점 대비 등락이 뜻을 갖기 때문이다.
최근 1년만 받으면 그 안의 최고가가 전부 신고가로 잡혀서 쓸모가 없다.

```json
{ "months": 72, "regions": [ { "code": "41171", "name": "경기도 안양시 만안구" } ] }
```

`code` 는 법정동코드 앞 5자리(시군구)다. 구가 있는 시는 구 단위 코드를 쓴다(안양시 만안구 41171, 동안구 41173).
`regions.json` 의 `_다른지역_예시` 에 광명·군포·의왕·화성·강남 코드를 넣어 두었으니 붙여 쓰면 된다.
지역 2곳 × 72개월이면 호출 144회이고, 결과 파일은 1~2MB(gzip 300KB) 안팎이다.

대상은 **아파트 매매**다. 오피스텔·연립다세대·전월세는 별도 API 라서 들어 있지 않다.

> 브라우저에서 이 API 를 직접 부르지 않는 이유: 공공데이터포털이 CORS 를 허용하지 않고,
> 정적 페이지에 인증키를 넣으면 그대로 공개된다. 그래서 키는 깃허브 시크릿에 두고
> 액션에서만 호출한다.

## 직접 실행

```
python fetch_molit.py --key "$KEY" --config regions.json --months 12 -o data/latest.json
python fetch_molit.py --key "$KEY" --lawd 11680,11650 --months 6 --format csv -o data/latest.csv
```

표준 라이브러리만 쓴다. 한 달치 호출이 실패해도 나머지는 계속 받고, 실패가 `--max-fail` 을 넘으면
종료코드 1 로 끝난다. 받은 내용이 기존 파일과 같으면 파일을 다시 쓰지 않아서 빈 커밋이 생기지 않는다.

## 정리 기준

| 항목 | 정의 |
| --- | --- |
| 묶음 단위 | 시군구 + 읍면동 + 단지명 + 전용면적(㎡ 반올림) |
| 신고가 | 묶음 안에서 시간순으로 볼 때 이전 모든 거래보다 높은 가격에 체결된 거래 |
| 경신 | 최근 N개월(기본 3) 안에 신고가가 나온 묶음. 경신폭은 직전 신고가 대비 |
| 시세 | 최근 N개월(기본 3) 거래의 중위값, 없으면 마지막 거래가 |
| 고점 대비 | 시세 ÷ 신고가 − 1 |
| 해제 거래 | 해제사유발생일이 있는 거래. 기본으로 제외(토글 가능) |

## 내게 맞는 단지 (추천 탭)

예산·면적·연식·성향을 넣으면 후보를 점수순으로 세워 준다. 예산은 **취득세와 중개보수를 빼고** 따진다
(1주택 기준: 6억 이하 1.1%, 6~9억 누진, 9억 초과 3.3%, 85㎡ 초과 농특세 0.2%, 중개보수는 구간별 상한요율).

점수는 아래 여섯 가지를 후보 안에서 백분위로 매긴 뒤 성향별 가중치로 합한 값이다.

| 항목 | 무엇을 보는가 |
| --- | --- |
| 거래 활발 | 최근 12개월 거래 건수. 팔고 사기 쉬운지 |
| 고점 낙폭 | 시세가 신고가에서 얼마나 내려왔는지 |
| 6개월 흐름 | 최근 6개월 중위값 ÷ 그 이전 6개월 중위값 |
| 가격 안정 | 최근 12개월 거래가의 변동계수. 낮을수록 시세가 또렷하다 |
| 동네 대비 | 같은 읍면동·같은 면적대의 평단가 중위값보다 싼지 |
| 연식 | 준공연도 |

성향은 다섯 가지 가중치 묶음이다 — 균형 있게 / 실거주·안정 우선 / 저평가·낙폭 큰 곳 / 반등·상승 흐름 / 환금성 우선.

**한계가 분명하다.** 실거래가에 없는 것은 전혀 반영하지 못한다. 학군, 역까지 거리, 세대수, 관리비,
전세가율, 재건축·리모델링, 향·조망·층·수리 상태, 지금 매물이 있는지. 집값을 좌우하는 것들이 여기 다 빠져 있으므로
후보를 좁히는 용도로만 쓸 것. 투자 권유가 아니다.

## 읽을 수 있는 형식

| rt.molit.go.kr CSV·엑셀 | 안내문 몇 줄 뒤에 `시군구, 단지명, 전용면적(㎡), 계약년월 …` 헤더가 있는 형식 |
| 실거래가 API 응답 JSON | `aptNm`, `dealAmount`, `excluUseAr`, `dealYear/Month/Day` … |
