# 신고가 장부 — 아파트 시세·신고가 정리

국토교통부 실거래가 파일을 넣으면 단지·전용면적별로 **최근 시세, 신고가, 신고가 경신 이력, 고점 대비 등락**을
한 표로 정리해 주는 정적 웹 도구. 서버가 없고 파일은 브라우저 밖으로 나가지 않는다.

- 배포: https://richroro.github.io/real-estate/
- 소스: `index.html` 한 파일 (엑셀 파일을 넣을 때만 SheetJS를 CDN에서 지연 로드)

## 쓰는 법

1. [실거래가 공개시스템](https://rt.molit.go.kr) → 아파트 매매 → 지역·기간 선택 → CSV 또는 엑셀 다운로드
2. 파일을 페이지에 끌어다 놓는다. EUC-KR/UTF-8 자동 판별, 여러 파일 동시 투입 가능(중복 거래는 제외)
3. 정리표를 CSV로 내려받거나, 표 복사(엑셀용 TSV) · 요약 텍스트 복사(카톡·블로그용)로 쓴다

`data/latest.csv` 를 같은 폴더에 두고 배포하면 페이지가 열릴 때 자동으로 읽는다.
`?src=경로` 로 다른 파일을 지정할 수도 있다(같은 사이트 안이거나 CORS 허용 주소).

## 정리 기준

| 항목 | 정의 |
| --- | --- |
| 묶음 단위 | 시군구 + 읍면동 + 단지명 + 전용면적(㎡ 반올림) |
| 신고가 | 묶음 안에서 시간순으로 볼 때 이전 모든 거래보다 높은 가격에 체결된 거래 |
| 경신 | 최근 N개월(기본 3) 안에 신고가가 나온 묶음. 경신폭은 직전 신고가 대비 |
| 시세 | 최근 N개월(기본 3) 거래의 중위값, 없으면 마지막 거래가 |
| 고점 대비 | 시세 ÷ 신고가 − 1 |
| 해제 거래 | 해제사유발생일이 있는 거래. 기본으로 제외(토글 가능) |

## 자동 수집 (선택)

`fetch_molit.py` 는 공공데이터포털 API로 시군구·월별 자료를 받아 같은 열 구조의 CSV로 저장한다.

```
python fetch_molit.py --key "인증키" --lawd 11680 --from 2025-10 --to 2026-09 \
    --region "서울특별시 강남구" -o data/latest.csv
```

표준 라이브러리만 쓴다. 이 스크립트는 실제 API 키 없이 작성했으므로 첫 실행 때 응답 필드명이 다르면
`fetch_month`/`rows.append` 부분을 맞춰야 할 수 있다.

## 지원하는 입력 형식

- rt.molit.go.kr 아파트 매매 CSV/엑셀 (상단 안내문 몇 줄 뒤에 `시군구, 단지명, 전용면적(㎡), 계약년월, 계약일, 거래금액(만원) …` 헤더가 있는 형식)
- 공공데이터포털 실거래가 API 응답 JSON (`aptNm`, `dealAmount`, `excluUseAr`, `dealYear/Month/Day` …)
