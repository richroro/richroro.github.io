# 키네신 — three.js

[기계 나비](../butterfly/)와 [기계 해마](../seahorse/)는 지어낸 기계였다. 키네신은 **진짜로 있는
기계**다. 세포 안에서 미세소관이라는 레일 위를 두 다리로 걸으며 짐을 나른다. 한 걸음이 8 나노미터,
걸음마다 ATP 한 개.

- 배포: https://richroro.github.io/kinesin/
- 소스: `index.html`(화면·조작) + `assets/kinesin.js`(장면)
- 공용: `/assets/scene-kit.js`(환경광·블룸·배경) + `/assets/three.min.js`(r186, MIT)

## 정직하게 밝혀 둘 것

| | |
| --- | --- |
| **숫자** | 아래 표의 값은 실제로 측정된 것이다. 화면의 계기판(걸음·거리·ATP), 격자 간격, 보폭이 전부 이 값에서 나온다. 코드에서도 `FACTS` 한 곳에만 적어 두고 나머지는 거기서 계산한다. |
| **모양** | 모식도다. 원자 좌표(PDB)를 읽어 그린 구조 모델이 **아니다.** 기구가 어떻게 맞물리는지 보이려고 깎은 형상이다. |
| **속도** | 기본값이 실제의 1/67 로 늦춰져 있다. 실제 속도로는 눈으로 좇을 수 없다. 화면에 늦춘 배수를 함께 적어 둔다. |

## 쓴 숫자

| 값 | 어떻게 쟀나 |
| --- | --- |
| 한 걸음 **8 nm** | 광집게(optical trap)로 한 걸음씩 떼어 내 측정 — Svoboda·Schmidt·Schnapp·Block, *Nature* (1993) |
| 머리가 가는 거리 **16 nm** | 머리 하나에만 형광을 달고 따라간 단분자 측정(FIONA) — Yildiz 외, *Science* (2004) |
| 걸음당 **ATP 1 개** | |
| 원섬유 **13 가닥**, 바깥지름 **25 nm**, 낱개 **4 nm** | 전자현미경 구조 |
| 버티는 힘 **약 5 pN** | 광집게로 끌어당겨 멈춰 세운 힘(흔히 5–7 pN 으로 인용) |
| 속도 **초당 약 800 nm** | 시험관 운동성 측정(초당 100 걸음). 문헌에 따라 0.5–1 µm/s |
| 한 번에 가는 거리 **약 1 µm** | 100 걸음쯤 걷고 레일에서 떨어진다 |

교과서와 리뷰에 실리는 합의값이고, 1차 문헌은 대표적인 것만 적었다.

## 레일 — 미세소관

원섬유 13 가닥을 원통으로 세우고, 가닥마다 α·β 튜불린을 4 nm 씩 번갈아 쌓는다.
이웃 가닥은 12/13 nm 씩 올려 놓는다(3-start 나선).

```js
pos.set(-Math.sin(th) * nm(R_WALL), Math.cos(th) * nm(R_WALL),
        nm(k * MONO + p * FACTS.latticeRise));     // p = 가닥, k = 낱개
```

한 바퀴(13 가닥) 돌면 12 nm, 곧 낱개 세 칸이 밀린다. **3 은 홀수라** α 가 β 와 만나는 줄이 딱
한 줄 생긴다 — 이게 이음매(seam)다. 따로 그리지 않았는데 격자를 그대로 깔았더니 나왔다.

낱개 1,612 개는 `InstancedMesh` 하나로 그린다. 구를 그대로 쓰면 구슬 같아서, 혹 일곱 개를
정해 두고 꼭짓점을 그 방향으로 밀어 단백질 덩어리처럼 만든다(`lumpy`). 법선은 면마다 계산하지
않고 **중심에서 꼭짓점으로 향하는 방향**으로 준다 — 면마다 계산하면 각이 지고, 구면 좌표로
계산하면 이음매에서 밝기가 튄다.

## 걸음 — 손잡이 넘기기

상태는 이것뿐이다. 뒷머리가 딛고 있는 발판 번호, 지금 움직이는 머리, 이번 걸음의 진행도.

```js
{ site: [0, 1], moving: 0, u: 0, steps: 0, side: 1 }
```

한 걸음이 끝나면 움직인 머리를 **두 칸** 앞에 내려놓고, 눈금을 한 칸 당기고, 역할을 바꾼다.

```js
g.site[g.moving] += 2;                 // 두 칸(16 nm) 앞으로
g.site[0] -= 1; g.site[1] -= 1;        // 눈금을 한 칸 당겨 숫자를 작게 유지
g.moving = 1 - g.moving;               // 다음엔 반대쪽 머리
```

머리는 16 nm 를 가지만 두 머리의 한가운데는 8 nm 만 나아간다. 그 한가운데를 화면 원점에
붙들어 두고 **레일 쪽을 뒤로 민다**. 격자의 주기가 8 nm 라서 한 걸음마다 레일을 8 nm 되돌려도
눈에 띄지 않는다 — 그래서 관은 유한한데 걸음은 끝이 없다.

머리는 한 걸음마다 180° 돌아간다(`yaw0[moving] += π`). 자벌레처럼 기는 게 아니라 정말로
번갈아 딛는다는 증거였던 그 회전이다. 두 머리는 색이 달라서 같은 머리가 번갈아 앞서는 게 보인다.

목줄은 머리와 자루를 잇는 구슬 일곱 개다. 매 프레임 머리 뒤쪽 꼭지와 자루 밑동의 위치를 다시
재서 2차 베지에 위에 늘어놓는다. 붙어 있는 쪽은 늘어지고 움직이는 쪽은 팽팽하다.

## 조작

| | |
| --- | --- |
| 시점 | 걸음 · 발 · 전체 |
| 걸음 속도 | 초당 0.1 ~ 6 걸음 (실제의 1/1000 ~ 1/17) |
| 발판 표시 | 키네신이 딛는 β 낱개만 밝게 |
| 한 걸음만 (→) | 한 걸음 가고 멈춘다 |
| H · I · S · Space | 화면 정리 · 설명 · 사진 저장 · 정지 |

`window.__kinesin` 으로 콘솔에서 만질 수 있다.
`setPreset('cell')`, `setView('feet')`, `set('stepsPerSec', 4)`, `stepOnce()`, `reset()`, `readout()`, `info()`.

## 성능

- 삼각형 약 53만(대부분 미세소관), 드로우콜 60 안팎. 낱개 1,612 개가 인스턴스 하나다.
- 모바일에서는 낱개의 면 수를 1/4 로 줄인다.
- 렌더 해상도에 상한(300만 픽셀)을 두고, 60프레임 평균이 34 아래면 한 번만 더 낮춘다.
- 탭이 숨으면 루프를 멈춘다. `prefers-reduced-motion` 이면 멈춘 채로 시작한다 — 한 걸음씩 눌러 볼 수 있다.
