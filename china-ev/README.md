# 중국 전기차 주식 노트

중국 전기차 종목을 볼 때 매번 다시 찾게 되는 것들 — 티커, 인도량, 시장별 차이 — 을 한 페이지에 모은 참고용 노트.

- 배포: https://richroro.github.io/china-ev/
- 소스: `index.html` 한 파일 (외부 스크립트·빌드 없음, 구글 폰트만 링크)

## 들어 있는 것

| 영역 | 내용 |
| --- | --- |
| 시장 온도 | 침투율 65.2%(사상 최고)와 소매 −10.1%(8개월 연속 감소)가 같은 달에 나온 이유 |
| 종목 표 | 7개사 × 홍콩/미국/본토 티커, 2025 연간·2026년 8월 인도량, 열 클릭 정렬 |
| 인도량 비교 | 연간 체급 비교 + 최근 월 인도량 + 전년 대비 증감률(발산형) |
| BYD 해부 | 8월 판매를 내수/해외로 쪼갠 결과 — 헤드라인과 정반대 이야기 |
| 투자 경로 | 홍콩·미국 ADR·본토 A주 비교, **실시간 개장 상태**(한국시간 환산) |
| 체크포인트 | 매월 1일 인도량 발표, 숫자를 볼 때 조심할 것 |

## 이 페이지가 말하려는 것

**하나. 비율이 아니라 대수를 봐라.** 가장 많이 인용되는 "중국 전기차 침투율 65%"는 전기차가 잘 팔려서 나온 수치가
아니다. 같은 달 전기차 소매 판매는 전년 대비 10.1% 줄었다. 내연기관차가 더 빠르게 무너지면서 분모가 작아진 결과다.
침투율 상승 폭은 이미 거의 멈췄다(7월 65.1% → 8월 65.2%).

**둘. 헤드라인은 쪼개 봐야 한다.** "BYD 8월 판매 17.8% 증가"를 지역별로 나누면 중국 내수 −14.3%, 해외 +134.5%다.
해외 비중이 43%까지 올라왔다. BYD를 볼 때 봐야 할 변수가 중국 내수 통계에서 관세·현지 공장·환율로 옮겨갔다는 뜻이다.

**셋. 같은 회사라도 어디서 사느냐가 다른 상품이다.** 지커는 2025년 12월 NYSE에서 상장폐지되어 지리 자회사로
들어갔다. ADR에는 이런 고유 위험이 있고, 표에서 취소선으로 표시해 두었다.

## 데이터

수치는 `index.html` 맨 위 `DATA` 블록 한 곳에 모아뒀다. 인도량은 **매월 1일** 각 사가 직접 발표하므로
그때마다 이 블록만 고치면 표·차트·파생 문구가 전부 따라 움직인다.

| 항목 | 기간 | 출처 |
| --- | --- | --- |
| 업체별 인도량 | 2025 연간 · 2026년 8월 | 각 사 월간 발표 / IR |
| BYD 내수·해외·차종 분해 | 2026년 8월 | BYD 월간 판매 공시 |
| NEV 소매·침투율 | 2026년 4~8월 | 중국승용차협회(CPCA) |
| 지커 상장폐지 | 2025-12-22 | 지리·지커 합병 완료 공시 |
| 티커·상장 시장 | 2026-09 기준 | 각 거래소 종목 정보 |

검증된 항등식(테스트에 포함):

```
BYD 2026년 8월
  250,827 (중국 내수) + 189,466 (해외)  = 440,293
  433,384 (승용)     +   6,909 (상용)  = 440,293
```

같은 달을 두 방향으로 쪼갠 값이 각각 합계와 맞는다. 표에 실린 다른 회사 수치는 연간·월간 발표치를 그대로 옮겼다.

> 샤오미 2025년 연간은 회사가 정확한 수치를 공개하지 않아 **근사치(약 41만대)** 이고, 표와 차트에 "약"으로 표시했다.
> 한 곳(화웨이 HIMA 연합, 2025년 589,107대)은 직접 상장된 주식이 없어 표에서 빼고 각주로만 적었다.

## 시장 개장 상태

거래소별 개장 여부와 한국시간 환산은 `Intl.DateTimeFormat` 의 `timeZone` 으로 계산한다.
브라우저 시계만 쓰고 네트워크를 타지 않는다.

```
현지 시각·요일  ← Intl.DateTimeFormat(tz).formatToParts(now)
UTC 오프셋      ← 그 값을 Date.UTC 로 되돌려 now 와의 차이를 분으로
한국시간 환산   ← (서울 오프셋 − 현지 오프셋) 을 세션 시각에 더함
```

오프셋을 그때그때 구하므로 **서머타임이 자동 반영된다**. 미국 정규장은 여름에 한국시간 22:30~05:00,
겨울에 23:30~06:00으로 바뀌고, 둘 다 테스트로 확인했다. 요일도 시장별 현지 기준이라
한국이 토요일 아침이어도 뉴욕은 금요일 밤으로 올바르게 판정한다.

**공휴일은 반영하지 않는다.** 춘절·국경절 같은 장기 휴장은 증권사 공지를 봐야 한다.

## 검증

헤드리스 크로미움(Playwright)에서 32개 항목을 확인했다.

- BYD 두 가지 분해가 각각 합계와 일치 (지역별, 차종별)
- 파생 문구 자동 계산 (BYD 제외 6사 합계 = BYD의 52%, 해외 비중 43%)
- 표 정렬: 기본(8월 내림차순) → 연간 내림차순 → 오름차순 → YoY 내림차순
- 지커 상장폐지 티커에 취소선이 실제로 적용되는지
- 차트 막대 개수, 발산형 차트의 0 기준선, 툴팁
- **고정 시계로 타임존 검증** — 여름/겨울 미국 개장, 홍콩·본토 세션의 한국시간 환산,
  아시아는 토요일인데 뉴욕은 금요일 밤인 순간의 시장별 요일 판정
- 데스크톱/모바일(375px) 가로 스크롤 0px, 다크 모드

## 색

차트 색은 검사를 돌려 통과한 값만 썼다. 증감률 차트의 발산형 두 색은 색각 이상 분리도·명도 대역·배경 대비를
밝은 모드와 어두운 모드에서 각각 확인했고, 어두운 모드용은 밝은 모드 값을 그대로 쓰면 명도 대역을 벗어나서
따로 골랐다. 증가는 빨강, 감소는 파랑(한국 증시 관례)이되 부호(+/−)를 항상 같이 적어 색만으로 읽지 않게 했다.

## 한계

- 주가는 싣지 않는다. 이 페이지는 **실적 수치와 상장 구조**를 보는 용도다.
- 인도량은 대부분 출고(도매) 기준이라 실제 소매 판매보다 앞서간다.
- NEV 수치에는 플러그인 하이브리드가 섞여 있다. 순수 전기차만 보려면 회사별 차종 구성을 따로 봐야 한다.
- 투자 권유나 세무 자문이 아니다.
