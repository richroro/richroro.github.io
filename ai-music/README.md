# 한 줄 작곡 — 글로 만드는 AI 음악

“비 오는 밤에 듣는 잔잔한 로파이”처럼 한 줄 적으면 장르·조성·템포·악기를 읽어 곡을 짓고,
브라우저가 바로 연주한다. 결과는 WAV(오프라인 렌더)와 MIDI(악기별 트랙)로 저장한다.

- 배포: https://richroro.github.io/ai-music/
- 소스: `index.html` 한 파일 (외부 스크립트·폰트·샘플 없음, 서버 없음)

## 솔직한 정의

학습된 신경망이 아니다. **음악 이론 규칙 + 확률(마르코프 체인·가중 추첨)** 로 작곡하는 엔진이고,
소리는 Web Audio 오실레이터·필터·노이즈로 그 자리에서 합성한다.
Suno·Udio처럼 목소리가 들어간 노래는 못 만든다. 대신 설치·가입·비용이 없고, 같은 문장·씨앗값이면
언제 어디서나 같은 곡이 나오며, MIDI로 가져가 DAW에서 손볼 수 있다.

Magenta.js(MusicRNN) 같은 브라우저용 신경망을 붙이는 것도 검토했지만, 체크포인트를 외부 CDN에서
내려받아야 하고(수십 MB) 그 CDN이 언제 사라질지 모른다. “한 파일, 의존성 0” 원칙을 지키는 쪽을 택했다.

## 구조

`문장 → 설계도(P) → 악보(song) → 이벤트(초) → 소리` 네 단계가 한 방향으로만 흐른다.

```
interpret(prompt, seed, overrides)  →  P   { genre, bpm, root, mode, beats, swing, lead, chordInst, … }
compose(P)                          →  song { sections, chords, lead, chords_tr, bass, pad, arp, drums }   (박 단위)
renderEvents(song)                  →  song.events  [{ time(초), d, p(MIDI), v, tr, inst }]  (스윙·휴먼라이즈 적용)
buildGraph(ctx) + playEvent()       →  실시간 AudioContext 또는 OfflineAudioContext (같은 코드)
```

### 1. 문장 해석 (`LEX`, `interpret`)

- 78개 항목·500여 개 어간의 단서 사전. 각 항목은 어간 목록(`["잔잔","차분","calm",…]`)과 효과(장르 점수, 밝기, 에너지, 템포, 선법, 악기, 플래그)를 갖는다.
  조사·활용을 따로 처리하지 않고 **부분 문자열**로 맞춘다(“잔잔한”, “잔잔하게” 모두 “잔잔”에 걸린다).
- 장르는 점수 최댓값. 동점이면 씨앗값으로 고른다. 단서가 없으면 밝기·에너지로 후보군을 좁힌 뒤 씨앗값으로 고른다.
- 씨앗값은 `FNV-1a(문장) XOR (씨앗번호 × 황금비 상수)`. 같은 문장·번호면 같은 곡, “🎲 다른 버전”은 번호만 올린다.
- 화면의 “→ 「비」 비 오는 날 감성으로…” 목록이 실제로 걸린 단서다. 해석이 이상하면 이 목록에서 어느 단어 탓인지 바로 보인다.

### 2. 작곡 (`compose`)

- **구조**: 목표 길이(짧게 30초 / 보통 70초 / 길게 140초)를 템포·박자로 나눠 마디 수를 구하고, 8마디(짧으면 4마디) 섹션을
  `A B`, `A B A B`, `A B A B C B`… 순으로 채운다. 느린 발라드와 빠른 8비트가 같은 “보통”을 골라도 실제 길이가 비슷하다.
- **화성**: 절·후렴·브리지마다 진행을 한 번 정해 재사용한다(반복되는 절은 같은 코드). 70%는 장르별 진행표에서, 30%(브리지는 60%)는
  마르코프 전이표에서 뽑는다. 섹션 끝은 55% 확률로 딸림화음으로 바꾸고, 팝·발라드는 마지막 마디를 IV→V로 쪼개 종지를 만든다.
  단조의 V는 장르별 확률로 장3화음(화성단음계)이 된다. 7화음 확률도 장르별(재즈 100%, 록 0%).
- **보이싱**: 코드음마다 55~76 사이 옥타브 후보를 전부 조합해 “이전 보이싱에서 가장 적게 움직이는 것”을 고른다(성부 진행).
- **멜로디**: 스케일 도(度) 단위로 다룬다. 장르별 밀도(0~3)에서 리듬 셀을 골라 두 마디 동기를 만들고, 강박은 코드음·약박은 순차 진행을
  선호하는 가중 추첨으로 음높이를 붙인다. 목표 윤곽(아치·상승·하강·물결), 같은 음 세 번 금지, 도약 뒤 되돌아오기 규칙이 붙는다.
  8마디는 `동기 → 이조/재작성 → 동기 → 종지 변형(으뜸음·3음으로 끝나며 길게)` 네 구절이다. 후렴은 음역이 올라가고 밀도가 하나 높다.
- **반주**: 장르별 스타일 키 하나로 분기한다 — 아르페지오(발라드), 블록(팝), 컴핑(재즈, 찰스턴 리듬 추첨), 스트럼, 스탭(EDM 뒷박),
  16분 아르페지오(8비트), 움파(왈츠), 서스테인(시네마틱·앰비언트), 파워코드 8분(록), 로파이 두 번 치기(9음 추가 35%).
- **베이스**: 루트·5도·옥타브·3도·접근음 역할 표기로 패턴을 적고, 워킹 베이스는 `루트 → 3/5도 → 경과음 → 다음 근음의 반음 접근`.
- **드럼**: 16스텝 확률표(3박자는 12스텝). 1.0은 항상, 그 아래는 섹션 강도(절 .85, 후렴 1, 브리지 .75)를 곱해 추첨.
  섹션 마지막 마디는 80% 확률로 필인(스네어→탐, EDM 스네어 롤, 시네마틱 팀파니 롤), 후렴 첫 박 크래시, 아웃트로 첫 박에 마지막 한 방.

### 3. 소리 (`INST`, `DRUM`, `buildGraph`)

- 악기 함수 하나가 음 하나다: `(g, out, f, t, d, v)`. 오실레이터 1~5개 + 게인 ADSR + 필터. 감쇠는 `setTargetAtTime`(지수)로,
  릴리스 뒤 실제로 조용해지는 시각에 `stop()` 해 노드가 남지 않는다.
- 피아노는 삼각파+2배음 사인+약한 톱니를 저역 필터로 뭉치고 **음이 높을수록 빨리 사라지게** 했다. 일렉피아노는 2-오퍼레이터 FM(비율 1:1과 1:14).
  8비트 펄스는 `PeriodicWave`로 25% 듀티를 만든다. 벨·실로폰은 비정수 배음(2.756×, 5.4×)의 사인.
- 그래프: `트랙 게인 → (사이드체인) → 마스터 → [로파이: LPF 3.4k + 계단형 WaveShaper] → DC 차단 HPF → 컴프레서 → 출력`.
  잔향은 씨앗값으로 만든 지수 감쇠 노이즈 임펄스를 `ConvolverNode`에, 딜레이는 점8분 피드백. EDM은 킥마다 패드·아르페지오 게인을 0.22로 눌렀다 0.3초에 되돌린다.
- 실시간 재생은 120ms마다 0.5초 앞까지만 스케줄하는 lookahead 방식, WAV는 같은 `playEvent`를 `OfflineAudioContext`에 전부 스케줄한다.
  일시정지는 `ctx.suspend()`, 탐색은 그 시각 이후 이벤트만 다시 스케줄한다(그 전에 시작된 긴 음은 빠진다).

## 검증

헤드리스 크로미움(Playwright)에서 확인했다. 스크립트는 저장소에 넣지 않았다(테스트 전용 경로가 하드코딩돼 있어서).

- 예시 문장 10개 + 빈 문장·무의미한 문자열·영어·직접 지정(`A 단조`, `가단조`, `Bb`, `120bpm`, `2분`)·오탐 유도(`분위기`, `warm`, `블록`, `팝콘`, `기록`, `오락실`, `결혼`) 등 27개 문장 전부 생성.
  문장당 6~46ms. 음높이 21~108, 길이·세기·시각이 유효하지 않은 음표 0개, 정의되지 않은 드럼 0개
- 멜로디: 강박 음 가운데 코드음 비율 0.90~1.00, 12반음 넘는 도약은 27곡 합쳐 2건(최대 15반음). 이 수치를 잡느라 동기 폭 제한·구절 옥타브 이동·섹션 끝음 유도를 넣었다
- “보통” 길이가 62bpm 로파이 77초, 149bpm 8비트 74초, 143bpm 왈츠 68초로 템포와 무관하게 비슷하다
- 같은 문장·씨앗값 → 이벤트(트랙·음높이·시각) 완전 동일. “다른 버전” → 멜로디가 바뀌고 사용자가 손본 템포·선법은 유지
- WAV: `OfflineAudioContext`로 전곡 렌더해 NaN 0, 정규화 뒤 피크 0.73~0.95. 80초 곡 렌더 14초. 트랙별 솔로 렌더로 RMS·피크·DC를 재서 믹스를 배분했다(8개 장르 20초 발췌의 믹스 크레스트 팩터 3.4~5.8)
- MIDI: 파이썬으로 헤더·트랙 길이·델타타임·노트온/오프 짝·EOT 위치·템포(112bpm→535714µs)·박자·조표(A장조→♯3)를 파싱해 확인
- 재생 → 1.5초 뒤 위치 전진, 일시정지(`suspended`) → 재개 → 진행바 60% 클릭 탐색 → 처음으로
- 템포·선법·길이·드럼 해제 → 설계도에 반영되고 URL 해시에 기록. 그 해시로 새 탭(390px)에서 열면 같은 멜로디 복원, 가로 스크롤 없음
- 콘솔 오류·페이지 예외 0

## 한계

- 목소리·가사는 없다. 리드 악기가 노래 선율을 맡는다.
- 신경망이 아니라서 “쇼팽 같은”을 진짜 쇼팽처럼 만들지는 못한다. 규칙이 아는 만큼만 한다.
- 합성 악기라 실제 녹음 샘플의 질감은 없다. MIDI로 가져가 DAW 악기로 바꾸는 쪽이 낫다.
- 긴 곡의 WAV 렌더는 몇 초 걸리고, 그동안 탭이 살아 있어야 한다.
- 단서 사전에 없는 말은 씨앗값으로 처리된다. 화면의 “이렇게 읽었어요” 목록이 비어 있으면 그 경우다.
