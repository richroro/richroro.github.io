# 종목 3D 지도

[종목 노트](../)의 숫자를 표 대신 공간에 세운다. 좌우·높이·앞뒤에 지표를 하나씩 걸고 돌려 보면,
어느 회사가 어디에 서 있는지 정렬 버튼을 누르지 않고도 보인다.

- 배포: https://richroro.github.io/stocks/map/
- 소스: `index.html`(화면·조작) + `assets/map.js`(장면)
- 공용: `/assets/scene-kit.js`(환경광·블룸·배경 — 기계 나비와 같이 쓴다) + `/assets/three.min.js`

## 데이터를 새로 만들지 않는다

스크리너가 읽는 `/stocks/assets/registry.js` 를 **그대로** 읽는다. 파생 지표의 정의도 스크리너와 같게 맞췄다.

| 축으로 쓸 수 있는 것 | 계산 |
| --- | --- |
| 매출 | `data.rev` (로그 축) |
| 매출 성장률 · 총마진 | `data.growth` · `data.gm` |
| 영업이익률 · 순이익률 | `oi / rev` · `ni / rev` |
| 임직원 · 1인당 매출 | `data.emp` · `rev / emp` (둘 다 로그 축) |
| 업력 | 올해 − `p.est` |
| 최대 부문 비중 | `top.v / top.of` |

레지스트리에 종목이 늘면 이 화면도 같이 는다. 따로 고칠 것이 없다.

## 이상치가 축을 끌고 가지 않게

순이익률처럼 한두 곳이 범위를 통째로 끌고 가는 축이 있다. 적자가 매출의 서른 배인 회사가 하나 있으면
−3,000% 까지 자가 늘어나고, 나머지 서른여섯 곳은 맨 위 한 줄에 뭉쳐 아무것도 안 보인다.

그래서 범위는 **분위수 8~92%** 로 잡는다. 꼬리가 짧으면 그냥 다 담고, 길면 잘라 낸다.
잘린 회사는 버리지 않고 **가장자리에 붙이고 겉면을 뼈대로 바꿔** 표시한다 — 저기 바깥에 있다는 뜻이다.
카드에는 언제나 진짜 숫자가 나온다.

로그 축(매출·임직원·1인당 매출)은 자릿수가 네 단계를 넘으면 눈금을 10배 간격으로만 찍는다.

## 없는 숫자를 숨기지 않는다

영업이익을 따로 공시하지 않는 회사가 절반이다. 고른 축 중 하나라도 미공시면 그 회사는
**왼쪽 '미공시' 선반**에 흐리게 세워 둔다. 조용히 빼면 화면이 깨끗해지지만, 그건 거짓말이다.
축을 바꿀 때마다 선반의 식구가 바뀌는 게 그 자체로 정보다 — 패널 머리에 몇 곳인지 센다.

## 이름표 자리 다툼

37 개가 겹치면 아무것도 못 읽는다. 매 프레임 이름표를 화면 좌표로 투영해서,
**카메라에 가까운 것부터 자리를 잡고 이미 놓인 것과 겹치면 접는다**(지도에 지명 얹는 방식).
짚고 있는 회사는 무슨 일이 있어도 남긴다. 돌리면 가려졌던 이름이 저절로 드러난다.

눈금 글씨는 3D 로 그리지 않고 HTML 로 얹는다. 폰트 파일을 싣지 않아도 또렷하고, 화면 배율을 따라간다.

## 색

기본은 **한국 기업과의 관계**다. 이 사이트에만 있는 축이라 제일 앞에 뒀다.

| | |
| --- | --- |
| 초록 | 공급 — 한국 기업이 납품하는 쪽 |
| 파랑 | 고객 — 한국 기업이 사 오는 쪽 |
| 빨강 | 경쟁 — 같은 시장에서 겨루는 쪽 |
| 회색 | 간접 — 직접 거래는 옅은 쪽 |

묶음(M7·반도체·소프트웨어…)이나 회사 고유색으로도 바꿀 수 있다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 드래그 / 한 손가락 | 시점 회전 |
| 휠 / 두 손가락 | 확대·축소 |
| 점 위에 올리기 | 숫자 카드 |
| 점 누르기 | 그 회사 페이지로 |
| `R` · `L` | 시점 되돌리기 · 이름표 접기 |

`?focus=nvda` 처럼 붙이면 그 회사로 시선을 옮긴 채로 열린다.

## 성능

- 점 37 개 + 격자 + 후처리로 드로우 콜 약 100, 삼각형 약 9천. 노트북에서 60fps 가 나온다.
- 렌더 타깃 픽셀 상한을 두고, 화면이 좁으면 카메라가 알아서 물러선다.
- 탭이 가려지면 멈추고, `prefers-reduced-motion` 이면 자동 회전을 끈 채로 시작한다.
- WebGL2 가 없으면 표로 된 종목 노트로 안내한다.
