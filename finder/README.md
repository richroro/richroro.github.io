# 전 종목 탐색기

미국(나스닥·뉴욕·아메리칸)과 한국(코스피·코스닥·코넥스)에 상장된 주식 **전 종목**을 한 곳에서
찾고 분석하는 페이지.

- 배포: https://richroro.github.io/finder/
- 종목 바로 열기: `/finder/#s=AAPL` · `/finder/#s=005930`
- 심층 노트가 있는 37곳(`/stocks/`, `/m7/`)은 상세 화면에서 그 페이지로 이어진다

## 무엇을 할 수 있나

| 기능 | 내용 |
| --- | --- |
| 검색 | 한글 이름 · 영문 이름 · 티커 · 종목코드 · **초성**(`ㅅㅅㅈㅈ` → 삼성전자). 미국 종목 약 280곳은 한글 이름(`엔비디아`, `구글`)으로도 찾는다 |
| 오늘 시장 | 시장별 상승·하락 종목 수, 중위 등락률, 52주 신고가권 개수, 급등·급락 목록 |
| 업종 흐름 | 업종별 **중위** 등락률 타일(1일·1주·1개월·3개월·1년). 누르면 스크리너가 그 업종으로 걸러진다 |
| 스크리너 | 시장·거래소·업종·시총 규모 필터, 빠른 조건 14개(신고가권, 골든크로스, RSI 과매도, 거래 급증 …), 열 묶음 3개(기본·기술적·점수), CSV 내려받기, ★ 관심 종목 |
| 상세 분석 | 1년 주간 차트, 규칙 기반 요약 문장, 기간 수익률, 52주 범위, 시장 안 백분위 점수 4개, 기술적 지표, 같은 업종 비교, TradingView 인터랙티브 차트·재무제표 |

## 데이터

페이지는 `data/stocks.json` **한 파일**만 읽는다. `build.py` 가 만들고, GitHub Actions
(`.github/workflows/update-finder.yml`)가 화~토 07:30 KST 에 다시 만들어 커밋한다. 인증키는 필요 없다.

| 무엇 | 출처 | 막히면 |
| --- | --- | --- |
| 미국 종목 목록 · 시총 · 업종 · 산업 · 국가 | [rreichel3/US-Stock-Symbols](https://github.com/rreichel3/US-Stock-Symbols) (나스닥 스크리너 일별 사본) | 실패로 끝나고 기존 파일 유지 |
| 미국 1년 일봉(수정 종가) | Yahoo Finance (`yfinance`) | 종목별로 **이전 지표를 그대로 유지** |
| 한국 1년 일봉 · 시총 · 관리종목 여부 | [FinanceData/marcap](https://github.com/FinanceData/marcap) (KRX 전종목 시세) | 실패로 끝나고 기존 파일 유지 |
| 한국 업종 · 주요제품 · 상장연도 | KIND 상장법인목록 | `data/kr_meta.json` 캐시 |
| 원/달러 | Yahoo `KRW=X` | KB금융·신한지주 ADR 과 원주 종가 비율(1 ADR = 1주) |

- 워런트·라이츠·유닛과 우선주 시리즈(`ABR^D` 같은 것)는 미국 목록에서 뺐다. 한국 우선주는 남겼다.
- 종목 수가 5,000 아래로 떨어지면(`--min-rows`) 저장하지 않고 실패한다. 원천이 깨진 날 좋은 파일을 덮지 않기 위해서다.

### 한국 수정 주가

marcap 의 종가는 수정 전 가격이다. 액면분할·병합이 있으면 1년 수익률이 수십 배로 튄다.
**한국은 하루 가격제한폭이 ±30%**라서, 전날 대비 +31%/−31% 를 넘는 변동은 시장이 아니라
주식 수 변경에서 온 것으로 보고 그날의 비율로 이전 가격을 모두 맞춘다(그날 상장주식수 비율과 비슷하면 그쪽을 쓴다).

그래도 **거래량이 0인 채로 호가만 움직이는 코넥스 종목**은 수익률이 수천 % 로 나올 수 있다(실제 데이터다).
그래서 스크리너는 기본으로 "거래가 거의 없는 종목"(20일 평균 거래대금 한국 1억 원·미국 50만 달러 미만)을 숨긴다.
검색에서는 숨기지 않는다.

### 파일 구조

```
{"meta": {built, usAsof, krAsof, fx, fxSrc, counts, cols}, "rows": [[...], ...]}
```

행은 `meta.cols` 순서의 배열이고 시총 순으로 정렬돼 있다. 한 줄에 한 종목이라 커밋 diff 를 읽을 수 있다.

| 열 | 뜻 | 단위 |
| --- | --- | --- |
| `id` `m` `n` `ko` | 티커/종목코드 · 거래소 · 이름 · 한글 별칭(`|` 구분, 첫 번째가 표시명) | |
| `sec` `ind` `cty` `ipo` `prod` | 업종 · 산업 · 국가 · 상장연도 · 주요제품 | |
| `p` `d1` | 종가 · 1일 등락 | 현지 통화 · % |
| `mc` `mcu` | 시가총액 | 현지 통화 백만 · 달러 백만 |
| `r5` `r21` `r63` `r126` `r252` `ytd` | 1주 · 1개월 · 3개월 · 6개월 · 1년 · 연초 이후 수익률 | % |
| `fh` `fl` `h52` `l52` | 52주 고점 대비 · 저점 대비 · 52주 최고 · 최저 | % · 가격 |
| `pm50` `pm200` `up` `x` | 50·200일선 대비 · 50일선>200일선 · 최근 20일 교차(`G`/`D`) | % |
| `rsi` `vol` `mdd` | RSI(14, Wilder) · 63일 변동성(연환산) · 1년 최대낙폭 | · % · % |
| `tv` `vs` | 20일 평균 거래대금 · 5일/60일 거래량 배수 | 현지 통화 백만 · 배 |
| `sm` `st` `ss` `sl` | 모멘텀 · 추세 · 안정성 · 유동성 점수 | 0~100 백분위 |
| `sp` `spl` `sph` | 1년 주간 종가 스파크라인(64단계 문자) · 그 최저 · 최고 | |
| `nd` `asof` `warn` | 일봉 개수 · 마지막 일봉 날짜 · 관리종목/투자주의환기 | |

### 점수

점수는 좋고 나쁨이 아니라 **같은 시장 안의 위치**다. 미국은 미국끼리, 한국은 한국끼리, 일봉이 60개 이상인 종목만 비교한다.

```
모멘텀  = 평균(3개월, 6개월, 1년 수익률의 백분위)
추세    = 평균(50일선 대비, 200일선 대비의 백분위)
안정성  = 평균(변동성 낮은 순 백분위, 최대낙폭 얕은 순 백분위)
유동성  = 20일 평균 거래대금 백분위
```

## 직접 돌리기

```bash
pip install pandas pyarrow numpy yfinance
python finder/build.py                     # 전부 네트워크에서
python finder/build.py --no-us-history     # 미국 일봉 생략 — 이전 지표 유지
python finder/build.py --us-limit 1500     # 미국 일봉은 시총 상위 1,500곳만
python -m http.server  # → http://localhost:8000/finder/
```

`--us-dir`, `--kr-dir` 로 미리 받아 둔 원천 파일(`nasdaq_full_tickers.json` …, `marcap-2026.parquet` …)을 쓸 수 있다.
Actions 탭에서 이 워크플로를 **Run workflow** 로 바로 돌릴 수도 있다.

한글 별칭은 `ko_alias.json` 에 있다. 티커가 바뀌면(예: 배릭 `GOLD`→`B`, 파라마운트 `PARA`→`PSKY`)
엉뚱한 회사에 한글 이름이 붙으므로, 추가할 때는 원천 목록의 회사명과 대조한다.

## 알려진 한계

- **실시간이 아니다.** 전 거래일 종가 기준이다.
- PER·PBR·배당 같은 재무 지표는 전 종목을 키 없이 받을 수 있는 출처가 없어 싣지 않았다. 미국 종목은 상세 화면의 TradingView 재무제표로 본다.
- 상세 화면의 1년 차트는 파일 크기 때문에 **5거래일 간격 주간 종가**다. 일봉은 인터랙티브 차트로 본다.
- 매일 약 3MB 파일을 커밋하므로 저장소가 1년에 100~150MB 커진다. 커지면 Pages 를 Actions 배포로 바꾸고 이 파일을 커밋하지 않는 구조로 옮기면 된다.
