# 증거 은행 — 지금 이 저장소에서 돌고 있는 자동화

일정·숫자는 쓸 때마다 SKILL.md 1번 명령으로 다시 확인한다. 여기와 다르면 저장소가 맞다.
cron은 UTC 기준이라 한국 시간은 +9시간이다.

## 추천 순서 (일반 사장님·직장인이 공감하기 쉬운 순)

### 1. 아파트 실거래가 매일 자동 수집 — `/real-estate/`
- 무엇: 공공데이터 API에서 실거래가를 매일 받아 단지·면적별로 정리, 신고가·고점 대비·전세가율 계산
- 언제: 매일 06:10 KST (`update-real-estate.yml`), 바뀐 게 있을 때만 커밋
- 이야기: "부동산 앱을 매일 열어 보던 일을 코드가 대신 한다" / 서버·DB 없이 깃허브만으로
- 공감 대상: 부동산 중개사무소, 매물 정리하는 블로거, 임장 다니는 직장인
- 대응 서비스: 정해진 시간 자동 수집·정리

### 2. 공모주 일정 하루 3번 자동 갱신 — `/ipo/`
- 무엇: 청약 일정·수요예측 결과를 모아 한 화면 정리, 데이터 검사 후 반영
- 언제: 평일 07:10·12:10·17:10 KST (`update-ipo.yml`)
- 이야기: "여러 사이트를 돌며 확인하던 일정을 한 화면에, 틀린 값은 검사에서 걸러진다"
- 주의: 데이터 자동화 사례로만. 청약 권유 문장 금지
- 대응 서비스: 가격·재고 모니터링(여러 사이트 돌며 확인)과 같은 구조

### 3. 미국·한국 전 종목 데이터 평일 자동 갱신 — `/finder/`
- 무엇: 전 종목 데이터 갱신 + 종목 페이지·사이트맵 자동 생성
- 언제: 화~토 07:30 KST, 미국장 마감 뒤 (`update-finder.yml`, UTC 월~금 22:30)
- 이야기: "수천 개 항목을 매일 갱신하고 페이지까지 자동으로 찍어 낸다" — 규모를 보여 주는 사례
- 대응 서비스: 엑셀/시트 자동 정리의 대규모 버전, 상품 목록·상세페이지 자동 생성

### 4. 테스트가 붙은 자동화 — `ipo-tests.yml`, `finder-tests.yml`
- 이야기: "자동화가 조용히 틀리는 게 제일 무섭다. 그래서 검사를 같이 돌린다" — 신뢰를 파는 글

### 5. 설치 없는 웹 도구 — `/video-editor/`, `/salary-rank/`, `/ai-music/`
- 이야기: "필요한 도구를 하루 만에 웹페이지로" — 자동화 외 개발 역량. 스레드 가벼운 글용

## 쓰지 않는 것
