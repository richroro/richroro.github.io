# 채널별 형식과 주의사항

## 네이버 블로그
- 목적: 검색으로 들어오는 사람에게 "이 사람한테 맡기면 되겠다"
- 제목: 검색어를 앞에 — "엑셀 반복 작업 자동화, 매일 1시간 줄인 방법" 식. 낚시성 제목 금지
- 구성: 이런 분께(3줄) → 손으로 하던 방식 → 만든 것(화면 캡처 자리 표시) → 지금 어떻게 도는지(시간·주기) → 비슷한 일을 하는 분께 → 무료 진단 안내 + 링크
- 본문에 검색어를 자연스럽게 2~4번. 같은 단어 억지 반복 금지
- 태그 10개: 업무자동화, 엑셀자동화, 크롤링, 구글시트 + 사례 업종 키워드
- 이미지 자리는 `[이미지: 무엇을 캡처할지]`로 표시 (실제 페이지 URL 같이)

## 카페 (네이버 카페 등)
- 목적: 그 카페 사람들 고민을 풀어 주는 사람으로 보이기. **홍보 글이 아니다**
- 쓰기 전에 사용자에게 확인할 것: 어떤 카페인지, 홍보·외부링크 규칙, 등급 제한
- 형식 A 정보 글: "○○ 매일 손으로 하시는 분들, 이렇게 하면 줄어요" — 무료로 따라 할 수 있는 방법(함수, 시트 기능, 무료 도구)을 먼저 준다
- 형식 B 답변: 질문 글에 다는 답 2~3개. 방법을 먼저, 끝에 "더 복잡하면 쪽지 주세요" 정도
- 링크는 카페 규칙이 허용할 때만, 서명이나 프로필로
- 같은 글 여러 카페 복붙 금지 — 카페 성격(셀러, 사무직, 부동산 등)에 맞게 다시 쓴다

## 스레드 (Threads)
- 글 하나 500자 이하. 글자 수를 꼭 세어서 표기
- 첫 줄이 전부다: 숫자나 장면 ("새벽 6시 10분, 내가 자는 동안 코드가 실거래가를 모은다")
- 시리즈로 꾸준히: "자동화 일지 #n" — 만든 것, 막힌 것, 고친 것. 실패담이 반응이 좋다
- 링크는 본문 말고 첫 댓글에
- 해시태그는 0~1개 (주제 태그 하나)

## 채용·외주 사이트
공통: 사이트마다 양식·글자 수 제한이 다르니, 사용자가 화면의 항목 이름을 알려 주면 거기에 맞춘다. 모르면 아래 기본 구성으로.

- 크몽·숨고 (서비스/고수 프로필)
  - 서비스 제목: 결과 중심 — "매일 하는 엑셀·사이트 확인, 자동으로 돌게 만들어 드립니다"
  - 설명: 이런 일 가능(목록) → 진행 방식(무료 진단 → 견적 → 1~2주 → 소스 제공) → 실제 돌고 있는 사례 링크 → 할 수 없는 일(약관 위반 크롤링, 로그인 우회 등)
  - 가격은 랜딩 페이지 값과 맞춘다
- 위시켓·프리모아 (포트폴리오)
  - 사례당: 프로젝트명 / 문제 / 사용 기술(Python, GitHub Actions, 공공데이터 API 등 저장소에서 확인된 것만) / 결과 / 링크
- 원티드·리멤버·링크드인 (경력 프로필)
  - 헤드라인: "업무 자동화 · 데이터 수집 파이프라인"
  - 소개 3줄 + 대표 사례 3개를 성과 문장으로 ("공공 API → 매일 06:10 자동 수집, 6년치 실거래 정리")
  - 링크드인은 영어 버전도 같이 만들지 사용자에게 묻는다
