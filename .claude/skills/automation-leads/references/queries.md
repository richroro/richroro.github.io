# 검색어 모음

`WebSearch`에서 조합해서 쓴다. 최근 글 위주로 보려면 연도/월을 붙인다 (예: `2026년 10월`).

## 고통 표현 (한국어)
- "엑셀 복붙" 매일
- "매일 아침" 엑셀 정리 귀찮
- "수작업으로" 정리 하는데 자동화
- "일일이" 확인 하는데 방법
- "매크로" 만들 수 있나요 엑셀
- "자동으로" 카톡 보내는 방법 사장님
- 구글시트 자동 업데이트 방법 질문
- 여러 엑셀 파일 합치기 매주
- 스마트스토어 주문 엑셀 정리 자동
- 쿠팡 경쟁사 가격 매일 확인
- 재고 확인 매일 사이트 들어가서
- 세금계산서 엑셀 정리 반복
- 근태 엑셀 취합 매달
- 보고서 매주 같은 작업 반복

## 지불 의사가 드러나는 표현
- 크몽 엑셀 자동화 요청
- 숨고 업무 자동화 견적
- 위시켓 크롤링 자동화 프로젝트
- "외주 맡기면 얼마" 자동화
- "개발자 구합니다" 엑셀 자동화
- 데이터 입력 알바 모집 엑셀 (→ 자동화 대체 제안)
