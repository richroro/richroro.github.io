# 편집 규칙집

편집할 때마다 이 문서를 처음부터 읽고 따른다. 수치는 `rules.json` 에 있고, 이 문서는 그 수치의 뜻과
**판단 기준**(무엇을 지우고, 무엇을 강조하고, 언제 자료화면을 넣는지)을 적는다.
둘을 고칠 때는 항상 같이 고치고, 맨 아래 **피드백 반영 기록**에 한 줄 남긴다.

- 현재 상태: **기본 규칙** (정보 전달형 한국어 토킹헤드 유튜브 스타일). 레퍼런스 영상을 분석하면 0장과 각 장을 그 결과로 바꾼다.

## 1. 교정 대본 원칙 — 가장 중요

교정은 **지우기만** 한다. 말을 바꾸거나 순서를 바꾸거나 새 문장을 만들지 않는다. 말투·어미·사투리·농담은 그대로 둔다.

지운다:
- 단독 군말: 어, 음, 으, 아, 에, 그, 저, 뭐 (문장 안에서 뜻이 있으면 남김: "그 회사", "저는", "뭐가 문제냐면")
- 같은 말을 다시 한 곳: 앞의 것을 지우고 뒤의 완성된 쪽을 남긴다 ("먼저 계좌를 / 먼저 계좌를 만들어야" → 뒤만)
- 말하다 끊고 다시 시작한 앞부분 ("계 / 계좌는", "이게 / 이건 그러니까" → 다시 시작한 쪽만)
- 문장 전체를 다시 말한 경우: 더 매끄러운 쪽 하나만 (보통 뒤)
- 촬영 준비·확인 말: "다시 할게", "잠깐만", "이거 찍히고 있나" 같은 것
- 0.35초 넘는 쉼은 프로그램이 자동으로 0.2초로 줄인다 (따로 지울 필요 없음)

지우지 않는다:
- 일부러 반복한 강조 ("진짜 진짜 중요해요", "절대, 절대")
- 웃음·감탄이 말투의 일부일 때
- 애매하면 남긴다

자막 표기(`fix`): 받아쓰기가 틀린 글자만 고친다 — 맞춤법, 띄어쓰기, 고유명사, 숫자 표기("이십 영업일" → "20영업일").
들리는 말과 다른 단어로 바꾸지 않는다. 소리는 고치지 못하므로, 들리는 대로가 기준이다.

## 2. 컷

- 점프 컷: 교정 대본에서 지운 곳과 긴 쉼마다 자른다.
- 낱말 앞 여유 0.06초, 뒤 여유 0.14초 (말끝이 잘리지 않게). 영상 맨 앞 0.12초, 맨 끝 0.5초.
- 컷 경계는 0.01초 페이드로 소리 튐을 막는다.

## 3. 화면 확대

- 점프 컷마다 100% ↔ 110% 를 번갈아 써서 컷이 튀어 보이지 않게 한다 (1.2초보다 짧은 조각은 직전 배율 유지).
- 강조 순간에는 118% 로 확 당겼다가, 강조 시간이 끝나면 원래 배율로 돌아온다.
- 확대 중심은 가로 50%, 세로 42% (얼굴이 화면 위쪽에 오도록).

## 4. 자막

- 글꼴 Pretendard Bold, 크기 화면 높이의 6.4%, 흰 글자 + 검은 외곽선(글자 크기의 13%), 화면 아래 7.5% 위.
- 한 줄만. 가로 영상 17자, 세로 영상 13자 이내 (띄어쓰기 빼고). 넘으면 낱말 경계에서 길이가 고르게 나눈다.
- 0.3초 넘게 쉬거나 문장이 끝나면 줄을 바꾼다. 마침표·쉼표는 찍지 않는다 (물음표·느낌표는 둠).
- 강조 낱말은 자막 안에서 노란색(#FFD400).

## 5. 강조 자막

- 언제: 핵심 숫자, 결론, 경고·주의, 영상 제목과 직결된 말. **1분에 2~4개**. 연달아 붙이지 않는다 (최소 8초 간격).
- 모양: 화면 위쪽, Pretendard Black, 노란 글자 + 검은 외곽선, 커졌다 작아지는 팝 효과, 1.6초.
- 문구: 말한 내용을 짧게 줄인 것 (10자 안팎). 말하지 않은 내용을 덧붙이지 않는다.
- 같이 들어가는 것: 팝 효과음 + 118% 확대.

## 6. 효과음

| 순간 | 효과음 |
| --- | --- |
| 강조 자막 | pop |
| 자료화면 등장 | whoosh |
| 인트로 제목 | ding |

크기는 말소리보다 12dB 작게. 효과음은 코드로 합성한 것만 쓴다 (저작권 문제 없음).

## 7. 배경음

- 사용자가 드라이브 `bgm` 폴더에 음악을 넣었으면 그걸 쓰고, 없으면 합성한 잔잔한 배경음.
- 말 쉴 때 말소리보다 17dB 작게, 말하는 동안은 8dB 더 줄인다 (덕킹). 처음 1초 페이드 인, 끝 2초 페이드 아웃.

## 8. 자료화면

- 언제: 말한 내용에 **확인 가능한 구체적 사실**이 나올 때 — 정책·제도 이름, 기사화된 사건, 공식 수치, 서비스·사이트 이름. 1분에 1~3개, 2~5초.
- 찾는 법: WebSearch 로 공식 사이트(정부·기관·회사 공식 페이지)를 먼저, 없으면 주요 언론 기사를 찾는다. WebFetch 로 실제 문구를 확인한다.
- 넣는 법:
  1. 페이지 캡처가 되면(`url`) 캡처를 쓴다.
  2. 캡처가 막히면 `card` — 확인한 기사 제목/공식 문구를 **글자 그대로** 옮긴다 (`news`: 매체·날짜·제목, `site`: 기관·주소·핵심 문구, `stat`: 숫자 하나).
  3. 확인하지 못한 내용은 넣지 않는다. 기사 제목·수치를 지어내지 않는다.
  4. WebFetch 가 네트워크 정책에 막히면, WebSearch 결과에 실제로 나온 제목·주소·요약 문장만 쓴다.
     매체 이름을 확실히 모르면 도메인으로 적는다 (`출처: news.example.co.kr 「기사 제목」`).
- 출처: 오른쪽 아래에 작게 `출처: 매체/기관명 (날짜)`.
- 모양: 흐린 원본 위에 자료를 가운데, 4% 천천히 확대, 0.15초 페이드.

## 9. 인트로 · 아웃트로

- 인트로: 첫 2.6초 동안 화면 위쪽에 영상 제목(Pretendard Black) + ding. 제목은 영상 내용으로 짧게 (15자 안팎).
- 아웃트로: 마지막 0.6초 화면·소리 페이드 아웃. 따로 아웃트로 화면은 넣지 않는다.

## 10. 검수 기준

완성 후 매번 확인하고, 고친 다음 보고한다.
- 자막 오타: `review.py` 가 다시 받아쓴 소리와 다른 줄 + 자막 전체를 눈으로 한 번 읽기.
- 소리 끊김: 자막이 떠 있는데 0.4초 넘게 무음, 낱말 중간을 자른 컷, 클리핑.
- 화면 멈춤: 자료화면이 아닌데 2.5초 넘게 변화 없음, 검은 화면.
- 개인정보: 전화번호·이메일·주민번호·카드·계좌번호는 자동으로 흐림. **이름·주소·알림창·메신저·다른 사람 얼굴·차량 번호판·택배 송장**은 장면 모음을 눈으로 보고 직접 흐림 처리.
