# 기계 해마 — three.js

[기계 나비](../butterfly/)를 만들고 나서 같은 재료로 다른 기구를 짜 본 것.
나비가 가로로 퍼지는 물건이라면 해마는 세로로 선다. 날갯짓 대신 **말리는 꼬리**와
**물결치는 등지느러미**가 움직임을 맡는다. 모델링 파일도 텍스처 이미지도 없다.

- 배포: https://richroro.github.io/seahorse/
- 소스: `index.html`(화면·조작) + `assets/seahorse.js`(장면)
- 공용: `/assets/scene-kit.js`(환경광·블룸·배경) + `/assets/three.min.js`(r186, MIT)

## 뼈대 — 마디 서른 개

머리 아래로 `THREE.Group` 서른 개를 부모–자식으로 잇는다. 자식은 부모보다 `SEG_LEN(i)` 만큼
아래에 놓이므로, 부모를 돌리면 그 아래 전부가 따라 돈다. 마디마다 길이와 굵기가 조금씩 줄고
육각 고리·속대·돌기 셋·관절 핀이 한 벌씩 붙는다.

```js
const N = 30;
const SEG_LEN = (i) => 0.2  * (1 - 0.55 * (i / N));
const RING_R  = (i) => 0.27 * Math.pow(1 - 0.8 * (i / N), 0.9) + 0.02;
```

꼬리를 감는 데 쓰는 값은 관절 하나당 **몇 도**뿐이다. 아래로 갈수록 더 꺾이도록
`smooth(9, 24, i)` 로 가중치를 주면 사슬 전체가 저절로 소용돌이가 된다.

```js
j.rotation.x = restAngle(i) - curl * smooth(9, 24, i) + (몸을 훑고 내려가는 잔물결);
```

`curl` 이 0.06 이면 거의 곧게 서고 0.5 를 넘으면 한 바퀴 반을 돈다.
배에 달린 톱니 두 개도 따로 돌지 않고 같은 `curl` 에서 각도를 받는다 — 꼬리가 감긴 만큼 감긴다.

## 지느러미 — 갈비와 막

등지느러미는 마디 4~14 에 갈비 열한 대를 세우고, **한 박자씩 늦게** 흔든다.
그 시차 때문에 물결이 꼬리 쪽으로 흘러가는 것처럼 보인다.

```js
const ph = t * 8.6 - k * 0.95;      // k 는 갈비 번호
holder.rotation.y = Math.sin(ph) * 0.36;
```

갈비 사이를 잇는 막은 **미리 만들어 둔 모양이 없다.** 매 프레임 갈비의 밑동과 끝을
월드 좌표로 재서 몸통 좌표로 되돌리고, 그 두 점을 띠 버퍼에 그대로 써넣는다.
관절이 어떻게 꺾이든 막이 따라붙는다.

```js
ribs[k].tip.getWorldPosition(v); body.worldToLocal(v);
arr[k * 6 + 3] = v.x; …                       // DynamicDrawUsage
```

막의 바깥선은 알파 지도로 깎는다. `u` 를 갈비 번호, `v` 를 밑동(0)→갈비 끝(1)으로 두고
갈비 사이마다 한 번씩 패이게 그려 두면, 막은 부챗살 사이에서 오목해지고 갈비 끝만 밖으로 나온다.
뿌리 쪽은 아예 비워서 몸통 위에 천처럼 덮이지 않게 했다.

## 빛과 질감

| 항목 | 내용 |
| --- | --- |
| 무지갯빛 | 막에 박막 간섭(iridescence). 캔버스에 그린 두께 지도가 자리마다 색을 가른다 |
| 환경광 | 정방형도법 HDR 환경맵을 픽셀 단위로 구워(`PMREMGenerator`) 금속의 하이라이트 모양을 정한다 |
| 물 | 수면에서 내려오는 빛기둥 일곱 장 + 올라가다 사라지고 아래에서 다시 오르는 거품. 거품은 텍스처 없이 점 하나를 셰이더로 깎는다 |
| 빛 번짐 | 밝은 곳만 뽑아 다섯 단계로 흐린 뒤 합치고 ACES 톤매핑·비네팅·그레인·색수차를 한 패스에 입힌다 |

금속의 `roughness` 는 적은 값 그대로 들어가지 않는다. 거칠기 지도의 평균이 0.5 라
three 가 곱하면서 절반으로 줄기 때문에, 재질마다 `userData.roughK` 배수를 곱해 보정한다.

## 조작

| | |
| --- | --- |
| 드래그 / 휠·핀치 | 돌리기 / 확대 |
| 꼬리 감기 | 곧게 선 자세 ↔ 한 바퀴 반 |
| 지느러미 | 물결 속도 (0 이면 멈춘다) |
| H · I · S · R · Space | 화면 정리 · 설명 · 사진 저장 · 시점 초기화 · 정지 |

`window.__seahorse` 로 콘솔에서 만질 수 있다.
`setPreset('steel')`, `set('curl', 0.4)`, `setView(theta, phi, dist)`, `setTime(t)`, `info()`.

## 성능

- 삼각형 약 1만 개, 드로우콜 260 안팎. 관절·갈비는 형상을 공유하고 재질은 일곱 개뿐이다.
- 렌더 해상도에 상한(300만 픽셀)을 두고, 60프레임 평균이 34 아래로 떨어지면 한 번만 더 낮춘다.
- 탭이 숨으면 루프를 멈춘다. `prefers-reduced-motion` 이면 헤엄과 자동 회전을 끄고 자세만 보여 준다.
