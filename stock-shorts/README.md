## 데이터

**주가**는 [전 종목 탐색기](../finder/)가 매일 받아 오는 `finder/data/stocks.json`(빌드 2026-09-26)에서 옮겼다.
미국은 9/25, 한국은 추석 연휴 전 마지막 거래일 9/23 종가다. 1년 차트는 같은 파일의 주간 종가 부호(`sp`)를 그대로 풀어 그린다.
한국 종목 시가총액은 파일에 적힌 원/달러(1,355.28원)로 환산한 값이다.

**소식**은 여러 매체가 같은 내용을 전한 것만 썼고, 출처 링크를 페이지에 달았다.

**파생값**(배수·환산 시총·고점 대비)은 `D` 와 계산 표에서 원값으로 다시 계산한다.

## 검증

헤드리스 크로미움(Playwright)에서 확인했다.

- 페이지 `DATA` 의 14종목 × 필드 98개가 `finder/data/stocks.json` 과 **전부 일치**, 기준일·환율도 일치
- 8개 장면 프레임을 실제 폰트로 렌더해 겹침·잘림 확인 (메모리 막대 라벨 넘침을 고침)
- 저장 버튼으로 끝까지 녹화 → 받은 파일 다시 디코딩: **1080×1920, 50.17초**, 오디오 피크 0.81
- 재생/일시정지, 장면 이동, 탐색, 대본 표 강조, JS 에러 0건, 데스크톱·모바일(375px) 가로 스크롤 0px

## 새 주에 다시 만들려면

1. `DATA.stocks` 값을 그 주의 `finder/data/stocks.json` 에서 다시 옮기고 `usAsof`/`krAsof`/`fx` 를 고친다.
2. 소식이 바뀌면 `DATA.news`, 각 장면의 `facts`·`cap`, `SOURCES` 를 고친다.
3. 위 데이터 대조 검사를 다시 돌린다.

## 한계

- 소식은 시점이 박힌 내용이라 자동 갱신하지 않는다. 주가만 바꾸고 소식을 그대로 두면 틀린 영상이 된다.
- 실적 발표일은 예정일이라 바뀔 수 있다. 영상에도 적었다.
- 1개월 수익률은 21거래일 기준이라 달력상 ‘9월 한 달’과 조금 다르다.
- 실시간 녹화라 50초가 걸리고, 헤드리스 크로미움에서는 WebM, 크롬·엣지 정식판에서는 MP4 로 저장된다.
