## What failed / workarounds
- natv.go.kr / www.assembly.go.kr / likms / record.assembly.go.kr: timeouts at first (000). w3.assembly.go.kr and m.webcast.go.kr worked with retries; the agent proxy resets ~30 % of connections, so every fetch was retried.
- YouTube: searches and some metadata worked at first. After ~300 parallel metadata calls, YouTube answered "Sign in to confirm you're not a bot" / HTTP 429 and redirected to google.com/sorry; video data returned 403 even when extraction succeeded. A bgutil PO-token provider was tried briefly, then dropped on the orchestrator's instruction (no cookie/impersonation/proxy workarounds). Note: these NATV clips also carry auto-dubbed English/Indonesian audio tracks, so if YouTube is ever used, select `language=ko`.
- www.usgs.gov returns 403 to curl's default UA. A normal browser User-Agent works, and the files are on S3.
- No YouTube heatmaps were collected for any item.
