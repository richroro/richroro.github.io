# 쇼츠 리믹스 — 제목+자막 쇼츠 만들기

여러 영상에서 쓸 장면만 잘라 이어 붙이고, **위 큰 제목 · 가운데 영상 · 아래 자막** 틀에 얹어
9:16 쇼츠로 저장하는 정적 웹 앱. 요즘 쇼츠에서 흔한 두 가지 틀을 바로 고를 수 있다.

| 스타일 | 생김새 |
| --- | --- |
| 화이트 채널형 | 흰 배경, 왼쪽 위 채널 로고·이름, 둥근 글꼴 제목, 영상 아래 검은 자막 |
| 블랙 레벨형 | 검은 배경, 꽉 찬 흰 제목, 영상 위 `LV.1 LV.2 LV.3`(지금 단계만 초록), 영상 속 대사 자막, 노란 아래 자막, 회색 작은 글씨(노래 제목) |
| 카드형 | 크림 배경, 둥근 모서리 영상 |

- 배포: https://richroro.github.io/shorts/
- 소스: `index.html` 한 파일 (외부 스크립트·빌드 없음, 구글 폰트만 링크)
- 파일은 서버로 올리지 않는다. `objectURL` 로만 열고, 결과는 화면 녹화 방식으로 만든다.

## 되는 것

| 영역 | 기능 |
| --- | --- |
| 불러오기 | 영상·사진 여러 개 한 번에, 끌어다 놓기 |
| 장면 고르기 | 구간 바의 양 끝 손잡이 끌기, 빈 곳 눌러 장면 보기, "지금 장면을 시작/끝으로", 재생 위치에서 분할(<kbd>S</kbd>), 복제(같은 영상의 다른 장면), 순서 바꾸기, 삭제 후 되돌리기 |
| 클립마다 | 아래 자막, 영상 속 대사 자막, 단계(LV), 출처 표시, 꽉 채우기/전체 보이기(흐린 배경), 확대·위치(미리보기에서 끌기·휠), 소리 크기 |
| 템플릿 | 위 제목(영상 내내 고정), `*강조*` 문법, 단계 이름, 아래 작은 글씨, 채널 이름·로고 이미지, 글꼴 6종, 색 6가지, 외곽선, 크기·영상 위치/높이 — 브라우저에 자동 저장 |
| 소리 | 원본 소리 크기, 배경음악(반복·시작 지점·끝 1.5초 페이드) |
| 저장 | 1080×1920 / 720×1280, 30/60fps. 크롬·엣지는 MP4, 그 밖은 WebM |

## 구조

- 상태는 `S`(템플릿 `tpl` + 클립 목록 + 소리)와 `UI`(재생 위치·현재/선택 클립)로 나뉜다.
- 그리기 좌표계는 늘 1080×1920. 미리보기 캔버스는 720 폭, 저장할 때만 저장 해상도로 키우고 배율로 맞춘다.
  한 장면은 `compose()` 하나가 그린다. 스타일 고르기의 작은 미리보기도 같은 함수로 그린다.
- 클립마다 `<video>` 요소를 따로 만든다. 다음 클립 요소를 미리 시작점에 맞춰 두어(`preseekNext`) 클립이
  바뀔 때 멈칫하지 않고, 같은 영상을 쪼갠 클립끼리도 탐색 위치가 엉키지 않는다.
- 재생 시계는 **지금 클립 영상의 `currentTime`** 에서 읽는다(사진 클립만 rAF 경과 시간). 디코딩이 밀려도
  화면·소리·자막이 서로 어긋나지 않는다.
- 소리는 `요소 → 요소별 Gain → mix → [스피커, MediaStreamDestination]`. 녹화본에는 뒤쪽 갈래가 들어간다.

## 만들면서 걸린 것

| 증상 | 원인 | 대응 |
| --- | --- | --- |
| 자막 일부 글자만 다른 글꼴로 그려짐 | 구글 폰트의 한글 글꼴은 글자 범위별 조각으로 나뉘어 있고, 캔버스는 안 받아진 조각을 대체 글꼴로 그린다 | 쓰는 글자를 모아 `document.fonts.load(font, text)` 로 미리 받고 다시 그림. 저장 직전에도 한 번 기다림 |
| 영상을 넣었는데 회색 상자만 보임 | 첫 프레임이 준비되기 전에 그리고 `loadeddata` 를 놓침 | 준비 안 된 프레임이면 `draw()` 가 false 를 돌려 다음 프레임에 다시 시도 |
| 미리보기에 놓으면 클립이 두 번 들어감 | 상자와 문서 둘 다 `drop` 을 받음 | 문서 한 곳에서만 받음 |
| 블랙 스타일에서 `*강조*` 가 안 보임 | 강조색과 자막색이 같은 노랑 | 강조색을 단계 강조와 같은 초록으로 |

## 검증

헤드리스 크로미움(Playwright)에서 ffmpeg 로 만든 시험 영상을 넣어 확인했다.

- 영상 2개·사진 1장 불러오기, 썸네일, 길이 인식
- 블랙 레벨형 선택 → 단계 `LV.1, LV.2, LV.3` 채워지고 클립에 순서대로 배정
- 끝 손잡이를 50% 로 끌기 → 구간 0~4초, 2초 지점 <kbd>S</kbd> 분할 → 0~2 / 2~4초
- 재생 중 클립 경계 통과, 사진 클립 "전체 보이기" 흐린 배경, 복제·삭제·되돌리기
- 390px 폭 화면에서 가로 넘침 없음
- 저장: 720×1280, 타임라인 10.0초 → 파일 10.2초, 장면 순서·자막·단계 강조 전환 확인, 오디오 평균 −21dB(무음 아님)

## 한계

- 실시간 녹화라 영상 길이만큼 시간이 걸리고, 그동안 탭을 벗어나면 안 된다.
- 유튜브 링크에서 바로 가져오기는 안 된다(브라우저 보안상 불가). 영상 파일을 먼저 기기에 받아 둬야 한다.
- 아이폰 HEVC(.mov)는 PC 크롬에서 안 열릴 수 있다. 그럴 땐 MP4(H.264)로 바꿔 넣는다.
- 탭을 닫으면 클립 편집 내용은 사라진다(템플릿만 저장됨).
- 남의 영상은 허락을 받았거나 인용 범위 안에서 쓰고 출처를 표시해야 한다.
