# 업로드 전 검토표 (조회수 10만+ 쇼츠 형식 기준)

모든 쇼츠는 올리기 전에 이 표로 검토한다. 기준은 2026년 8~10월 조회수 10만 이상 한국어 쇼츠 782편 조사에서 나왔다(`research/research-fun.md` 388편, `research/research-info.md` 394편). 숫자로 잴 수 있는 항목은 `python3 qa_review.py <id>`가 재고, 나머지는 사람이 본다.

## 1. 자동 검사 (`qa_review.py`)

| 항목 | 통과 | 근거 |
|---|---|---|
| 길이 | 25~45초. 31~45초가 가장 좋다 | 길이를 확인한 247편의 중앙값은 34초다. 31~45초 구간의 조회수 중앙값이 139만으로 가장 높고, 15초 이하가 73만으로 가장 낮다 |
| 제목 띠 | `"titleStyle": "band"`, 2줄 | 첫 화면의 62%(241편)가 위쪽 검정 띠에 2줄 제목을 둔다(중앙값 54만) |
| 제목 길이 | 한 줄 13자 이하, 합계 약 20자 | 제목 중앙값은 20자다 |
| 제목 호기심 | "~하는 이유", "~썰", "정체", "생긴 일", "역대급", "TOP", "소름", 숫자, "?" 중 하나 | 가장 자주 쓰인 패턴이다(이유 24, 썰 24, TOP 21, 역대급 20, 소름 17, 물음표 43) |
| 첫 장면 | 3.5초 안에 다음 장면으로 넘어감 | 첫 1~2초에 훅을 걸고 바로 움직인다 |
| 장면 길이 | 가장 긴 장면 4.5초 이하, 평균 3초 안팎. 인터뷰·연설은 6초 이하 | 클립형은 2~4초, 썰은 문장마다 그림이 바뀐다. 한 사람이 길게 말하면 문장 사이에서 확대 컷(같은 영상을 더 크게, 또는 덜 크게)으로 화면을 바꾼다 |
| 자막 한 장 | 한국어 12자 이하(번역 자막은 30자, 영어 70자) | 한 번에 1줄, 7~12자다 |
| 구독·좋아요 요청 | 없음 | 잘 되는 쇼츠는 반전 한 줄로 끝내고 바로 끊는다 |
| 소리 | −14 LUFS ±1 | 유튜브 재생 음량 |
| 검은 화면 | 0.05초 이상 없음 | 끝이 검게 끝나면 다시 보기가 끊긴다 |
| 용량 | 30MB 이하 | |

## 2. 사람이 보는 항목 (`out/review/<id>/`의 첫 장면·마지막 장면·16칸 시트를 보고)

1. **첫 프레임 = 썸네일.** 제목 띠와 함께 주인공(놀란 얼굴, 캐릭터, 동물 클로즈업)이 0초부터 보이는가. 무엇을 보게 될지를 0초에 약속하는가.
2. **첫 문장 = 훅.** 첫 내레이션이나 첫 대사가 질문, 숫자, 이상한 상황인가. 배경 설명으로 시작하지 않는가.
3. **한국 시청자가 멈출 이유.** 한국의 일상 감정(웃김, 설렘, 공감, 소름, 귀여움)이나 한국 연결 고리가 있는가. 외국 소재만 있고 "나와 무슨 상관?"에 답이 없으면 다시 쓴다.
4. **반전과 끝.** 마지막 2~4초에 반전이나 답이 오고 바로 끊기는가. 첫 장면으로 다시 이어지거나(루프), 댓글을 부르는 한 줄이 있는가.
5. **글자.** 겹치거나 잘린 글자가 없는가. 자막이 소리와 맞는가.
6. **시리즈.** 같은 채널의 다른 편과 같은 틀(제목 띠, 색, 음악 톤)인가. 한 포맷을 반복하는 채널의 적중률이 9~14/15다.

## 3. 형식별 추가 기준

| 형식 | 잘 되는 예 (조사) | 추가로 볼 것 |
|---|---|---|
| 썰(캐릭터) | 썰구리 14/15 적중, 중앙값 40만. 내레이션 썰 중앙값 109만 | 첫 화면에 글 카드와 함께 캐릭터 얼굴이 보이는가. 이상한 행동이나 규칙으로 시작해 "~한 이유"를 마지막에 푸는가. 대사는 말풍선, 내레이션은 자막인가 |
| 정보·지식·뉴스 | 누리호 해설 27.5만(구독 0.2만), 텍스트 뉴스 카드 중앙값 32만 | 실제 영상이나 사진인가(그래픽만으로 된 해설은 쓰지 않는다). 한국인이 지금 궁금한 질문인가. 날짜와 출처가 화면과 설명란에 있는가 |
| 유명인 인터뷰 | 영한 자막 동기부여(레퍼런스 Project스노우볼) | 그 유명인의 얼굴이 크게, 0초부터 나오는가(질문하는 사람이 먼저 나오면 첫 1~2초에 유명인을 먼저 보여 준다). 제목에 유명인 이름이 있고, 실제 발언과 맞는 질문("..?")인가. 핵심 한 줄로 끝나는가 |
| 랭킹 TOP5 | 중앙값 410만(24편) | 아래쪽 순위표, "다들 몇 위가 제일 ○○?ㅋㅋ" 질문, 1위로 끝나는가 |

## 4. 올릴 때

- 업로드 제목은 화면 제목과 같거나 더 짧게, 끝에 "ㅋㅋ", "ㄷㄷ", "?"를 붙인다(조사에서 ㅋㅋ 38편, ㄷㄷ 19편).
- 고정 댓글로 경험을 묻는 질문을 단다("여러분도 이런 짝꿍 있었나요?").
- 하루 1~2편, 같은 시간대에 올린다.
