# 쇼츠 50만+ 무음(목소리 없는) 형식 조사

조사일 2026-10-11. 사용자 요청은 "사연은 안되겠다 음성 많이 들어가면 어색해 음성없고 50만 이상으로 해서 조사해서 더 만들어줘"였다. 그래서 이번에는 **내레이션·대사·TTS가 없는** 쇼츠 가운데 조회수 50만 이상만 봤다. 원자료는 `research-500k-mute.csv`다.
- `source=search`·`channel_tab`: 50만 이상 1,122행. 형식과 목소리 판정이 붙어 있다.
- `source=tab_all`: 채널 113곳 쇼츠 탭의 최근 48편 전체(5,663행). 적중률을 다시 계산할 때 쓴다.

**목소리 판정 근거(추정).**
- **무음으로 본 것**
  - `#worker #process #satisfying` 해시태그.
  - 흰 카드 이름표형, 클립 모음(TOP N, "모먼트", "선택하기"), 손만 나오는 레시피.
  - 썸네일 가운데에 자막이 한 줄 고정돼 있거나 아래에 작은 설명 문단만 있는 화면.
  - 곡명이 제목인 애니(샬론티).
- **목소리 있음으로 본 것**
  - 썸네일 가운데 큰 자막이 말 단위로 끊긴 것("테스트 속에", "하단의 블록을", "타버릴 판이었던 거조"): 내레이션 자막 모양이다.
  - 사람이 말하는 화면, 방송 클립, 상식 퀴즈 채널(김블루, 김켈리), 해설형 기술 채널(이런거지).
  - 판정이 애매하면 `mixed`로 뒀다.
- **썸네일**: 12장을 분석용으로만 받았다. 저장소에는 올리지 않았다.
- **요청 규칙**: 요청 간격은 2.3초 이상(잠금 파일)이었고 User-Agent는 `richroro-shorts/1.0`이었다. 캡차, `google.com/sorry`, 429는 없었다. 로그인, 우회, 프록시, 다른 클라이언트, 미러는 쓰지 않았다.

**표본 크기.**
- 무음으로 판정한 50만+는 **423행, 채널 45곳**이다.
- 그중 날짜가 묶인 것(검색 필터 안이거나 채널 탭 최신 33편 안)은 **278행, 채널 43곳**이다.
- 목소리 있음은 652행, 애매는 47행이다.

## 1. 결론

1. **무음 50만+를 작은 채널(구독 10만 미만)이 반복해서 내는 형식은 흰 카드다.**
   - 흰 카드 + 실제 클립 한 편 + 장면 자막(사랑빛 11/30, 지구촌동물극장 9/30): 20/60 = **33%**.
   - 흰 카드 + 클립(잘난지): 8/30 = 27%.
   - 흰 카드 사진 리스트(겔라다 11/30, 미도리치치 1/30, 오레오쿠키 0/30): 12/90 = 13%.
2. **해외 공정·작업 영상 채널(#worker #process)은 식었다.**
   - Playboard 월간 상위였던 곳(앞선 조사 §4)의 최근 30편은 강남각(7.5만) 1/30, 순삭슈퍼(6.2만) 0/30, Look(0.7만) 0/30, 목작소(8.5만) 3/30, Quick Hands(3.5만) 6/30이다. 5곳 합계 10/150 = **6.7%**다.
   - 틀딱감성(2.2만)은 공정 영상을 그만두고 애니 클립 채널이 됐다.
   - 다만 **소재로서 공정은 여전히 크게 터진다**.
     - 흰 카드에 공장 클립을 담은 「참치캔 공장에서 '진짜 광기'라고 불리는 역대급 공정」: 16,024,059회.
     - 「완벽만을 추구하는 도자기 공방」: 1615만. 다만 내레이션 자막형이다.
     - 3D 프린팅 클립 모음 341만·171만, 용접 클립 다수.
3. **그래서 고른 형식: 흰 카드 + 공정 클립 한 편 + 단계 자막.**
   - 무음 작은 채널 중 적중률이 가장 높은 레이아웃(흰 카드 + 클립)에 지금 크게 터지는 소재(공정, 3D 프린팅, 용접)를 담는다.
   - 클립은 남의 영상 대신 NASA 직원이 찍은 퍼블릭 도메인 영상을 쓴다.
4. **합법적으로 못 하는 무음 형식은 뺐다.**
   - 클립 모음 랭킹(동물사전 14/30, 랭킹공·랭킹김·랭킹권)과 "모먼트" 모음(숏랭커 「역대급 번개 모먼트」 2276만)은 남의 영상 재업로드다.
   - 손만 나오는 음식(생활탐험 6/30, 맛있다욧 5/30, 합계 15.6%)은 직접 촬영해야 한다.
   - 무언 2D 애니(샬론티 27/30, 중앙값 162만)는 구독 40만 채널의 캐릭터 팬 애니라 작은 채널 근거가 아니고 저작권 캐릭터다.
5. **퀴즈·텍스트 카드는 무음 근거가 없다.** 50만+ 퀴즈(김블루 678만·125만, 김켈리 561만·307만·269만)는 모두 사람이 말하거나 TTS로 읽는 채널로 판정했다. 무음으로 볼 수 있는 텍스트 퀴즈 50만+는 찾지 못했다.

**우리가 맞춘 것.**
- **레이아웃**: ①·②의 흰 카드. `src/lib/Card.tsx`를 그대로 쓰고 그림 상자만 정사각형(1000×1000)으로 키웠다. 세로·가로 공정 클립이 다 들어간다.
- **첫 1초 훅**: 결과가 가장 잘 보이는 장면부터 시작한다.
  - 레이저가 금속 가루에 무늬를 새기는 순간.
  - 거대한 돔이 용접 로봇 위로 내려오는 장면.
  - 엔진이 불을 뿜기 직전의 시험대.
- **자막**: ②처럼 그림 아래 한 줄 + 괄호 단계 표시("1단계"). 숫자와 사실은 NASA 영상 설명에 있는 것만 쓴다.
- **속도 조절**: ③처럼 긴 작업을 짧게 줄인다. 같은 클립 안에서 1배 → 2~16배 → 1배로 바꾼다. 엔진 시험은 약 500초를 30초 안에 담는다.
- **소리**: 목소리는 없다.
  - 음악: Kevin MacLeod.
  - 기계 소리: 직접 합성한 레이저·마찰 용접 소리와 금속 부딪는 소리.
  - 엔진 편: NASA 원본의 엔진 굉음. 사람 목소리가 없는지 받아쓰기(faster-whisper)로 확인했다.
- **루프**: 마지막 장면을 첫 장면과 같은 상태로 끝낸다(빈 가루판 → 빈 가루판, 조용한 시험대 → 조용한 시험대).
- **제목 틀**: ①의 "~하는 역대급 공정", ③의 "단 몇 초 만에", 숫자.
