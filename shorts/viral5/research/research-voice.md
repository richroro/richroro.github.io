# 목소리 조사: 히트 영상은 어떤 목소리를 쓰나, 우리는 무엇으로 바꾸나 (2026-10-10)

사용자 요청은 "음성도 인기 영상 음성처럼 개선해줘"였다. 이 문서는 세 가지를 다룬다.
1. 조회수 10만 이상 한국어 영상(우리 형식)이 쓰는 목소리와 말하는 방식
2. 형식별 목표 수치
3. 무료(오픈 모델)와 유료 후보를 우리 대본 12줄로 비교한 결과

데이터:
- `research-voice.csv`: 72행. 영상 페이지, 업체 사례, 기사에서 찾은 목소리 크레딧이다.
- `../voicelab/results.csv`: 후보별 12줄 점수.
- `../voicelab/screen.csv`: 목소리별 2줄 점수.

**방법과 한계(먼저 읽기)**
- 페이지 글만 봤다. 제목, 설명란, 고정 댓글, 업체 사례 페이지, 기사다.
- **유튜브 소리와 영상은 받지 않았다.** 그래서 히트 영상의 실제 말 속도는 재지 못했다.
- youtube.com 시청 페이지는 26편만 읽었다. 그 뒤로는 이 환경의 접속이 Google 확인 페이지(google.com/sorry)로 계속 넘어갔다.
- 중간에 유튜브 미러로 받은 약 130편은 규칙(미러 금지) 위반이라 **모두 버렸다.** 표와 통계에 없다.
- 그래서 괴담 쇼츠와 썰 쇼츠는 영상 설명란을 직접 확인한 표본이 0편이다. 이 두 형식의 숫자는 업체 사례와 추정에 기댄다.
- 아무도 직접 듣지 못했다. 목소리 비교는 객관 지표(예측 MOS, 받아쓰기 오류율, 말 속도, 음높이 폭)로만 했다. 최종 선택은 사용자의 귀가 한다(A/B 파일은 `final/voice_ab/`).

## 1. 히트 영상은 어떤 목소리를 쓰나

### 1-1. 출처별 개수 (`research-voice.csv` 72행)

| 목소리 출처 | 행 수 | 근거 |
|---|---|---|
| Typecast(타입캐스트) | 23 | Typecast 블로그의 채널 사례 22, 검색 스니펫 1. **영상 설명란에서 직접 확인한 것은 0** |
| 사람 목소리(성우, 본인 더빙·연기) | 24 | 영상 제목 19("성우 이지선 낭독", "직접 녹음, AI아님", "[성우 버전]", "병맛더빙"), 설명란 2, 기사 3 |
| Supertone Play | 1 | 업체 인터뷰(짤덕방) |
| CLOVA Dubbing, ElevenLabs, Vrew, CapCut | 0 | 영상에서도 업체 사례에서도 찾지 못함 |
| 크레딧 없음 | 24 | 설명란을 직접 읽은 26편 가운데 24편 |

설명란을 직접 읽은 26편:
- 정보·지식 쇼츠 10, ○○ 특 2, 낙서 짤툰 2, 스토리 롱폼 11, 다큐 롱폼 1
- **TTS 제품 이름이 적힌 영상은 0편이다.** 크레딧이 있는 2편(병맛교수 "더빙 : 병맛교수,야미야미", 아리의 이야기 "남자 성우 / 여자 성우")은 모두 사람 더빙이다.

크레딧이 없다고 TTS를 안 쓴 것은 아니다. 약관상 표기 의무가 무료 플랜에만 있기 때문이다.
- Typecast: 무료만 의무. 문구는 "이 콘텐츠는 인공지능 가상 연기자 서비스, 타입캐스트를 활용하여 제작되었습니다. 출연진: … https://typecast.ai/kr"
- CLOVA Dubbing: 무료만 의무
- Vrew: 일본어 Voicevox 목소리만 의무

그래서 쇼츠 히트 채널은 유료 TTS를 쓰면서 표기하지 않는다고 본다(*추정*).

## 2. 말하는 방식 (텍스트로 얻은 근거와 추정)

자막 데이터를 받을 수 있는 경로가 미러뿐이었다. 그래서 히트 영상의 초당 글자 수는 **재지 못했다.** 아래는 업체 설정값, 크리에이터 진술, 우리 측정이다.

- **속도**
  - Typecast 속도는 0.5~2.0이고 기본은 1.0이다. 정보 내레이션에는 **1.1배를 권한다**("1배속은 조금은 느긋하게 들릴 수 있어요").
  - 블로그 검색 스니펫은 쇼츠에 1.2~1.5배를 권한다(*추정*).
  - 우리 기존 조사(research-info.md)는 정보 히트가 "체감 1.2배 이상, 문장 끝을 끌지 않는다"고 적었다.
  - ElevenLabs 속도는 0.7~1.2다.
- **기본 속도 측정**: 이번에 Edge 목소리의 기본 속도를 쟀다. SunHi 6.2, InJoon 6.6, Hyunsu 5.4음절/초(T01, 쉼 포함)다. 그래서 1.1배는 약 6.8~7.3음절/초다.
- **쉼**
  - 꿀잼교실은 쉼표로 띄어 읽기를 만든다.
  - Typecast는 1초가 넘는 무음을 1초로 줄인다("말 속도만 올려서는 해결되지 않아요").
  - 반전 전 쉼에 대한 글 근거는 찾지 못했다.
- **감정**
  - Typecast 혜진 글: 정보 영상의 제목 줄은 기쁨 100%, 본문은 40~60%, 마무리는 기본 톤.
  - 썰은 화남·슬픔을 상황극에 쓰고, 끝음을 조절한다.
- **대사 연기**
  - 썰 쇼츠는 인물마다 다른 목소리를 쓴다(팥쥐).
  - 사연툰 롱폼은 남녀 성우를 나눠 모든 남자 인물과 모든 여자 인물을 맡긴다(아리의 이야기).
- **우리 지금 상태(측정)**
  - 썰 내레이션(SunHi +28%)은 7.8음절/초다. 업체 권장 1.1배보다 빠르고, 예측 MOS가 2.3으로 가장 낮다.
  - 대사는 같은 SunHi에 음높이만 ±10~20Hz 바꿔서, 인물이 갈리지 않는다.

### 4-2. 지표 (`voicelab/score.py`)

- **MOS**
  - UTMOS22 strong(MIT, ONNX)으로 예측한 자연스러움이다(1~5).
  - **영어 청취 시험으로 학습한 모델**이라 한국어에서는 대략적인 신호다.
  - 같은 후보를 다시 돌리면 평균이 ±0.1 정도 흔들렸다. 0.1 안쪽 차이는 같다고 본다.
- **CER**: faster-whisper large-v3-turbo(MIT)가 받아쓴 글과 대본의 한글 글자 오류율이다. 숫자와 영어는 양쪽 모두 한글 읽기로 바꿔서 비교했다.
- **속도·쉼·음높이**: 음절/초(목표 대비 오차), 80ms 이상 쉼, pYIN 음높이 폭(반음)이다.
- **RTF**: 이 컨테이너(CPU 4코어, GPU 없음)에서 합성 시간 ÷ 소리 길이다. 따로 조용한 상태에서 쟀다.

- Supertonic의 예측 MOS가 가장 높다(3.80). 대신 두 가지가 약하다.

- 남은 후보는 **Supertonic, Azure 같은 목소리(`edge_tuned`), (기준) Edge 지금** 셋이다. A/B는 앞의 둘로 만들었다.

## 6. 지금 쓰는 Edge 읽기 서비스(edge-tts)의 약관

**판정: 수익화 영상에 써도 된다는 근거가 없다. 오히려 Microsoft 약관에 걸린다.**

- edge-tts의 동작
  - Edge 브라우저에 들어 있는 토큰(`TRUSTED_CLIENT_TOKEN`)을 Edge 밖에서 쓴다.
  - Edge 확장 프로그램처럼 꾸며 `speech.platform.bing.com/consumer/speech/synthesize/readaloud`를 부른다(github.com/rany2/edge-tts `constants.py`).
- Microsoft Edge 사용권 계약(2026-09 갱신, explore.microsoft.com/en-us/edge/terms)
  - §1.3 "You may not use tokens the Software uses to call into a Microsoft Azure service separate from the Software."
  - §2.8(f) "use tokens the Software uses to call into a Microsoft service separate from the Software"
  - §2.8(c) "work around any technical limitations in the Software…"
- Microsoft Services Agreement(2026-09-30 시행)
  - §3(a)(vi): 접근 제한 우회와 무단 스크래핑 금지
  - Bing 자료는 "noncommercial, personal use only"
- Microsoft Q&A 진행자(2024-10-07, 법률 문서 아님): Azure 구독 없이 상업적으로 쓰면 "could be a violation of our terms of service", 공식 Azure AI Speech를 권장한다.
- edge-tts의 GPL은 파이썬 코드에만 적용된다. 목소리와 출력물에 대한 권리는 주지 않는다.
- **대안**
  - 같은 목소리(SunHi, InJoon, Hyunsu, 다국어 목소리)를 정식으로 쓰는 길은 Azure AI Speech다.
  - F0 무료 등급(월 50만 자)으로 우리 분량은 $0이다. 한국어 여자 목소리도 JiMin, SeoHyeon, SoonBok, YuJin이 더 있다.
  - `voice_engine.py`에 `"engine": "azure"`(Speech SDK, WordBoundary로 같은 음절 타임라인)를 넣어 두었다. Edge 목소리 이름이 1:1로 맞아서 `--engine azure`나 `VOICE_ENGINE=azure`로 배역을 다시 짜지 않고 바꿀 수 있다. 키가 없어 실행해 보지는 못했다.
  - 지금 카탈로그 전체를 다시 녹음하는 분량은 약 5.5만 자다(쇼츠 약 137편 × 평균 244자 = 3.35만 자, 롱폼 약 3.8천·7.6천·8천 자). F0 한도의 약 11%다.
- **edge-tts는 비교 시험과 A/B에서 같은 목소리를 미리 듣는 데만 썼다.** 발행할 영상에는 쓰지 않는다.

## 7. 권고

1. **Edge 읽기 서비스는 그만 쓴다(6절).** 지금 쓰는 목소리 그대로 가려면 Azure F0로 옮긴다(무료). 필요한 것은 `AZURE_SPEECH_KEY`/`AZURE_SPEECH_REGION` 환경 시크릿뿐이다.
2. **무료로 키 없이 지금 바로 쓸 수 있는 것은 Supertonic 3다.**
   - 이 CPU에서 합성 RTF 0.27이고, 예측 MOS가 가장 높다.
   - 인물마다 다른 프리셋 목소리 10개(여 5, 남 5)가 있다.
   - 약점은 평평한 억양과 짧은 고함 대사다. 사연툰 롱폼처럼 감정 연기가 큰 것은 귀로 확인한 뒤 정한다.
   - 라이선스(OpenRAIL-M)는 AI 생성 사실 고지를 요구한다. 지금 설명란의 "목소리: AI 합성 음성"이 그 고지다.
3. **돈을 쓴다면 Typecast API Lite($15/월)다.** 히트 쇼츠의 업체 사례가 몰린 곳(발키리, 하영, 한서린, 공철 등 캐릭터 연기)이다. 유료면 크레딧이 필요 없다.
   - 다만 우리가 직접 들어 보지 못했다. 사용자가 키를 주면 같은 12줄 시험을 다시 돌린다.
4. 롱폼 사연·괴담 낭독은 히트가 사람 목소리 쪽이다(1-3). TTS로 만들면 인물별 목소리 분리와 쉼 규칙은 꼭 지킨다.
