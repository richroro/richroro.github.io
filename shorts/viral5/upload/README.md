# 업로드 설명글 (모든 영상 공통 형식)

모든 영상의 유튜브 설명글은 이 형식으로 만든다. 2026-10-10 사용자가 보여 준 예시 설명글(AI 뉴스 쇼츠)의 구성을 그대로 따른다.

```
요약 문단 (2~4문장)

[롱폼만] 챕터 목록 (0:00 인트로 …)

▶ ○○ 채널 구독: https://www.youtube.com/@핸들

[선택] 관련 링크 (https://…)

출처: 원본 1 · 원본 2 · 음악: "곡" Kevin MacLeod (incompetech.com), CC BY 4.0 (…) · 주의 문구

#Shorts #주제 #주제 … (8~15개)
```

## 쓰는 법

1. 영상마다 `upload/specs/<id>.json`을 쓴다.
2. `python3 upload/make_desc.py <id>`를 돌린다. `upload/txt/<id>.txt`에 붙여 넣을 설명글이 생긴다.
3. 전체를 다시 만들 때는 `python3 upload/make_desc.py --all`을 돌린다. 채널별 모음 `upload/<채널>.md`도 다시 생긴다. 모음에는 제목, 설명글, 고정 댓글이 업로드 순서대로 들어 있다.
4. 채널 이름과 핸들은 `upload/channels.json` 한 곳에만 적는다. 바꾸고 `--all`을 돌리면 모든 설명글의 구독 줄이 바뀐다.

## spec 항목

| 키 | 필수 | 내용 |
|---|---|---|
| `title` | ○ | 업로드 제목(README 각 편의 제목) |
| `summary` | ○ | 요약 문단. 아래 "요약 쓰는 법" |
| `tags` | ○ | 해시태그(# 없이). `#Shorts`는 쇼츠에 자동으로 맨 앞에 붙고, 채널 태그는 `channels.json`에서 붙는다. 합쳐서 15개까지 |
| `sources` | ○ | 출처 목록. " · "로 이어 한 줄이 된다. 예: "영상: Pexels(작가명)", "사진: NASA", "자료: 국가법령정보센터 도로교통법(2026-10-10 기준)", "그림·이야기·목소리 직접 제작" |
| `caveat` | | 수치나 주장을 검증하지 못했을 때의 주의 문구. 예: "수치는 ○○ 공식 발표 기준이며 독립 검증 결과는 아닙니다" |
| `fiction` | | 창작이면 `true`. 요약 앞에 "(창작)"이 붙는다 |
| `music` | | 음악 제목 목록. 없으면 그 영상의 edit.json에서 읽는다 |
| `chapters` | 롱폼 | `[["0:00", "인트로"], ["1:20", "…"]]`. 0:00부터 3개 이상, 각 10초 이상 |
| `channel` | | 채널 키. 없으면 id 앞부분으로 `channels.json`에서 찾는다 |
| `long` | | 롱폼이면 `true`(채널 설정에 있으면 생략). `#Shorts`를 붙이지 않고 챕터를 넣는다 |
| `pinned` | | 고정 댓글 |

## 요약 쓰는 법 (예시 설명글 기준)

- **2~4문장, 60~320자.** 뉴스처럼 담백하게 쓰고, 이모지와 낚시 문구는 쓰지 않는다.
- **첫 문장은 영상의 훅을 풀어 쓴 사실 문장이다.** 누가, 언제, 어디서를 넣는다. 예: 「클로드, 코덱스 시대는 끝났다는 말은 ChatGPT를 같이 만든 전 OpenAI 연구원 디오고 알메이다의 발언입니다.」
- **둘째 문장은 핵심을 쉬운 말로 푼다.** 「~라는 것.」처럼 짧게 끊어도 된다.
- **셋째 문장은 새 정보나 결론이다.** 숫자와 이름은 구체적으로 쓴다.
- **이야기형(썰·괴담·짤툰)은 상황과 궁금증까지만 쓴다.** 마지막 반전이나 괴담의 정답은 쓰지 않는다.
- **창작이면 `fiction: true`로 둔다.** 요약 앞에 "(창작)"이 붙는다.
- **출처 줄에는 원본과 라이선스를 담백하게 적는다.** "저작권 만료" 같은 말은 쓰지 않는다. CC BY 자료는 작가, 라이선스, 출처를 함께 적는다.
- **수치가 한쪽의 발표나 발언이면 `caveat`에 그렇다고 적는다.**
