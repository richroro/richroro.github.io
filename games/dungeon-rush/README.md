# Dungeon Rush · 던전 러시

횡스크롤 4인 협동 던전 액션. 워리어·아처·위저드·클레릭 4명이 한 파티를 이루고,
사람이 안 앉은 자리는 AI 동료가 채운다. 불타는 마을 → 고블린 지하 감옥 → 드래곤 둥지 3스테이지.

- 배포: https://richroro.github.io/games/dungeon-rush/
- 소스: `index.html` 한 파일. 외부 스크립트·이미지·오디오 없이 캔버스와 Web Audio 로 전부 그린다.
  (웹폰트 Black Han Sans 만 Google Fonts 에서 받고, 실패하면 시스템 폰트로 대체)

## 조작

| | 이동 | 공격 | 스킬 | 구르기 |
| --- | --- | --- | --- | --- |
| P1 키보드 | W A S D | J | K | L |
| P2 키보드 | 방향키 | , | . | / |
| 게임패드 | 스틱 / 십자키 | A | X / Y | B |
| 터치 | 왼쪽 화면 드래그 | 공격 | 스킬 | 구르기 |

P / Esc 일시정지, M 소리 끄기. 파티 편성 화면에서 P2 는 `,` 키, 패드는 A 버튼을 누르면 참가한다.
넘어진 동료 옆에 서 있으면 살려낸다(클레릭은 더 빠르게). 고기는 체력, 동전은 점수.

## 영웅

| 영웅 | 역할 | 기본 공격 | 스킬 |
| --- | --- | --- | --- |
| 워리어 | 탱커 | 3단 콤보 | 회오리 베기 (주변 4연타) |
| 아처 | 딜러 | 화살 연사 | 화살 비 (9방향 관통) |
| 위저드 | 광역 | 마법탄 | 낙뢰 (화면의 적 5명에게 번개) |
| 클레릭 | 지원 | 철퇴 2연타 | 치유의 빛 (전원 회복·부활 + 주변 피해) |

## 적

고블린, 창병, 샤먼(불덩이), 오크(슈퍼아머), 그리고 스테이지 3 보스 레드 드래곤
(할퀴기 · 브레스 · 운석 · 졸개 소환, 체력 50% 이하에서 분노).
적은 공격 전에 머리 위에 빨간 `!` 를 띄우니 구르기로 피하면 된다.

## 온라인 협동

편성 화면의 **온라인 협동**에서 방을 만들면 4자리 코드가 나오고, 친구는 **방 참가**에서 코드를 입력한다.
빈 영웅 자리에 순서대로 앉고, 호스트가 출발을 누르면 시작한다. 도중에 나간 사람의 영웅은 AI 가 이어받는다.

- 호스트가 게임 전체를 계산하고(초당 60틱), 게스트는 자기 입력만 보낸다(초당 30회).
  호스트는 초당 30번 장면(영웅·적·투사체·이펙트·효과음)을 보내고 게스트는 그걸 보간해서 그린다.
- 연결은 WebRTC(PeerJS, unpkg CDN 에서 온라인 버튼을 눌렀을 때만 불러옴). 중계에는 PeerJS 무료 공개 서버를 쓰므로
  서버가 내려가 있거나 사내망·일부 통신망처럼 WebRTC 가 막힌 곳에서는 접속이 안 될 수 있다.
- 호스트가 일시정지·스테이지 재시작을 관리한다. 게스트는 조이스틱과 버튼, 키보드(P1 키)만 쓴다.

## 검증

- 헤드리스 크로미움에서 전원 봇으로 3스테이지 끝까지 완주(드래곤 격파, 승리 화면), 콘솔 에러 0.
- 주소 뒤에 `?auto=1&fast=4&stage=2` 를 붙이면 봇 자동 플레이(4배속, 스테이지 지정)로 볼 수 있다.
- 390×844 터치 화면에서 조이스틱·버튼 배치를 캡처로 확인했다.
- 온라인: PeerJS 자리에 가짜 중계를 끼워 호스트 1 + 게스트 2 페이지로 방 만들기 → 코드 입력 → 자리 배정 → 출발 → 게스트 입력(이동·공격)이 호스트에 반영되고 화면이 게스트에 전달되는 것, 게스트가 나가면 AI 로 바뀌는 것까지 확인했다.

확인 못 한 것: 실제 PeerJS 서버를 통한 접속(이 개발 환경에서는 CDN 이 막혀 있었다), 실제 게임패드, 실기기 터치 감각, 소리 밸런스, 인터넷 지연에서의 체감.
