# Sakura Crossing · 벚꽃 건널목 마을

벚꽃이 핀 일본 소도시를 1인칭으로 걸어 다니는 3D 산책 게임.

- 배포: https://richroro.github.io/games/sakura-crossing/
- 소스: `index.html` 한 파일 + `vendor/three.module.min.js`(Three.js r170, MIT)
- 외부 모델·이미지·음원 없음. 건물, 나무, 고양이, 전차, 텍스처, 소리까지 전부 코드로 만든다.
  간판 글씨만 Google Fonts 의 Noto Serif JP 를 쓰고, 못 불러오면 기기 글꼴로 그린다.

## 둘러볼 곳

| 명소 | 할 수 있는 것 |
| --- | --- |
| 踏切 건널목 | 30~44초마다 경보가 울리고 차단기가 내려온 뒤 3량 전차가 지나간다. 방향은 번갈아 바뀐다 |
| 상점가 16곳 | 노렌이 바람에, 지나가는 사람에게 흔들린다. 찻집 우산, 술통, 채소 상자, 꽃통 |
| 桜月堂 화과자 가게 | 안으로 들어갈 수 있다. 진열장 앞에서 화과자 사기 |
| 太鼓橋 붉은 다리 | 꽃잎이 떠내려가는 강 위 |
| 桜坂神社 | 돌계단 40단 위. 참배(방울 + 두 번 손뼉), 오미쿠지 |
| さくら坂 역 | 플랫폼 벤치에 앉아 전차 구경 |
| 千年桜 | 공원 한가운데 큰 벚나무 |

숨은 고양이 6마리와 명소 6곳은 찾은 만큼 브라우저에 저장된다. 시간은 낮 → 해 질 녘 → 밤.
밤에는 초롱과 창문에 불이 들어오고, 가까운 초롱 4개에 점광원을 옮겨 붙여 벚꽃을 비춘다.

## 조작

| | 데스크톱 | 휴대폰 |
| --- | --- | --- |
| 걷기 | WASD/방향키, Shift 달리기, Space 점프 | 왼쪽 화면 끌기(끝까지 밀면 달리기) |
| 둘러보기 | 클릭 후 마우스(포인터 잠금) | 오른쪽 화면 끌기 |
| 행동 | E | 분홍 버튼 |
| 시간 / 지도 | T / M | 오른쪽 위 버튼 |

## 구현 메모

- **드로콜**: 단색 부품 수천 개를 재질별로 모아 28 m 격자 칸마다 한 메시로 합친다(칸 단위 절두체 컬링).
  한 화면에 40~230콜, 삼각형 약 30만 개(그림자 패스 포함).
- **벚꽃**: 작은 이십면체 11개를 뭉친 '송이' 두 벌을 인스턴스로 뿌린다. 첫 버전은 송이 하나가 큰 다면체라
  바위처럼 보여서 바꿨다.
- **충돌**: 건물은 2D 사각형, 나무·기둥은 원. 높이는 `groundH(x, z)` 한 함수로 계산하고, 한 걸음에
  0.55 m 넘게 오르거나 0.6 m 넘게 떨어지면 막는다. 그래서 계단(0.4 m)과 다리, 역 경사로는 오르고
  강·언덕 돌담·플랫폼 끝에서는 멈춘다.
- **소리**: Web Audio 합성. 건널목 종(738 Hz + 비조화 배음), 레일 이음매 소리, 강물, 바람, 새, 고양이,
  신사 방울, 자판기. 음악은 미야코부시 음계(E F A B C)로 코토 느낌을 낸 즉흥 선율.
- **성능**: 느린 기기에서는 2초 평균 38fps 밑이면 해상도를 0.2씩 낮춘다(최저 0.9배).

## 검증

헤드리스 크로미움(SwiftShader)에서 확인했다.

- 걷기 경로 12개: 남쪽 끝에서 북쪽으로 달리면 건널목 → 상점가 → 다리 → 계단 40단을 올라 신사 새전함
  앞에서 멈춤(높이 4 m), 가게 입구 오목한 곳에서 멈춤, 桜月堂 안 진열장 앞에서 멈춤, 강 난간·돌담·
  플랫폼 끝·월드 경계에서 멈춤, 다리 난간 안쪽 유지.
- 휴대폰(Pixel 7 에뮬레이션): 가상 조이스틱으로 전진, 오른쪽 끌기로 시야 회전, 고양이 쓰다듬기·
  화과자 사기·참배·오미쿠지·자판기·벤치 앉기 버튼 동작. 페이지 오류 0건.
- 낮·해 질 녘·밤 화면, 전차 통과 중 차단기와 경보등.

**확인 안 된 것**: 실기기 프레임레이트(SwiftShader 는 CPU 렌더라 느리다), 실제 소리 듣기.

## 영감

Claude 로 만든 3D 벚꽃 마을 데모 'Sakura Crossing' 소개 글을 보고 처음부터 새로 지었다. 원본 코드는 쓰지 않았다.
