# 무법 도시

탑다운 오픈월드 범죄 액션. 초창기 GTA 같은 위에서 내려다보는 시점으로, 걸어 다니다 아무 차나
빼앗아 타고, 전화박스에서 임무를 받고, 경찰 수배를 따돌리며 $25,000을 모으는 게임.

- 배포: https://richroro.github.io/games/lawless-city/
- 소스: `index.html` 한 파일 (외부 스크립트·에셋·빌드 없음, 사운드도 Web Audio 합성)

## 조작

| | 키보드 | 터치 |
| --- | --- | --- |
| 걷기 / 운전 | WASD · 방향키 | 왼쪽 화면을 누르고 끌기 (운전 중엔 끈 방향으로 차가 꺾이고, 뒤로 당기면 후진) |
| 타기 / 내리기 | F · E | 탑승 버튼 (가까운 차가 있으면 노랗게 켜짐) |
| 공격 / 핸드브레이크 | Space | 공격 버튼 (운전 중엔 드리프트) |
| 무기 바꾸기 | Q | 무기 버튼 |
| 일시정지 · 소리 | Esc · M | 왼쪽 위 II 버튼 |

조준은 자동이다. 서 있으면 사거리 안의 가장 가까운 상대를, 걷는 중이면 바라보는 방향 ±30° 안의
상대를 잡는다. 경찰·임무 표적이 우선.

## 도시

82×82 타일(한 타일 48) 격자에 8×8 블록. 도로는 2차선 우측통행이고, 시드가 고정이라 매번 같은 도시가 나온다.

| 장소 | 하는 일 |
| --- | --- |
| 병원 | 시작 지점 · 죽으면 여기서 다시 시작 |
| 경찰서 | 잡히면 여기서 다시 시작 |
| 도색소 | 차를 타고 들어가면 $300에 수리 + 색 변경 + **수배 해제** |
| 총포상 | 걸어 들어가면 $200에 권총 탄 40발 |
| 차고 | 차량 탈취 임무의 납품 장소 |
| 전화박스 (초록) | 임무 받기 |

거리에는 권총 탄약 12곳, 체력 8곳이 흩어져 있고 먹으면 45초 뒤 다시 생긴다.
쓰러진 사람은 현금을, 경찰은 현금과 탄약을 떨어뜨린다.

## 임무

같은 종류가 연달아 나오지 않게 셋 중 하나를 준다.

| 임무 | 내용 | 보수 |
| --- | --- | --- |
| 급한 택배 | 차를 타고 픽업 지점 → 제한 시간 안에 먼 목적지 | 거리 비례 (대략 $1,200~2,000) |
| 금색 스포츠카 | 주차된 금색 차를 훔쳐 차고로. 200초 | $2,400 × 차 상태 (최소 20%) |
| 검은 밴 제거 | 조직 밴(내구도 230)을 박살. 가까이 가면 도망친다. 160초 | $3,000 |

## 수배

별 0~5개. 범죄마다 수배 수치가 오르고, 소수점 아래를 버린 값이 별 개수다.

| 행동 | 수배 |
| --- | --- |
| 경찰 앞에서 총 쏘기 · 차 빼앗기 | 최소 ★1 |
| 시민 사망 | +0.35 (최소 ★1) |
| 경찰 공격 / 사망 | +0.4 / +1 (최소 ★2) |
| 순찰차 빼앗기 | +0.5~0.6 (최소 ★2) |
| 차 폭파 | +0.4, 경찰차면 +1 |

- 추격 순찰차 수: ★1~5 = 1, 2, 3, 4, 6대. 화면 밖 도로에 생겨 교차점 격자를 따라 플레이어 쪽으로 오고,
  눈에 보이면 곧장 들이받으러 온다. 걸어 다니면 차에서 경찰이 내려 쫓아온다(★3부터 2명).
- ★1 경찰은 잡으러만 오고, ★2부터 총을 쏜다.
- 경찰 눈(순찰차 430, 경관 340 + 시야)에 안 띄고 `5 + 별×2.5`초 버티면 별이 하나 떨어진다. 떨어지는 중엔 별이 깜박인다.
- 걷다가 경찰에 1.4초(★2 이상 1.9초) 붙잡히거나, 차가 거의 멈춘 채로 경찰에 둘러싸이면 체포.
- 죽거나 잡히면 탄약 전부와 돈 10%(+$50/$100)를 잃고 진행 중인 임무는 실패.

## 구현 메모

- **차 물리**: 전진·횡 속도로 나눠서 가속/브레이크, 횡 속도만 그립으로 감쇠한다. 핸드브레이크는 그립을
  8.5 → 1.4로 떨어뜨려 드리프트가 된다. 벽 충돌은 차 둘레 12점을 타일과 비교해 막힌 쪽 가장 얕은 면으로
  밀어내고, 차끼리는 차마다 원 3개로 근사해 질량비로 충격량을 나눈다. 충격 속도에 비례해 내구도가 깎이고
  0이 되면 3.2초 뒤 폭발(반경 85 안의 사람은 즉사, 95 안의 차는 연쇄 피해).
- **교통**: 교차점 9×9 격자를 따라 다음 교차점의 차선 점(중앙선에서 오른쪽으로 24)을 향해 달린다.
  앞에 차나 사람이 있으면 서고, 3초 넘게 막히면 1.5초 동안 밀고 나간다(교차로 교착 방지). 1.2초 넘게
  제자리면 후진해서 빠져나온다.
- **경찰 길찾기**: 격자가 꽉 차 있어서 BFS 대신 플레이어 쪽 교차점까지의 맨해튼 거리가 가장 작은 이웃을 고른다.
- **건물**: 지붕을 카메라 중심 기준으로 `1 + 높이×0.42` 배 확대해 그리고, 카메라 쪽을 향한 벽면만 채운다.
  90년대 탑다운 GTA의 그 시점.
- **인구**: 화면 밖 고리(보이는 반경 + 20~700)에서 차 22대, 시민 34명을 유지하고 멀어지면 지운다.
  임무 차량과 추격 중인 경찰은 더 멀리까지 남긴다.

## 검증

헤드리스 크로미움(Playwright)에서 확인했다.

- 새 게임 → F로 옆 차 탑승 → W로 주행(1.8초에 약 620 이동) → Space+D 드리프트, 스키드 자국.
- 60초 무작위 운전 + ★3 추격 시뮬레이션에서 차·사람 좌표 NaN 0건, 페이지 에러 0건. 경찰차 3대와
  경관 4명이 붙어 결국 체포 → 경찰서에서 벌금 떼고 다시 시작.
- 임무 3종을 끝까지: 택배 픽업 → 배달, 금색 차 탑승 → 차고 납품, 검은 밴 도주 후 폭파 → 보수 지급.
- 390×844 터치: 조이스틱을 위로 끌면 동쪽을 보던 차가 북쪽으로 꺾여 달림, 탑승/하차 버튼.

**확인 안 된 것**: 실기기 터치 감각, 저사양 폰 프레임. 난이도·보수 밸런스는 사람이 오래 해 봐야 안다.

## 라이선스

개인 프로젝트. 실제 게임의 이름·로고·에셋은 쓰지 않았고, 그래픽은 전부 캔버스 도형으로 그린다.
