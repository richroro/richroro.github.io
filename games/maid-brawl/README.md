# 격파 메이드

달밤의 저택에서 건틀릿을 낀 메이드가 저주받은 인형들을 두들겨 부수는 횡스크롤 액션.
타격감(히트스톱·화면 흔들림·종이 꽃가루·빛기둥·"격파!!!" 글자)과 게임 규칙이 같이 움직이도록 만들었다.

- 배포: https://richroro.github.io/games/maid-brawl/
- 소스: `index.html` 한 파일 (외부 스크립트·이미지·사운드·빌드 없음)
  - 캐릭터·적·배경은 전부 캔버스 도형으로 그린다. 메이드는 관절 각도 11개짜리 포즈를 보간해서 움직인다.
  - 효과음과 배경음악은 Web Audio 로 그때그때 합성한다.

## 모드

| 모드 | 내용 |
| --- | --- |
| 저택의 밤 | 웨이브마다 인형이 양쪽에서 몰려온다. 웨이브를 깰 때마다 강화 하나를 고르고, 5웨이브마다 보스. 쓰러지면 끝, 최고 웨이브·누적 데미지를 기록 |
| 훈련장 | 쓰러지지 않는 오뚝이 샌드백. 누적 데미지·DPS·최대 연타를 본다. 플레이어도 무적 |

타이틀 화면 뒤에서는 봇이 훈련장을 자동으로 플레이한다.

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | ← → / A D | ◀ ▶ |
| 공격 | J / Z (누르고 있으면 콤보가 이어짐) | 공격 |
| 점프 | K / Space / ↑ / W (짧게 누르면 낮게) | 점프 |
| 대시 | L / Shift / C (무적 0.24초, 공중 1회) | 대시 |
| 회전차기 | I / X (쿨 5초, 시전 중 무적) | 회전 |
| 격파(필살) | O / V (게이지 100) | 격파 |
| 일시정지 | Esc / P | Ⅱ |

세로 화면에서는 위가 게임, 아래가 버튼. 가로 화면에서는 버튼이 게임 위에 반투명으로 뜬다.

**가로 모드**: 타이틀의 "가로 모드로 하기" 버튼이나 오른쪽 위 ⟳ 버튼. 폰의 화면 회전이 잠겨 있거나
앱 안 브라우저처럼 회전이 안 되는 곳에서도, 화면 전체를 CSS 로 90도 돌려서 폰을 옆으로 눕혀 플레이할 수 있다.
전체화면과 `screen.orientation.lock` 이 되는 브라우저(안드로이드 크롬 등)에서는 실제로 가로 고정을 먼저 시도하고,
폰을 실제로 가로로 돌리면 CSS 회전은 자동으로 풀린다. 설정은 `maidbrawl.rot` 에 저장된다.

## 기술

| 기술 | 입력 | 데미지 | 특징 |
| --- | --- | --- | --- |
| 잽 → 스트레이트 → 어퍼컷 → 회축 | 공격 연타 | 11 / 14 / 18 / 30 | 어퍼컷은 띄우고, 회축은 날려서 벽에 박으면 추가 데미지(벽꽝) |
| 돌진 펀치 | 대시 중 공격 | 22 | 강공격 |
| 공중 콤보 | 떠 있는 적 근처에서 점프 중 공격 | 12 / 14 / 24 | 공중에 머문 채 두 번 띄우고 세 번째에 바닥으로 내려꽂는다. 한 번 착지할 때까지 한 세트 |
| 내려찍기 | 점프 중 공격 (근처에 떠 있는 적이 없을 때) | 20 + 착지 충격파 14 | 착지 지점 주변을 띄운다 |
| 회전차기 | 회전 | 8 × 6회 + 마무리 24 | 주변 전체, 마지막 타는 강공격 |
| 격파 | 게이지 100 | 190 (웨이브 모드는 170 + 웨이브×10) | 0.55초 모으는 동안 적이 멈추고, 화면 안의 모든 적을 친다 |

- 연타가 쌓일수록 데미지가 오른다(1연타당 +1.2%, 최대 +48%). 치명타 12% 확률로 1.6배.
- 격파 게이지는 타격당 1.6(강공격 3), 격파 1회당 6씩 찬다. 훈련장에서는 2.2배.
- 도깨비불의 탄은 공격으로 쳐내면 되돌아가서 적에게 30 데미지(반사).
- **완벽한 회피**: 대시를 시작하고 0.13초 안에 공격을 받을 뻔하면 발동. 2.2초 동안 적·탄·충격파가 30% 속도로 느려지고(화면이 푸르게 변함) 격파 게이지 +12.
- **스타일 랭크**: 연타 수에 따라 C(10)·B(20)·A(35)·S(50)·SS(80)·SSS(120). 맞거나 연타가 끊기면 초기화되고, 결과 화면에 최고 랭크가 남는다.

## 강화

웨이브를 깰 때마다 무작위 3개 중 하나를 고른다(게임은 그동안 멈춤). 키보드는 1·2·3.

| 분류 | 강화 | 효과 | 최대 |
| --- | --- | --- | --- |
| 공격 | 강철 건틀릿 | 공격력 +15% | 5 |
| 공격 | 급소 찌르기 | 치명타 확률 +8%, 배율 +0.2 | 3 |
| 공격 | 연타 장인 | 연타 보너스 2배, 연타 유지 +1초 | 2 |
| 공격 | 진동 발차기 | 회축·돌진 펀치·내려꽂기가 바닥을 타고 가는 충격파(12×단계)를 쏜다 | 2 |
| 공격 | 벽꽝 전문가 | 벽 충돌 피해 3배, 주변 적에게도 16 | 1 |
| 생존 | 메이드의 체력 | 최대 체력 +25, 전부 회복 | 4 |
| 생존 | 튼튼한 코르셋 | 받는 피해 -15% | 3 |
| 생존 | 흡혈 앞치마 | 격파할 때마다 체력 +3 | 3 |
| 생존 | 홍차 한 잔 | 체력 60 회복 (체력 70% 미만일 때만 나옴) | - |
| 기술 | 가벼운 구두 | 이동 속도 +12%, 대시 쿨 -20% | 3 |
| 기술 | 회오리 치마 | 회전차기 쿨 -1.2초, 타수 +2 | 3 |
| 기술 | 잔상 회피 | 완벽한 회피 판정 2배, 회피 시 게이지 +25 | 1 |
| 기술 | 은쟁반 반사 | 반사탄 피해 2배, 관통 | 1 |
| 필살 | 달빛 충전 | 격파 게이지 획득 +30% | 3 |

## 적

| 적 | 첫 등장 | 체력 | 행동 |
| --- | --- | --- | --- |
| 오뚝이 허수아비 | 1웨이브 | 70 | 통통 뛰어 다가와서 몸통 박치기. 맞으면 오뚝이처럼 흔들린다 |
| 도깨비불 | 2웨이브 | 40 | 거리를 두고 떠다니며 탄을 쏜다 |
| 갑옷 인형 | 3웨이브 | 150 | 정면의 약공격을 방패로 막는다. 등 뒤를 치거나 강공격으로 가드(45)를 깨면 5초간 방패를 떨군다 |
| 폭탄 곰인형 | 4웨이브 | 45 | 다가와서 심지에 불을 붙이고 1.25초 뒤 폭발(반경 약 110, 플레이어 18·주변 인형 45). 강공격에 맞으면 점화되고, 체력이 바닥나면 바로 터지지 않고 맞은 방향으로 날아가 0.45초 뒤에 터진다. 인형 무리에 차 넣으면 연쇄 폭발 |
| 대왕 오뚝이 | 5웨이브마다 | 1300 (보스마다 +30%) | 점프 내려찍기(양쪽으로 충격파), 굴러오기, 체력 60% 아래에서 부하 소환. 경직 게이지가 바닥나면 그로기 |

- 적은 느낌표(!)를 띄우고 공격한다. 2웨이브부터는 느낌표 후반(준비 동작 60% 이후)에 약공격으로 끊기지 않으므로 어퍼컷·강공격으로 끊거나 피해야 한다.
- 웨이브가 오를수록 체력 +13%, 공격력 +6%, 준비 동작이 빨라진다(최대 30%).
- 웨이브를 깨면 체력 18 회복(보스 웨이브는 40). 적이 14% 확률로 하트(+15)를 떨군다.

## 배경음악

파일 없이 코드로 작곡·합성한다. 전부 D단조, 저택 홀 느낌의 잔향(2.2초 컨볼루션)을 건다.

| 곡 | 쓰이는 곳 | 구성 |
| --- | --- | --- |
| title | 타이틀 | 100BPM 3/4 왈츠. Dm–Gm–C–F–Bb–Gm–A–A, 오르골 멜로디 + 하프시코드 반주 + 패드 |
| battle | 웨이브·훈련장 | 148BPM. Dm–Bb–C–A–Gm–Dm–Bb/C–A, 하프시코드 16분 아르페지오 + 베이스 + 드럼. 두 바퀴째(8마디 뒤)부터 바이올린풍 리드 |
| boss | 보스 웨이브 | 168BPM. Dm–Eb–Dm–A–Bb–Gm–Eb–A, 16분 베이스, 4마디마다 탐 필인, 4마디 뒤부터 리드 |

- 곡은 0.8초 동안 서로 겹치며 바뀐다. 웨이브 사이·강화 선택 중에는 드럼과 리드가 빠지고, 일시정지 중에는 볼륨이 줄어든다.
- 쓰러지면 음악이 멈추고 짧은 종결구가 나온다.
- 타이틀과 일시정지 화면에서 배경음·효과음을 따로 끌 수 있다(`maidbrawl.bgm`, `maidbrawl.sfx`).
- 브라우저 정책 때문에 화면을 한 번 누르거나 키를 누른 뒤부터 소리가 난다.

## 기록

`localStorage` 의 `maidbrawl.best` 에 최고 웨이브와 그때의 누적 데미지를 저장한다.
소리 끔 설정은 `maidbrawl.muted`.
