# 격파 메이드

달밤의 저택에서 건틀릿을 낀 메이드가 저주받은 인형들을 두들겨 부수는 횡스크롤 액션.
타격감(히트스톱·화면 흔들림·종이 꽃가루·빛기둥·"격파!!!" 글자)과 게임 규칙이 같이 움직이도록 만들었다.

- 배포: https://richroro.github.io/games/maid-brawl/
- 소스: `index.html` 한 파일 (외부 스크립트·이미지·사운드·빌드 없음)
  - 캐릭터·적·배경은 전부 캔버스 도형으로 그린다. 메이드는 관절 각도 11개짜리 포즈를 보간해서 움직인다.
  - 효과음은 Web Audio 로 그때그때 합성한다.

## 모드

| 모드 | 내용 |
| --- | --- |
| 저택의 밤 | 웨이브마다 인형이 양쪽에서 몰려온다. 5웨이브마다 보스. 쓰러지면 끝, 최고 웨이브·누적 데미지를 기록 |
| 훈련장 | 쓰러지지 않는 오뚝이 샌드백. 누적 데미지·DPS·최대 연타를 본다. 플레이어도 무적 |

타이틀 화면 뒤에서는 봇이 훈련장을 자동으로 플레이한다.

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | ← → / A D | ◀ ▶ |
| 공격 | J / Z (누르고 있으면 콤보가 이어짐) | 공격 |
| 점프 | K / Space / ↑ / W (짧게 누르면 낮게) | 점프 |
| 대시 | L / Shift / C (무적 0.24초, 공중 1회) | 대시 |
| 회전차기 | I / X (쿨 5초, 시전 중 무적) | 회전 |
| 격파(필살) | O / V (게이지 100) | 격파 |
| 일시정지 | Esc / P | Ⅱ |

세로 화면에서는 위가 게임, 아래가 버튼. 가로 화면에서는 버튼이 게임 위에 반투명으로 뜬다.

## 기술

| 기술 | 입력 | 데미지 | 특징 |
| --- | --- | --- | --- |
| 잽 → 스트레이트 → 어퍼컷 → 회축 | 공격 연타 | 11 / 14 / 18 / 30 | 어퍼컷은 띄우고, 회축은 날려서 벽에 박으면 추가 데미지(벽꽝) |
| 돌진 펀치 | 대시 중 공격 | 22 | 강공격 |
| 내려찍기 | 점프 중 공격 | 20 + 착지 충격파 14 | 착지 지점 주변을 띄운다 |
| 회전차기 | 회전 | 8 × 6회 + 마무리 24 | 주변 전체, 마지막 타는 강공격 |
| 격파 | 게이지 100 | 190 (웨이브 모드는 170 + 웨이브×10) | 0.55초 모으는 동안 적이 멈추고, 화면 안의 모든 적을 친다 |

- 연타가 쌓일수록 데미지가 오른다(1연타당 +1.2%, 최대 +48%). 치명타 12% 확률로 1.6배.
- 격파 게이지는 타격당 1.6(강공격 3), 격파 1회당 6씩 찬다. 훈련장에서는 2.2배.
- 도깨비불의 탄은 공격으로 쳐내면 되돌아가서 적에게 30 데미지(반사).

## 적

| 적 | 첫 등장 | 체력 | 행동 |
| --- | --- | --- | --- |
| 오뚝이 허수아비 | 1웨이브 | 70 | 통통 뛰어 다가와서 몸통 박치기. 맞으면 오뚝이처럼 흔들린다 |
| 도깨비불 | 2웨이브 | 40 | 거리를 두고 떠다니며 탄을 쏜다 |
| 갑옷 인형 | 3웨이브 | 150 | 정면의 약공격을 방패로 막는다. 등 뒤를 치거나 강공격으로 가드(45)를 깨면 5초간 방패를 떨군다 |
| 대왕 오뚝이 | 5웨이브마다 | 1300 (보스마다 +30%) | 점프 내려찍기(양쪽으로 충격파), 굴러오기, 체력 60% 아래에서 부하 소환. 경직 게이지가 바닥나면 그로기 |

- 적은 느낌표(!)를 띄우고 공격한다. 2웨이브부터는 느낌표 후반(준비 동작 60% 이후)에 약공격으로 끊기지 않으므로 어퍼컷·강공격으로 끊거나 피해야 한다.
- 웨이브가 오를수록 체력 +13%, 공격력 +6%, 준비 동작이 빨라진다(최대 30%).
- 웨이브를 깨면 체력 18 회복(보스 웨이브는 40). 적이 14% 확률로 하트(+15)를 떨군다.

## 기록

`localStorage` 의 `maidbrawl.best` 에 최고 웨이브와 그때의 누적 데미지를 저장한다.
소리 끔 설정은 `maidbrawl.muted`.
