# 우노 카드 게임

색이나 숫자를 맞춰 먼저 손을 비우는 우노 규칙 카드 게임. 토끼·곰·여우 컴퓨터 1~3명과 겨룬다.

- 배포: https://richroro.github.io/games/uno/
- 소스: `index.html` 한 파일 (외부 스크립트·에셋·빌드 없음). 카드 108장은 전부 CSS와 인라인 SVG로 그린다.

## 규칙

카드는 표준 구성 108장: 4색 × (0 한 장, 1~9 두 장씩, 건너뛰기·방향 바꾸기·+2 두 장씩) + 와일드 4장 + 와일드 +4 4장.

| 상황 | 처리 |
| --- | --- |
| 낼 수 있는 카드 | 지금 색이 같거나, 숫자·기호가 같거나, 와일드 |
| 와일드 +4 | **지금 색 카드가 없을 때만** 낼 수 있다 (공식 규칙). 도전 규칙 대신 아예 막았다 |
| 낼 카드가 없음 | 더미에서 한 장. 그 카드가 맞으면 바로 내거나 넘길 수 있고, 다른 카드는 못 낸다 |
| 방향 바꾸기 | 둘이서 할 때는 건너뛰기와 같다 |
| +2 · +4 | 다음 사람이 받고 차례를 쉰다 |
| +2 · +4 쌓기 (선택) | 하우스 룰. +2 위에는 +2·+4, +4 위에는 +4만 얹을 수 있고, 못 얹으면 쌓인 만큼 받는다 |
| 첫 카드 | 숫자 카드가 나올 때까지 뒤집는다. 기호 카드는 더미 아무 데나 도로 꽂는다 |
| 더미가 바닥남 | 맨 위 카드만 남기고 버린 카드를 섞어 새 더미로 |
| 첫 차례 | 판마다 한 자리씩 돌아간다 |

**우노!** — 카드가 두 장일 때 한 장을 내려면 먼저 `우노!` 버튼을 누른다. 깜빡하고 냈으면
다음 컴퓨터가 움직이기 전까지 잠깐(약 1.3초) 더 누를 수 있고, 그래도 안 누르면 85% 확률로
걸려서 2장을 받는다. 컴퓨터도 15% 확률로 깜빡하는데, 그러면 자리에 `잡기!` 버튼이 뜨고
다음 사람이 움직이기 전에 누르면 그 컴퓨터가 2장을 받는다. 그 전에 다른 사람이 움직이면
컴퓨터가 "앗, 우노!" 하고 늦게라도 외친다.

**점수** — 먼저 손을 비운 사람이 남의 손에 남은 카드만큼 받는다. 숫자는 그 수, 기호 20점,
와일드 50점. 마지막 카드가 +2·+4면 다음 사람이 받은 카드까지 점수에 들어간다.
통산 판 수·승수·모은 점수는 `localStorage` (`uno.*`)에 남는다.

## 컴퓨터

카드마다 점수를 매겨 가장 높은 걸 낸다.

- 손에 많이 든 색을 이어 가고, 점수 큰 숫자 카드부터 털어 낸다
- 와일드는 아껴 두되, 다음 사람이 두 장 이하면 +4·기호 카드부터 쓴다
- 곧 끝낼 사람에게 차례를 돌려주는 방향 바꾸기는 피한다
- 와일드 색은 손에 가장 많이 든 색으로 고른다
- 쌓기 중에는 +2부터 쓰고 +4는 아낀다

모든 자리를 이 컴퓨터로 채워 150판씩 돌린 승률(내 자리 포함, 자리별):

| 인원 | 자리별 승 | 한 판 평균 차례 |
| --- | --- | --- |
| 2명 | 67 / 83 | 32 |
| 3명 | 48 / 51 / 51 | 37 |
| 4명 | 41 / 32 / 40 / 37 | 44 |
| 4명 + 쌓기 | 37 / 32 / 35 / 46 | 48 |

자리에 따른 쏠림은 보이지 않는다(첫 차례가 판마다 돌아가므로).

## 화면

- 위: 컴퓨터 자리. 남은 장수, 뒷면 부채, 지금 차례(점 세 개)와 다음 차례(`다음`) 표시
- 가운데: 더미와 버린 카드. 버린 카드 테두리가 **지금 색**이라 와일드 뒤에도 색이 바로 보인다.
  지금 색·순서 방향·쌓인 장수를 칩으로, 마지막 행동을 한 줄로 보여 준다
- 아래: 내 손패. 색 → 숫자 → 기호 → 와일드 순으로 정렬하고, 낼 수 있는 카드는 올라오고
  나머지는 어두워진다. 카드가 많아 탭하기 어려울 만큼 겹치면 2~3줄로 접는다
- 못 내는 카드를 누르면 왜 안 되는지 알려 준다 (예: "+4는 빨강 카드가 없을 때만 낼 수 있어요")
- 6과 9에는 밑줄을 친다

## 구현 메모

진행은 `async` 함수 흐름이다. 기다림(`wait`)과 카드 날리기(`fly`)는 전부 판 번호(`gen`)를
확인해서, 도중에 나가거나 새 판을 시작하면 이전 판의 흐름이 거기서 끊긴다. `wait`는
일시정지 중에는 시간이 흐르지 않는다.

카드를 주고받을 때 데이터는 먼저 옮기고 그림이 따라간다. 그래서 애니메이션 도중에 판이
끊겨도 카드 수가 어긋나지 않는다(버린 카드로 날아가는 동안의 한 장만 예외라, 검사는
차례가 시작될 때 한다).

| 겪은 것 | 대응 |
| --- | --- |
| 내가 우노를 안 외치고 건너뛰기·+2를 내면 차례가 곧장 나에게 돌아와서, 컴퓨터가 잡을 틈이 없었다 | 차례가 나에게 바로 돌아오는 경우 따로 틈을 주고 확인한다 |
| 컴퓨터가 우노를 깜빡하고 건너뛰기를 내면(둘이서) 잡기 버튼이 뜨자마자 그 컴퓨터가 다시 둔다 | 잡을 수 있는 자리가 있으면 컴퓨터가 생각하는 시간을 1.4초 늘린다 |
| 더미 뒷면이 시작 화면을 거치면 아래로 밀려 칩을 가렸다 | 절대 위치 카드에 `left/top: 0`을 CSS로 고정 |

## 검증

헤드리스 크로미움(Playwright)에서 실제로 돌렸다.

**규칙·진행** — 모든 자리를 컴퓨터로 채우고 대기·애니메이션을 끈 채 750판(2~4명, 쌓기 켜고 끄고)을
돌리며 매 차례 확인: 카드가 108장인지, 같은 카드가 두 군데 있지 않은지, 나간 카드가 규칙에
맞는지, 와일드에 색이 정해졌는지. 위반 0건, 끝나지 않은 판 0, 콘솔 에러 0.

**조작** — 실제 클릭으로 한 판 끝까지(카드 내기, 더미 뽑기, 뽑은 카드 넘기기, 와일드 색 고르기,
결과 화면, 한 판 더, 나가기 확인). 따로 상황을 만들어서: 우노를 외치고 내기 → 배지, 컴퓨터
잡기 → 2장, 우노 없이 내기 → 4번 모두 걸림, +4를 못 낼 때 안내, 색 고르기 취소 후 다시 고르기.
360×640, 390×844, 1280×800에서 화면이 겹치지 않는지 스크린샷으로 확인했다.

**확인 안 된 것** — 실기기 터치와 소리, 사람이 했을 때의 난이도.

## 라이선스

개인 프로젝트. 우노(UNO)는 Mattel의 상표이며, 이 게임은 규칙만 따랐고 공식 로고·카드 디자인은 쓰지 않았다.
