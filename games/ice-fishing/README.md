# 얼음강 그물잡이

얼어붙은 강에 그물을 치고, 거슬러 올라오는 물고기 떼를 받아 **찢어지기 직전에** 끌어올리는
한 손 세로형 낚시 게임. 스레드에 뜬 모바일 게임 광고(얼음 강에서 그물로 물고기를 끌어올리는 장면)를
보고 그 손맛을 웹으로 옮겼다.

- 배포: https://richroro.github.io/games/ice-fishing/
- 소스: `index.html` 한 파일 (외부 스크립트·에셋·빌드 없음)

## 조작

| 동작 | 터치 | 키보드 |
| --- | --- | --- |
| 그물 옮기기 | 화면을 좌우로 끌기 | ← → |
| 끌어올리기 | 아래 파란 버튼 | Space / ↑ |
| 일시정지 | 오른쪽 위 ⏸ | Esc / P |

그물은 손가락을 곧장 따라가지 않고 속도 상한(초당 420)이 있다. 얼음·상어를 피할 때 미리 움직여야 한다.

## 규칙

하루는 60초. 그날 번 돈이 목표를 넘으면 다음 날로, 못 넘어도 번 돈은 지갑에 그대로 남는다.

| 들어오는 것 | 무게 | 값 |
| --- | --- | --- |
| 빙어 (5~9마리 떼, 빠름) | 1kg | 1🪙 |
| 연어 (2~4마리 떼) | 3kg | 5🪙 |
| 황금송어 (혼자, 가장 빠름) | 2kg | 25🪙 |
| 얼음 (2일차부터, 위에서 떠내려옴) | 5kg | 0 |
| 상어 (3일차부터, 1.6초 전 경고) | — | 그물이 바로 찢어짐 |

- 그물 무게가 버팀을 넘거나 상어가 들어오면 **찢어진다**. 안에 있던 고기는 전부 도망가고 2.4초 동안 수선한다.
- 버팀의 **75% 이상** 채워서 끌어올리면 만선 ×1.5.
- 끌어올리는 동안(0.7초 + 한 마리당 0.028초)은 그물이 물 밖이라 아무것도 안 들어온다.
- 하루가 끝날 때 그물에 남은 고기는 보너스 없이 거둔다.

그래서 매 순간 "하나만 더 받고 올릴까"를 고르는 게임이 된다.

## 업그레이드

| | 효과 | 단계별 가격 |
| --- | --- | --- |
| 🥅 넓은 그물 | 폭 88 → 168 | 80 · 180 · 340 · 600 · 950 |
| 🪢 질긴 그물 | 버팀 24 → 59kg | 100 · 220 · 400 · 680 · 1050 |
| 💪 빠른 손 | 끌어올리는 시간 ×0.8씩 | 70 · 160 · 300 · 520 · 840 |
| 🪱 미끼 뿌리기 | 물고기 떼 간격 ×0.88씩 | 120 · 260 · 460 · 760 · 1200 |

목표는 `140 + (날-1)×65 + max(0, 날-4)×15`. 1일차 140, 5일차 415, 10일차 815.

## 난이도 측정

그물을 가장 값진 무리 쪽으로 옮기고 상어를 피하는 봇으로 하루씩 4판 돌렸다(헤드리스 크로미움, 고정 스텝 직접 호출).
"능숙"은 0.15초마다 판단·오차 ±5·얼음도 피함·75%에서 올림, "가볍게"는 0.4초마다·오차 ±20·얼음 무시·60%에서 올림.

| 날 | 업그레이드 | 목표 | 능숙 | 가볍게 |
| --- | --- | --- | --- | --- |
| 1 | 없음 | 140 | 307~378 | 210~229 |
| 3 | 폭·버팀·손 1 | 270 | 360~534 | 259~291 |
| 5 | 폭·버팀 2, 손·미끼 1 | 415 | 360~574 | 298~388 |
| 8 | 폭·버팀 3, 손·미끼 2 | 655 | 594~756 | 328~556 |
| 12 | 폭·버팀 5, 손·미끼 4 | 975 | 838~1370 | 656~923 |

초반 이틀은 누구나 넘기고, 3~5일차부터 업그레이드를 사야 목표에 닿는다. 8일차 이후는 능숙해도 가끔 떨어진다.

## 검증

헤드리스 크로미움(390×844)에서 시작 → 그물 이동 → 잡기 → 끌어올리기 → 과적 찢어짐 → 수선 복귀 →
하루 끝 → 상점 구매 → 다음 날까지 실제 이벤트로 확인했고 콘솔 오류 0.

**확인 안 된 것** — 실기기 터치와 사람의 실제 플레이 감각.

## 저장

`localStorage['iceFishing.v1']` 에 날짜·지갑·업그레이드·소리 설정만 둔다. 외부 요청 0건.
화면이 가려지면 자동으로 일시정지하고 소리를 끈다.
