# 스트레스 팍팍

스트레스 게이지 100%에서 시작해 0%가 될 때까지 마음껏 부수는 세로형 웹 게임.
놀이 네 가지를 아래 탭으로 오간다.

- 배포: https://richroro.github.io/games/stress-relief/
- 소스: `index.html` 한 파일 (외부 스크립트·에셋·빌드 없음, 효과음도 Web Audio 로 합성)

## 놀이

| 탭 | 하는 것 | 게이지 |
| --- | --- | --- |
| 🫧 뽁뽁이 | 누르거나 문질러서 방울을 터뜨린다. 한 장을 다 터뜨리면 새 장이 깔린다. 한 장에 하나씩 숨은 "대왕 뽁"은 터질 때 색종이가 튄다 | 방울 하나 −0.35, 대왕 뽁 −4 |
| 🍽️ 접시 깨기 | 접시 → 월요일 머그컵 → 화분 → 보고서 띄운 모니터 → 자명종 순서로 떨어진다. 누른 자리에서부터 금이 가 조각이 바닥에 쌓인다 | 하나 −3 |
| 🍡 말랑이 | 찌르면 움푹 들어가고 옆이 불룩해진다. 잡아당겼다 놓으면 "띠요옹" 하고 돌아온다 | 찌르기 −0.4, 당겼다 놓기 최대 −2.5 |
| 🗑️ 걱정 파쇄기 | 짜증나는 일을 적고 파쇄하면 종이가 가닥가닥 잘려 휴지통에 떨어진다 | 한 장 −12 |

0%가 되면 이번에 터뜨리고 깬 개수를 보여 주고, 게이지를 다시 채울 수 있다.

## 구현 메모

**접시 조각** — 물건을 오프스크린 캔버스에 한 번 그려 두고, 누른 점에서 8~12갈래로 방사형
쐐기를 만든 뒤 쐐기마다 두 번 반평면으로 잘라(Sutherland–Hodgman) 안쪽·가운데·바깥 세 조각을 얻는다.
조각은 그 다각형으로 `clip` 한 뒤 원래 그림을 그려서, 무늬와 글씨가 조각에 그대로 남는다.
쐐기는 물건을 감싸는 원 기준으로 자르기 때문에 그림이 하나도 안 걸린 빈 조각이 생기는데,
알파 채널을 몇 점 찍어 보고 버린다. 누를 때도 같은 알파로 판정해서, 물건을 감싸는 원 안이라도
그림이 없는 빈 곳을 눌러서는 깨지지 않는다.

**말랑이** — 둘레 점 30개를 이웃끼리 스프링으로 잇고, 중심 기준 원래 자리로 돌아가려는 힘과
넓이를 지키려는 압력을 더했다. 압력 덕분에 한쪽을 누르면 반대쪽이 불룩해진다.
1/120초 고정 스텝, 반암시적 오일러.

**뽁뽁이** — 손가락을 빨리 문지르면 `pointermove` 사이 간격이 방울보다 커져서 건너뛰는 방울이
생긴다. 직전 위치와 현재 위치 사이를 반지름의 60% 간격으로 쪼개 전부 확인한다.
주소창이 접혔다 펴지는 정도의 크기 변화에는 판을 다시 깔지 않는다.

**파쇄기** — 적은 글을 줄 공책 모양 캔버스에 그리고, 투입구 위에는 아직 안 들어간 윗부분만,
아래에는 들어간 만큼을 14가닥으로 잘라 그린다. 글이 길면 글씨와 줄 간격을 같이 줄이고,
그래도 넘치면 말줄임. **적은 내용은 저장하지 않는다.** 파쇄가 끝나면 입력창도 비운다.

| 증상 | 원인 | 대응 |
| --- | --- | --- |
| 접시 탭으로 넘어가면 화면이 멈춤 | 물건이 화면 위에서 떨어지는 동안 그림자 타원 반지름이 음수가 되어 `ellipse` 가 예외를 던지고, rAF 루프가 끊겼다 | 비율을 0.05~1로 묶고, 루프는 프레임 첫 줄에서 다음 프레임을 예약해 한 프레임 예외로 게임 전체가 멈추지 않게 했다 |
| 뽁뽁이 한 장이 게이지 30%를 깎음 | 방울 하나 −0.6 × 50개 | −0.35 로 낮췄다. 한 장 ≈ 17% |
| 공책 제목과 첫 줄 글씨가 겹침 | 첫 글줄을 첫 괘선 **위**에 올렸다 | 첫 괘선 아래 칸부터 쓴다 |
| 작은 화면에서 입력창이 파쇄기를 가림 | 파쇄기 위치를 무대 높이 비율로만 정했다 | 입력창 높이 아래로 내린다 |

## 검증

헤드리스 크로미움(Playwright)에서 390×780, 320×560 으로 실제 포인터 이벤트를 넣어 돌렸다.

- 뽁뽁이: 문지르기로 여러 개 터짐, 한 장을 다 터뜨리면 새 장(50개)이 깔림
- 접시 깨기: 물건 다섯 가지를 차례로 깨서 조각이 생기고, 조각 좌표에 NaN·화면 밖 이탈 없음
- 말랑이: 당겼다 놓은 뒤 3초 안에 중심이 제자리(오차 0.1px 미만), 넓이 비 1.00 으로 복귀
- 파쇄기: 긴 글을 넣고 파쇄 → 휴지통에 쌓이고 입력창으로 돌아옴
- 0% 시트 표시와 다시 채우기, 새로고침 뒤 마지막 탭과 누적 기록 유지
- 콘솔 에러 0

**확인 안 된 것** — 실기기 터치와 진동, 실제 스피커로 들은 효과음의 느낌.

## 저장

`localStorage` 의 `stress-relief:v1` 에 소리·진동 켜짐 여부, 마지막 탭, 누적 개수만 둔다.
외부 요청 0건. 백그라운드로 가면 `AudioContext` 를 멈춘다.
