# 뿡빵뿡 한글 숫자

7살 아이가 **하나·둘·셋**(우리말)과 **일·이·삼**(한자말)을 놀면서 익히는 숫자 놀이.
정답을 맞히면 고구마 캐릭터 ‘뿡이’가 뿡! 하고 방귀를 뀐다.

- 배포: https://richroro.github.io/games/ppung-numbers/
- 소스: `index.html` 한 파일 (외부 스크립트·에셋·빌드 없음)

## 구성

| 화면 | 내용 |
| --- | --- |
| 처음 | 읽는 말(하나·둘·셋 / 일·이·삼 / 둘 다)과 범위(10·20·50·100까지)를 고른다. 받은 스티커 30칸 |
| 배우기 | 숫자 판에서 누르면 숫자·우리말·한자말·그림이 한 카드에 나온다. ‘같이 세어 보자’는 1부터 끝까지 짚으며 읽어 준다 |
| 퀴즈 놀이 | 10문제. 아래 네 유형이 고르게 섞인다 |
| 결과 | 한 번에 맞힌 개수로 별 1~3개. 한 판마다 스티커 1개, 다 맞히면 1개 더 |

퀴즈 유형:

| 유형 | 보여 주는 것 | 고르는 것 |
| --- | --- | --- |
| 읽기 | 숫자 `7` | 글자 `일곱` |
| 찾기 | 글자 `일곱` | 숫자 `7` |
| 세기 | 그림 7개 | 글자 `일곱` |
| 듣기 | 음성 “일곱” | 숫자 `7` |

듣기 문제는 기기에 한국어 음성(`speechSynthesis`)이 있을 때만 나온다.

## 아이를 위한 규칙

- 틀려도 점수를 깎지 않는다. 틀린 보기만 흐려지고 다시 고를 수 있다. 두 번 틀리면 정답이 반짝인다.
- 정답을 맞히면 `7 = 일곱 = 칠`처럼 세 이름을 한 줄로 보여 주고 읽어 준다.
- 3연속 정답마다 “뿡빵뿡!” 큰 글자와 세 번 방귀.
- 20까지는 십 칸 틀(2×5)에 그림을 채우고, 그보다 크면 10개 묶음 막대 + 낱개로 보여 줘서 자릿값을 같이 본다.
- 보기는 헷갈리기 쉬운 수(바로 옆 수, 10 차이, 자리 바꾼 수)를 먼저 쓴다.
- 우리말은 아흔아홉까지다. 100이 나오면 한자말(백)로 묻는다.

## 구현 메모

- 방귀·효과음은 전부 Web Audio 로 합성한다. 톱니파에 네모파 떨림(13~24Hz)을 곱하고 저역 통과로 뭉갠 소리.
- 설정·스티커·음소거는 `localStorage`(`ppung.*`)에만 저장한다. 저장소가 막혀 있어도 게임은 그대로 돈다.
- `prefers-reduced-motion` 이면 애니메이션을 끈다.
