# 뿡빵뿡 한글 숫자

7살 아이가 **하나·둘·셋**(우리말)과 **일·이·삼**(한자말)을 놀면서 익히는 숫자 놀이.
정답을 맞히면 고구마 캐릭터 ‘뿡이’가 뿡! 하고 방귀를 뀐다.

- 배포: https://richroro.github.io/games/ppung-numbers/
- 소스: `index.html` 한 파일 (외부 스크립트·에셋·빌드 없음). 홈 화면 설치용으로 `manifest.webmanifest`, `sw.js`, 아이콘만 따로 있다.

## 구성

| 화면 | 내용 |
| --- | --- |
| 처음 | 읽는 말(하나·둘·셋 / 일·이·삼 / 둘 다), 범위(10·20·50·100까지), 문제 읽어 주기, 스티커 30칸, 뿡이 꾸미기, 부모님 기록 |
| 배우기 | 숫자 판에서 누르면 숫자·우리말·한자말·그림이 한 카드에 나온다. ‘같이 세어 보자’는 1부터 끝까지 짚으며 읽어 준다. 잘 아는 수에는 점이 찍힌다 |
| 퀴즈 놀이 | 10문제. 아래 여덟 유형이 고르게 섞인다 |
| 결과 | 한 번에 맞힌 개수로 별 1~3개. 한 판마다 스티커 1개, 다 맞히면 1개 더 |

퀴즈 유형:

| 유형 | 보여 주는 것 | 고르는 것 |
| --- | --- | --- |
| 읽기 | 숫자 `7` | 글자 `일곱` |
| 찾기 | 글자 `일곱` | 숫자 `7` |
| 세기 | 그림 7개 | 글자 `일곱` |
| 듣기 | 음성 “일곱” | 숫자 `7` |
| 다음 수 | `다섯 › 여섯 › ? › 여덟` | 글자 `일곱` |
| 크기 비교 | 🐘 더 큰 / 🐭 더 작은 | 두 글자 중 하나 |
| 글자 만들기 | 숫자 `48` | 글자 조각을 차례로 `마`·`흔`·`여`·`덟` |
| 단위 세기 | 강아지 3마리 | `세 마리` |

- 듣기는 기기에 한국어 음성(`speechSynthesis`)이 있을 때만 나온다.
- 단위 세기는 하나·둘·셋(또는 둘 다)일 때만, 20까지만 나온다. 단위 앞에서는 하나→한, 둘→두, 셋→세, 넷→네, 스물→스무.

## 셈 놀이 (더하기 빼기)

처음 화면에서 더하기 / 빼기 / 둘 다를 고르고 ‘셈 놀이’를 누르면 10문제가 나온다. 범위는 위에서 고른 10·20·50·100을 그대로 쓴다.

| 유형 | 보여 주는 것 | 고르는 것 |
| --- | --- | --- |
| 그림 셈 | 십 칸 틀 두 개를 `+`로 잇거나, 빼는 만큼 빨간 가위표 | 글자 `여덟` |
| 숫자 식 | `3 + 4 = ?` | 글자 `일곱` |
| 글자 식 | `셋 더하기 넷은?` | 숫자 `7` |
| 빈칸 | `7 − ? = 4` | 글자 `셋` |
| 이야기 | “사과 일곱 개가 있어요. 한 개를 먹었어요. 몇 개 남았을까?” | `여섯 개` |

- 20까지는 자유롭게 내고, 50·100까지는 받아올림·받아내림이 없는 식(`23 + 4`, `30 + 20`, `47 − 5`)만 새로 낸다. 답은 늘 1 이상.
- 그림 셈은 더하기 10+10, 빼기 20까지, 이야기 문제는 20까지만 나온다. 이야기는 늘 우리말 + 단위(한 개, 스무 마리).
- 틀린 식은 `ppung.mathMiss`에 최대 30개 저장해 두었다가 다음 판에 가끔 다시 낸다. 한 번에 맞히면 목록에서 빠진다.

## 아이를 위한 규칙

- 틀려도 점수를 깎지 않는다. 틀린 보기만 흐려지고 다시 고를 수 있다. 두 번 틀리면 정답이 반짝인다.
- 정답을 맞히면 `7 = 일곱 = 칠`처럼 이름을 한 줄로 보여 주고 읽어 준다.
- ‘문제 읽어 주기’를 켜 두면 문제마다 말풍선을 소리로 읽어 준다. 정답을 흘리지 않는 말만 읽고, 🔊 버튼은 힌트까지 읽는다.
- 3연속 정답마다 “뿡빵뿡!” 큰 글자와 세 번 방귀. 별 셋이면 결과 화면에 별비가 내린다.
- 20까지는 십 칸 틀(2×5)에 그림을 채우고, 그보다 크면 10개 묶음 막대 + 낱개로 보여 줘서 자릿값을 같이 본다.
- 보기는 헷갈리기 쉬운 수(바로 옆 수, 10 차이, 자리 바꾼 수)를 먼저 쓴다.
- 우리말은 아흔아홉까지다. 100이 나오면 한자말(백)로 묻는다.

## 복습

숫자마다 말(우리말/한자말)별로 `한 번에 맞힘 r`, `틀림 w`, `연속 정답 k`를 저장한다.

| 상태 | 조건 | 뽑힐 가중치 |
| --- | --- | --- |
| 헷갈리는 수 | 틀린 적 있고 `k < 2` | 4 (문제에 ‘다시 도전!’ 표시) |
| 처음 보는 수 | 기록 없음 | 2 |
| 보통 | 그 밖 | 1 |
| 잘 아는 수 | `k ≥ 2` | 0.5 |

부모님께 열면 말별로 잘 아는 수 개수와 헷갈리는 수 목록이 나온다. 기록만 따로 지울 수 있다.

## 뿡이 꾸미기

스티커가 모이면 옷이 열린다: 리본 2 · 모자 5 · 왕관 9 · 선글라스 13 · 신사 모자 18 · 꽃 24.
새로 열린 옷은 결과 화면에서 바로 입혀 준다.

## 구현 메모

- 방귀·효과음은 전부 Web Audio 로 합성한다. 톱니파에 네모파 떨림(13~24Hz)을 곱하고 저역 통과로 뭉갠 소리.
- 설정·스티커·옷·기록은 `localStorage`(`ppung.*`)에만 저장한다. 저장소가 막혀 있어도 게임은 그대로 돈다.
- 서비스 워커는 네트워크를 먼저 쓰고 실패할 때만 캐시로 연다(배포 직후 옛 파일이 남지 않게).
- 진동(`navigator.vibrate`)은 지원하는 기기에서만, 소리를 끄면 같이 꺼진다.
- `prefers-reduced-motion` 이면 애니메이션을 끈다.
