# Foldline · 접히는 길

도로가 벽과 천장으로 90도씩 접히는 3D 드라이빙 게임. 길 위에 떠 있는 음표를 지나가면
한 음씩 울리고, 이어 달리면 멜로디가 된다.

- 배포: https://richroro.github.io/games/foldline/
- 소스: `index.html` 한 파일. Three.js(0.170, jsDelivr CDN) 말고는 외부 스크립트가 없고,
  3D 모델·텍스처·오디오 파일도 없다. 차, 집, 꽃, 아치, 구름, 음표 그림, 음악까지 전부 코드로 만든다.

## 조작

| 키 | 터치 | 동작 |
| --- | --- | --- |
| ← → / A D | ◀ ▶ | 차선 바꾸기 (음표 줍기, 상자 피하기) |
| Space | JUMP | 점프. 나무 상자를 넘는다 |
| ↑ / W | GAS | 가속 (기본 30 → 40) |
| ↓ / S | — | 감속 |
| P / Esc | — | 일시정지 |
| R | — | 처음부터 |
| M | 🔊 | 소리 켜기/끄기 |

초록 화살표 판을 밟으면 1.6초 동안 부스트. 상자에 부딪히면 속도가 42%로 떨어진다.

## 코스

다섯 챕터, 약 1.4km. 크루즈 속도로 45초 안팎.

| # | 챕터 | 접히는 방식 |
| --- | --- | --- |
| 1 | Bougainvillea Corridor · 부겐빌레아 회랑 | 좌우 커브 뒤 옆으로 90도 비틀려 벽을 달린다 |
| 2 | Ceiling Street · 천장 거리 | 위로 두 번 접혀 거꾸로 매달린 집들 사이를 달리고, 180도 비틀어 돌아온다 |
| 3 | Riverlight · 강빛 길 | 아래로 꺾였다 다시 수평, 강 위 등불 옆에서 벽 타기 |
| 4 | Courtyard · 안뜰 | 두 번 비틀려 천장으로 올라간 안뜰, 다시 180도 |
| 5 | The Home · 집으로 | 한 번 떨어졌다 올라와 결승선 |

코스는 `PIECES` 배열 한 줄에 조각 하나다: `[길이, 좌우°, 위아래°, 비틀기°, 챕터]`.
조각마다 도로의 방향(쿼터니언)을 0.5 단위씩 조금씩 돌려 가며 중심선과 앞·위·오른쪽 축을 쌓는다.
차는 이 축 위에서 `(거리 s, 좌우 x, 높이 h)`로만 움직이므로 떨어지지 않고, 중력은 늘 도로의
아래쪽이다. 대신 하늘(월드 기준 그라데이션)과 빗줄기, 오른쪽 아래 중력 나침반이 진짜 아래가
어디인지 보여 준다.

코스를 고치면 자기 자신과 부딪히지 않는지 확인해야 한다. 지금 코스는 60단위 이상 떨어진
두 지점 사이 최소 거리가 47단위(도로 폭 14.4)다.

## 음악

- 챕터마다 직접 쓴 16칸(8분음표) 프레이즈 4개. 음표는 6단위 간격으로 깔려서,
  크루즈 속도(30)로 달리면 150BPM 8분음표로 들린다.
- 음 높이에 따라 차선이 정해진다. 낮은 음은 왼쪽, 높은 음은 오른쪽. 높은 음일수록 조금 더 높이 뜬다.
- 프레이즈 음표의 75% 이상을 모으면 그 프레이즈가 완성(송북에 노란색).
- 배경은 라디오 세 채널(PAPER MOON FM 로파이 · FOLD RADIO 밝은 비트 · NIGHT BUS 앰비언트).
  코드 진행이 챕터 조성을 따라가서 음표 소리와 어긋나지 않는다.
- BAND 버튼으로 음표 악기 변경: 뮤직박스 · 마림바 · 신스.
- 엔진음, 상자 충돌, 부스트, 점프, 빗소리까지 Web Audio 로 합성.

## 시간대와 날씨

DAWN · MORNING · NOON · GOLDEN · DUSK · NIGHT 를 고르거나, AUTO 로 두면 챕터마다
아침 → 한낮 → 노을 → 해질녘 → 밤으로 넘어간다. 밤에는 가로등이 켜지고 별이 뜬다.
RAIN 을 켜면 빗줄기가 월드 기준 아래로 떨어져서, 천장을 달릴 때는 비가 위로 올라가는 것처럼 보인다.

## 검증

헤드리스 크로미움(SwiftShader)에서 돌렸다.

- 봇 주행: 다음 음표 차선으로 붙고 상자 앞에서 점프하는 봇이 끝까지 완주.
  44.5초, 음표 69/70, 프레이즈 9/9, 챕터 스플릿 4개 모두 기록, 결과 화면과 최고 기록 저장까지 확인.
- 챕터별·시간대별 화면을 캡처해서 도로가 접히는 구간(벽, 천장, 180도 비틀기)에서
  카메라가 도로 아래로 들어가지 않는지 봤다.
- 390×844 터치 화면에서 실제 탭으로 시작, ◀ ▶ 버튼 조향 확인. 세로 화면은 시야각을 넓힌다.
- 콘솔 에러 0 (오프라인 테스트라 막아 둔 웹폰트 요청 제외).

확인 안 된 것: 실기기 GPU 성능과 소리. 테스트 환경은 소프트웨어 렌더러라 프레임이 느렸다.

## 라이선스

개인 프로젝트. 멜로디는 직접 쓴 것이고, 실존 게임의 에셋이나 코드는 쓰지 않았다.
