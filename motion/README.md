# 모션랩 — 브라우저에서 만드는 2D 모션 그래픽

애프터 이펙트 같은 키프레임 애니메이션을 설치 없이 브라우저에서 만드는 정적 웹 앱.
텍스트·도형·파티클 레이어에 키프레임과 이징을 걸고, 결과를 MP4/WebM·GIF·PNG로 저장한다.

- 배포: https://richroro.github.io/motion/
- 소스: `index.html` 한 파일 (외부 스크립트·빌드 없음, 구글 폰트만 링크)

## 되는 것

| 영역 | 기능 |
| --- | --- |
| 레이어 | 텍스트, 사각형(둥근 모서리), 원, 다각형, 별, 선, 이미지, 파티클(색종이·동그라미·별·불꽃) |
| 키프레임 | 속성마다 ◇ 로 키 찍기/지우기, 키가 있는 속성은 값을 바꾸면 그 시각에 자동으로 키 추가 |
| 이징 | 일정하게·부드럽게·천천히 멈춤/출발·확→스르륵·살짝 넘침·당겼다 출발·고무줄·통통 튀기·뚝 끊기 (곡선 미리보기) |
| 속성 | 위치·크기·가로/세로 배율·회전·불투명도·흐림, 크기·모서리·별 안쪽, 채우기·선 색(색도 보간), 선 두께, 그림자/빛 |
| 선 그리기 | 선 시작·끝·밀기(트림 패스) — 도형 테두리가 그려지거나 지워지는 효과 |
| 글자 | 글꼴 8종, 굵기·정렬·줄 간격·자간, 글자/단어/줄 단위 등장 효과 9종(타자기+커서, 뿅, 가림막, 글자 섞기 …) |
| 프리셋 | 들어올 때 11종 + 선 그리기 + 글자 6종, 나갈 때 7종 — 레이어 시작/끝 기준으로 키를 찍어 준다 |
| 반복 효과 | 둥실둥실·두근두근·흔들흔들·시계추·계속 회전·깜빡임·글자 물결 (키프레임 위에 더해진다) |
| 무대 | 끌어서 이동(가운데 스냅), 모서리로 크기, 위 손잡이로 회전(Shift 15°), 위치 경로 점선 표시 |
| 타임라인 | 레이어 막대 이동·양 끝 트리밍, ◆ 끌어서 타이밍 조절(프레임·재생 위치 스냅), Shift 로 여러 개 선택 |
| 템플릿 | 타이틀 인트로, 하단 자막, 로고 등장, 카운트다운, 구독 버튼(크로마키), 키네틱 타이포(9:16), 로딩 루프 |
| 프로젝트 | 16:9 / 9:16 / 1:1 / 4:5, 0.5~60초, 24/30/60fps, 배경 단색·선형·원형·투명, 되돌리기(120단계), 자동 저장, JSON 저장/열기 |
| 내보내기 | 영상(MP4 또는 WebM, 해상도·프레임·반복 횟수), GIF(투명 배경 지원), 현재 장면 PNG |

## 구조

상태는 `P`(프로젝트)와 `UI`(재생 위치·선택·펼침)로 나뉜다.

- 속성 값은 숫자/색 그대로이거나 `{k:[{t, v, e}]}` 키프레임 목록이다. `val(L, prop, t)` 하나가
  둘을 모두 처리하고, 키 사이는 **앞 키의 이징**으로 보간한다(색은 RGB 보간).
- `evalLayer()` 가 한 시각의 속성을 모두 계산한 뒤 반복 효과를 더한다. 그리기·클릭 판정·선택 상자가
  모두 같은 `layerMatrix()`(DOMMatrix: 위치 → 회전 → 배율 → 기준점) 를 써서 어긋나지 않는다.
- 렌더는 시간 `t` 만 받는 순수 함수라서 미리보기·썸네일·GIF·영상이 전부 같은 `render()` 를 쓴다.
  파티클도 레이어마다 고정 시드의 난수(mulberry32)를 써서 같은 시각이면 늘 같은 장면이 나온다.
- 선 그리기는 경로 길이를 도형별로 계산(타원은 라마누잔 근사)해서 `setLineDash([보일 길이, 나머지])` 와
  `lineDashOffset` 으로 자른다. 주기를 경로 길이와 같게 두어 닫힌 도형에서 ‘밀기’가 한 바퀴 이어진다.
- 글자는 한 글자씩 폭을 재서 배치하고(`measureText` 캐시), 등장 값 `reveal` 하나로
  글자·단어·줄 단위 진행도를 겹쳐 가며 나눠 준다.
- 되돌리기는 매 확정 시점의 JSON 스냅샷. 이미지는 `ASSETS` 로 따로 빼서 스냅샷이 무거워지지 않게 했다.

## 내보내기

- **GIF**: 라이브러리 없이 직접 인코딩한다. 프레임 24장에서 색을 모아 미디언 컷으로 256색 팔레트를 만들고
  (투명 배경이면 255색 + 투명 1색), 프레임마다 가장 가까운 색으로 바꾼 뒤 LZW 로 압축한다.
  그라데이션 배경이면 4×4 바이어 디더링을 기본으로 켠다. 렌더가 시간 함수라 실시간보다 빨리 뽑힌다.
- **영상**: `canvas.captureStream()` + `MediaRecorder` 실시간 녹화. 지원되는 첫 형식을 고른다
  (`H.264 MP4 → VP9 WebM → VP8 WebM → 기본`). 녹화 중에는 탭이 살아 있어야 한다.
- 파일 이름은 `motionlab_날짜_시각.확장자`. 한글 이름은 크로미움 계열에서 `download` 로 바뀌어 저장되는
  경우가 있어서 웹컷과 같은 규칙으로 영문+날짜를 쓴다.
- 샌드박스(iframe)에서 페이지가 직접 시작한 다운로드가 막히면 호스트 저장 창구로 넘긴다(웹컷과 같은 방식).

## 검증

헤드리스 크로미움(Playwright)에서 확인했다.

- 첫 화면 템플릿 자동 재생, 템플릿 7종 로드와 썸네일, 콘솔 오류 없음
- 레이어 추가 → 프리셋(글자별 뿅·사라지기·선 그리기·돌며 등장)이 해당 속성에 키를 찍는지
- 무대에서 끌어 이동, ◇ 로 키 찍고 다른 시각에 값 입력 → 키 2개, 타임라인에서 ◆ 끌기(0.41초 이동),
  막대 끝 트리밍, 이징 바꾸기, 되돌리기/다시 실행
- GIF 320×320·10fps → `ImageDecoder` 로 다시 풀어 20프레임·프레임당 100ms 확인, 투명 배경 GIF
- WebM 녹화 파일 생성, PNG 저장
- 프로젝트 저장 → 새로 → 열기 왕복, 새로고침 뒤 자동 저장 복원
- 390px 모바일 화면에서 가로 넘침 없음, 추가·속성·타임라인 탭 전환

## 한계

- 영상은 실시간 녹화라 길이만큼 시간이 걸리고, 브라우저가 MP4 녹화를 지원하지 않으면 WebM 으로 저장된다.
- 레이어 묶기(부모-자식)·마스크 레이어·자유 곡선(펜 도구)은 없다. 가림막 효과는 글자 효과로만 있다.
- 사파리는 캔버스 `filter` 지원이 늦어 흐림 효과가 보이지 않을 수 있다(나머지는 그대로 동작).
- GIF 는 256색이라 사진·그라데이션이 많으면 계단이 생긴다(디더링으로 완화).
