# 한글 놀이터

7살 아이를 위한 한글 공부 웹앱. 호랑이 캐릭터 '호야'가 함께 놀아 줍니다.

- 배포: https://richroro.github.io/hangul/
- 소스: `index.html` 한 파일 (빌드 없음, 글꼴만 Google Fonts `Jua`)

## 놀이

| 놀이 | 내용 |
| --- | --- |
| 자음 친구 / 모음 친구 | ㄱ~ㅎ, ㅏ~ㅣ 카드. 글자 이름과 예시 낱말(🚂 **기**차)을 읽어 줌. 전부 보면 별 3개 |
| 글자 만들기 | 자음 + 모음 = 글자. 미션(🦋 나비의 '나' 만들기)과 마음대로 모드 |
| 소리 찾기 | 들려주는 글자를 4개 중에서 고르기 (자음만/모음만 다른 헷갈리는 보기) |
| 그림 낱말 | 그림을 보고 맞는 낱말 고르기 |
| 빈칸 채우기 | 낱말에서 빠진 글자 고르기, 🔊로 낱말 전체를 힌트로 들을 수 있음 |
| 따라 쓰기 | 손가락으로 자음·모음·글자 따라 쓰기. 글자 모양을 얼마나 채웠는지, 선 밖으로 나갔는지 보고 별 1~3개 |
| 스티커북 | 별 5개마다 스티커 1장, 총 32장 |

퀴즈는 한 판에 5문제이고 한 번에 맞힌 문제마다 별 1개. 따라 쓰기는 글자마다 처음 성공했을 때 별 1개.

## 기술 메모

- 소리: 브라우저 음성 합성(`speechSynthesis`, ko-KR). 한국어 음성이 없는 기기에선 안내 문구가 뜸
- 효과음: Web Audio로 직접 합성 (부모 설정에서 끌 수 있음)
- 한글 조합: 유니코드 `0xAC00 + (초성×21 + 중성)×28 + 종성`
- 기록(별·스티커·본 글자)은 `localStorage`에만 저장
