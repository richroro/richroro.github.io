# 한글 놀이터

7살 아이를 위한 한글 공부 앱. 호랑이 캐릭터 '호야'와 함께 28단계 한글 모험을 떠납니다.

- 배포: https://richroro.github.io/hangul/
- 소스: `index.html` 한 파일 + PWA 파일(`manifest.webmanifest`, `sw.js`, 아이콘). 빌드 없음, 글꼴만 Google Fonts `Jua`

## 흐름

1. **처음 만남**: 이름과 함께할 동물 친구를 고르면 호야가 이름을 불러 줌 ("지우야, 반가워!")
2. **홈**: 레벨·연속 출석(🔥)·별, 오늘의 목표 링, "한글 모험 이어하기", 자유 놀이 10가지
3. **모험 지도**: 구불구불한 길 위 28단계. 앞 단계를 깨야 다음이 열리고, 단계마다 별 0~3개

## 모험 지도 (28단계)

| 나라 | 단계 | 배우는 것 | 문제 유형 |
| --- | --- | --- | --- |
| 🏰 자음 나라 | 7 | ㄱㄴ, ㄷㄹ … ㅍㅎ (두 개씩) | 새 글자 카드 → 글자 찾기, 첫소리 그림 찾기, 소리 듣고 고르기 |
| 🌊 모음 바다 | 5 | ㅏㅑ, ㅓㅕ … ㅡㅣ | 글자 찾기, 아/야 소리 구별, ㄱ+ㅏ=? |
| 🌳 글자 숲 | 6 | 가갸, 거겨 … 가~히 | 자음+모음 조합, 소리 찾기, 그림 낱말 |
| 🌷 낱말 동산 | 5 | 두 글자 → 긴 낱말 | 그림 낱말, 듣고 낱말 찾기, 빈칸 채우기 |
| ⛰️ 받침 산 | 5 | ㄱㄴ, ㄹㅁ, ㅂㅇ, ㄷㅅ 받침 | 받침 카드 → 가+ㄱ=?, 받침 소리 찾기 |

- 단계 별: 틀린 횟수 0번 ★3, 1~2번 ★2, 그 이상 ★1. 다시 하면 더 높은 기록만큼 별이 추가됨
- 두 번 틀리면 정답이 반짝이며 힌트를 줌 (아이가 막히지 않게)
- 나라를 하나 끝낼 때마다 보너스 별 3개

## 자유 놀이

자음 친구 · 모음 친구 · 받침 친구(카드) / 글자 만들기(미션·마음대로, 받침 넣기) / 소리 찾기 · 그림 낱말 · 빈칸 채우기(5문제) /
짝 맞추기(그림↔낱말 6쌍 카드 뒤집기) / 따라 쓰기(자음·모음·글자, 채점 별 1~3개) / 스티커북(32장)

## 성장 장치

- **별 → 스티커**: 별 5개마다 스티커 1장
- **레벨 9단계**: 🌰 한글 씨앗 → 🌱 새싹 → … → 🎓 박사 → 👑 한글 왕. 레벨 업 축하 창
- **하루 목표**: 놀이 N번(기본 3번). 달성하면 축하 창, 연속 출석 🔥 표시

## 부모님 메뉴

곱셈 문제로 잠금. 아이 이름·캐릭터 변경, 학습 현황(단계·별·정답률·출석), 최근 7일 놀이 막대그래프,
처음에 자주 틀린 글자·낱말 목록(누르면 소리), 효과음/배경 음악/읽기 빠르기/하루 목표 설정, 앱 설치, 기록 초기화.

## 기술 메모

- 소리: 브라우저 음성 합성(`speechSynthesis`, ko-KR). 효과음과 배경 음악은 Web Audio로 직접 합성
- 한글 조합/분해: 유니코드 `0xAC00 + (초성×21 + 중성)×28 + 종성`. 조사(을/를, 아/야, 으로/로)도 받침으로 자동 선택
- 문제는 단계마다 무작위 생성, 같은 정답이 한 판에 겹치지 않게 함
- 따라 쓰기 채점: 글자 모양 마스크와 그린 선을 96×96으로 겹쳐 덮은 비율·벗어난 비율 계산
- 기록은 `localStorage`(`hangul-playground-v2`)에만 저장. 이전 버전 기록은 자동으로 옮겨 옴
- PWA: 홈 화면 설치, 오프라인 실행 (페이지는 네트워크 우선이라 업데이트가 바로 반영됨)
