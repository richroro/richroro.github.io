EPISODES

맨손에서 시작한 사람들

물려받은 회사가 아니라 바닥에서 올라온 한국 창업가들. 편마다 이야기 방식이 다릅니다. 액자식, 하룻밤의 술자리, 두 시간의 교차 편집, 전단지의 1인칭, 실패 일지, 게임 스테이지, 두 나라의 거울, 고객의 하룻밤. 연도·숫자·사건은 공개된 사실만 쓰고, 대사와 장면 설정은 각색했습니다.

SOURCE

애니를 만드는 코드

그림 파일·영상 파일이 하나도 없습니다. 캐릭터 얼굴, 배경, 불길과 집중선까지 전부 SVG와 캔버스 코드로 그리고, 배경음과 효과음도 Web Audio로 합성합니다. 에피소드는 episodes.js의 대본 데이터일 뿐이라, 객체 하나를 추가하면 새 화가 생깁니다.

success-anime/
├─ engine.js     캐릭터/배경 렌더러 · 파티클 · 사운드 (공용 엔진)
├─ index.html    가로 재생기 · 대본 편집기
├─ shorts.html   9:16 세로 쇼츠 (요약 · 레슨)
├─ episodes.js   에피소드 대본 (인물 생김새 + 장면 + 컷 + 교훈)
├─ tools/        쇼츠 MP4 렌더러
└─ README.md     새 에피소드 추가 · 쇼츠 영상 뽑는 법
