# 테슬라 지표

테슬라를 볼 때 인도량 말고 **돈이 어떻게 도는지**와 **누가 납품하는지**를 같이 보려고 만든 지표 페이지.

- 배포: https://richroro.github.io/tesla-metrics/
- 소스: `index.html` 한 파일 (외부 스크립트·빌드 없음, 구글 폰트만 링크)

## 들어 있는 것

| 영역 | 내용 |
| --- | --- |
| 최근 분기 | 2026 Q2 매출·영업이익률·자동차 총마진·잉여현금흐름 |
| 매출·마진 | 분기별 매출과 영업이익률을 **따로** 그린 차트 + 연간 영업이익률 5년 |
| 사업 부문 | 2025년 자동차 / 에너지 / 서비스 매출과 전년 대비 |
| 공급망 | 배터리 셀·양극재·AI 칩 3개 갈래 도식, 한국 기업 표시 |
| 자율주행 | 무인 로보택시 도시·대수, FSD v15 일정, 비용이 향하는 곳 |

## 이 페이지의 요지

**같은 매출, 4분의 1 토막 난 이익.**

| | 2025 Q3 | 2026 Q2 |
| --- | --- | --- |
| 매출 | $28.10B | $28.24B (+0.5%) |
| 영업이익률 | 5.8% | 1.4% |
| 영업이익 | 약 $1.63B | $0.40B (**−76%**) |

매출은 사상 최대인데 영업이익률은 1.4%다. 판관비·연구개발비가 1년 새 47% 늘어 43.5억 달러가 된 게 가장 큰 이유고,
그 돈은 AI 인프라와 자율주행으로 간다. 지금 손익계산서는 **자동차 회사가 AI 회사 비용을 대고 있는 구조**다.

그래서 매출과 마진을 **한 그래프에 겹치지 않았다.** 축이 다른 값을 한 그림에 넣으면 착시가 생긴다.
분기 순서를 똑같이 맞춘 두 개의 차트로 나눠, 매출 그래프는 오르는데 마진 그래프는 꺾이는 걸 위아래로 보게 했다.

## 공급망

한국 투자자에게는 테슬라 주가보다 **누가 테슬라에 납품하는지**가 더 실용적일 때가 많아서, 세 갈래로 나눠 그렸다.
한국 기업은 배경색과 `KR` 태그로 표시한다(색만으로 구분하지 않는다).

| 갈래 | 공급처 |
| --- | --- |
| 배터리 셀 | 테슬라 자체 4680(US) · 파나소닉(JP) · **LG에너지솔루션(KR)** · CATL(CN) |
| 양극재 | **엘앤에프(KR)** · **포스코퓨처엠 · 에코프로비엠(KR)** |
| AI 칩 | **삼성전자 파운드리(KR)** · TSMC(TW) |

가장 큰 건이 삼성 파운드리다. AI6 전량 위탁생산, 165억 달러 규모, 텍사스 테일러 공장, 2033년까지.
AI5 물량도 TSMC와 나눠 맡는다. 자율주행이 진척될수록 파운드리 실적과 연결된다.

> 공급 계약은 바뀐다. 엘앤에프의 29억 달러 하이니켈 계약처럼 **기간이 명시된 건은 기간까지 적어 두었다.**
> 페이지에도 투자 전 각 사 공시로 최신 상태를 확인하라는 경고를 달아 두었다.

## 데이터

수치는 `index.html` 맨 위 `DATA` 블록 한 곳에 모여 있다. 실적은 분기 종료 3~4주 뒤에 나온다.

| 항목 | 기간 | 출처 |
| --- | --- | --- |
| 매출·영업이익률·부문별 매출 | 2025 Q1 ~ 2026 Q2 | Tesla 분기 실적 발표 (Quarterly Update / 8-K) |
| 연간 영업이익률 | 2021 ~ 2025 | Tesla 연간 실적 · 10-K |
| 배터리 셀 공급사 | 2026-09 기준 | 각 사 발표 및 업계 보도 |
| AI 칩 위탁생산 | 2025-07 계약 | 삼성전자 공시 · 머스크 공개 확인 |
| 양극재 공급 계약 | 2024 ~ 2025 | 엘앤에프 공시 |
| 로보택시 운행 현황 | 2026-09 기준 | 로보택시 추적 집계 |

검증된 항등식(테스트에 포함):

```
2025 분기 매출  19.335 + 22.496 + 28.095 + 24.901 = 94.827   (연간 발표 94.83)
영업이익 = 매출 × 영업이익률
  25 Q3   28.095 × 5.8% = 1.63B
  26 Q2   28.240 × 1.4% = 0.395B   (발표 0.398B, 반올림 차이)
  26 Q1   22.390 × 4.2% = 0.940B   (발표와 일치)
```

부문별 매출 합계는 각 수치가 반올림돼 연간 합계와 0.03B 차이가 난다 — 페이지에도 적어 두었다.

## 검증

헤드리스 크로미움(Playwright)에서 22개 항목을 확인했다.

- 분기 매출 합계 == 연간 발표치
- 영업이익 = 매출 × 마진이 발표된 영업이익과 일치 (25 Q3 / 26 Q2 / 26 Q1)
- "같은 매출에 이익 4분의 1" 주장이 데이터로 성립하는지 (비율 4.13배)
- 부문 합계가 반올림 오차 범위(0.04B) 안인지
- 에너지 비중 파생값(13.5%), 차트 막대 개수, 툴팁, 표 전환과 합계 검산 행
- 공급망 도식: 레인 3개 · 노드 8개 · 한국 기업 4곳이 실제로 강조되는지, 삼성·LG엔솔·엘앤에프가 들어 있는지
- 데스크톱/모바일(375px) 가로 스크롤 0px, 다크 모드

## 한계

- 주가·밸류에이션(PER 등)은 싣지 않는다. 시세는 [테슬라 주주 계산기](../tesla/)에 있다.
- 영업이익은 매출 × 발표 마진으로 되짚은 값이라 반올림 오차가 있다. 정확한 값은 실적 자료를 봐야 한다.
- 로보택시 대수는 집계 시점 기준이고 빠르게 바뀐다.
- 투자 권유가 아니다.
