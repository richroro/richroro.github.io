# 오늘의 경제 — 경제뉴스 한눈에

주요 언론사의 경제 RSS 를 한곳에 모아 보여 주는 정적 사이트.

- **같은 사건은 하나로 묶는다.** 매체마다 제목이 조금씩 달라도("한은, 기준금리 동결" / "한국은행 기준금리 2.50% 동결")
  한 줄로 모으고, 다른 매체 기사는 그 아래 관련 기사로 단다.
- **주요 뉴스**는 여러 매체가 함께 다룬 순서로 고른다. 편집자가 없어도 오늘 무엇이 큰 뉴스인지 드러난다.
- 분야(증시·금리·환율·부동산·산업·기업·국제·가상자산·경제일반)별 탭, 검색, 매체·날짜 고르기, 최근 30일 지난 뉴스.
- 오늘 많이 나온 말(같은 사건은 한 번만 센다), 분야·매체별 기사 수, 피드 수집 상태.
- 맨 위 시장 지표 띠: 코스피·코스닥·원/달러·S&P 500·나스닥·미 국채 10년·WTI·금·비트코인 (한 달 추이 포함).
- 기사 저장(☆)과 읽은 기사 흐리게 표시는 브라우저에만 남는다. 주소(#cat=market&q=금리)로 지금 보는 화면을 공유할 수 있다.
- 페이지를 열어 둔 채로 두면 5분마다 새 수집이 있는지 보고 "새 기사 N건" 단추를 띄운다.

배포: https://richroro.github.io/news/

## 어떻게 돌아가나

서버가 없다. 깃허브 액션(`.github/workflows/update-news.yml`)이 06~23시(한국 시각) 매시 17분에
`fetch_news.py` 를 돌려 결과를 `news/data/` 에 커밋하고, GitHub Pages 가 그대로 내보낸다.
바뀐 게 없으면 커밋하지 않는다. 인증키는 필요 없다.

```
news/feeds.json              수집할 RSS 와 시장 지표 목록 — 여기만 고치면 된다
news/fetch_news.py           수집기 (파이썬 표준 라이브러리만 사용)
news/data/index.json         갱신 시각, 날짜 목록, 피드 상태, 24시간 키워드
news/data/days/2026-10-06.json  그날(한국 시각) 기사 — 최신순, 최대 900건
news/data/markets.json       시장 지표 (Yahoo Finance)
news/index.html, app.js      페이지
```

날짜별 파일로 나눈 까닭: 매시 커밋하므로 파일 하나에 다 넣으면 저장소가 금방 불어난다. 날짜로 나누면
매번 오늘 파일만 바뀐다. 30일이 지난 파일은 지운다.

### 수집기가 하는 일

1. `feeds.json` 의 피드를 차례로 받는다. 실패한 피드는 건너뛰고(상태에 기록), 이미 모은 기사는 그대로 둔다.
   EUC-KR 피드, `&` 가 이스케이프 안 된 깨진 XML 도 읽는다.
2. 제목·요약을 손질하고(HTML 태그·엔티티 제거, 요약 110자), 링크의 추적 변수(utm_ 등)를 떼어 같은 기사를 알아본다.
   구글 뉴스 같은 모음 피드는 "제목 - 매체" 에서 매체를 떼어 내고, 직접 받은 기사와 겹치면 버린다.
3. 분야는 제목·요약의 낱말로 정한다(`CATEGORIES`). 못 정하면 피드의 `hint`.
4. 최근 3일치 기사를 다시 묶는다. 제목의 글자 조각과 낱말을 흔한 정도로 가중한 유사도를 보고,
   **숫자가 엇갈리면**(코스피 2,900 / 코스닥 900, 23주 / 3주) 비슷해도 떼어 놓는다.

### 피드 더하기·빼기

`feeds.json` 의 `feeds` 에 한 줄 넣는다. `hint` 는 `market` `macro` `estate` `industry` `global` `crypto` `general` 중 하나.
모음 피드면 `"aggregator": true`. main 에 푸시하면 수집이 바로 한 번 돈다.

## 로컬에서

```
python news/fetch_news.py                 # 실제로 받기 (news/data 에 씀)
python -m unittest discover -s news/tests # 테스트 (네트워크 없이 tests/fixtures 사용)
python -m http.server -d .                # http://localhost:8000/news/
```

## 저작권

제목과 짧은 요약, 원문 링크만 보여 준다. 기사 저작권은 각 언론사에 있고, 기사를 누르면 언론사 원문으로 간다.
